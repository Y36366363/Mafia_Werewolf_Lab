# v36 冻结审计协议（2026-11-10）

## 策略与参数字典
本轮不改游戏策略，不增q网格，不新增打平衡，不加信用。重放v35的dead_q0与dead_q50、self_copy_early与self_copy_team_relay四单元全部2048个旧留出：8,192次完整历史重放。再用210000000起的1024个新种子、同四单元作4,096次固定策略确认。另209000000起每单元2局smoke，共8局。旧留出已被查看，只做诊断；新批也不拿来改规则。

- dead_q0/q50：只在警察凭警队名单私知首死跳警者不是队友时，初始一次局部回应概率0%／50%；本人被查杀的防御保留。其他时点包括day2起沿用既有续局。
- self_copy_early：首死匪发非匪金水，第一活匪复制并错误归票。self_copy_team_relay：两匪共同给第三匪金水，该假金水可同窗接力。完整后续计划继承v35。
- 公开真实查杀：离线核实报告者为警察、报匪与其已知的真实验人一致。策略不能读取裁判目标角色。目标已死亡的查杀不能混入“可执行真实查杀”。
- 跟票／采纳：仅指实际票与声明目标一致，不等于认证来源。
- 旧事实仍在历史／今天有资格成为建议／最终实际票，三者分别记录；死亡不认证来源，不恢复机械轮出。
- 金水来源链：谁在哪天给谁报好人、来源是否存活、是否在当前观察者处被排除、当前建议及接力是谁。身份、归票资格和信用不是同一个指标。

## 审计问题与方法
1. q50公开可执行真实查杀后，当日平民有多少实际跟票；未跟票是PK限制、私人反证、其他正式归票、来源冲突还是同池排序？
2. 次日来源死亡／仍存活后，旧报告是否仍在历史，是否因时效不再作为当前指令，是否被新验人／正式归票替代？不把旧目标已出局当作遗忘。
3. 验好人后：警方内推、金水普通accuse、金水relay、最终票分别如何形成；有无同一发言slot相互冲突的动作？
4. 警察day2起是否在无活匪悍跳时也自动公开，续局公开机制是否限制了第一日q的解释？

审计器只调用原策略并记录当时Observation与解释，不改变返回动作、不额外抽随机数。所有旧对局逐一匹配v35完整transcript哈希和终局；新批每单元3个预定种子独立用原API重放。好人票验证合法、私人已知匪优先、私人金水不误投；解释器不读取隐藏角色，离线评价才加角色标签。

每轮公开历史只存一次，角色可见私人事实和实际票分开存。完整细节仅对说明案例重放保存，主输出为每局／每日过程汇总。重点旧例固定207000002，另按“真查杀未获多数”“首日成功后终局失败”“普通accuse与relay不一致”等类型首例选读，均为事后说明，不是新增确认性证据。

## 统计边界
新鲜确认批预设每个匪条件q0→q50，两个指标最终好人胜率、首日出匪，共4项同时95%配对翻转Clopper–Pearson+联合界。历史审计只描述，不重新称为独立复现。重复报告按日与目标合并，不能把相关玩家票当独立样本。

额外一致性检查：读取既有v35 q100记录，q50已实际回应时，两者应有同一报告和完整轨迹；这里只是已有哈希匹配，不声称重跑全部q100。q0/q50同首夜对照检验完整策略效应，不把终局差异全部归于暴露这个单个中介。

## q的后续定位
q可写成依据信息集I的条件概率q(I)，或由少量可调整参数控制；不追求永久固定百分比。首验结果、公开来源、发言顺位、警队可用人数等合法条件都可成为未来输入，本轮不拟合。“动态q”本身不保证均衡，仍需训练／留出、双方反制和策略边界验证。

本轮先给可解释的机制证据，再决定是否修接收器、统一发言动作或调整续局，不能在同批发现问题后立刻改规则追胜率。
