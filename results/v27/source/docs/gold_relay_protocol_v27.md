# v27 冻结方案：金水接受委托与接力归票

本文件在正式开发/验收模拟前冻结；2026-11-01。不是均衡求解，不选 q，不使用信用数值或票型学习，不加入金水假跳挡刀。标准4警4匪8民；其余规则和 v26 相同。

## 策略与参数字典

- `base`：v26 的 `aligned`，警察保留真实验人、内推；知道活匪时明确归票并据私人事实投票。无委托。
- `fixed`：沿用 base；公开报验人的警察在没有直接查杀归票、仅有未决名单时，明确委托尚未发言且自己曾公开验好的非队友。金水通常重申名单第一人；若有名单内私人反证则优先使用，不能明知匪在场却强制投另一个人。
- `local`：相同委托；金水使用自己的 Observation，通过现有信息路由，在名单内重新选择。金水没有警队身份、警察座位表或未公开验人。若掌握的活匪在授权名单外，拒绝受理，保留自己原行动。
- `q0/q50/q100`：仅首日“首夜未死警、首名活警尚未公开、假警先出现且没查杀警队”窄分支中的回应概率0%、50%、100%；其余原有强制/普通发言不变。不是所有局面的总体跳警率。
- `late/decoy`：继承 `safe_late` 位置刀 / `posterior_decoy` 位置伪装刀；不改刀法与验人。
- `near/far`：首名匪早发假查杀时，选择其后非匪的最近/最远发言位；匪只知道己队，不能区分警民。
- `restate`：原悍跳者活着才在后续轮次重申；死亡后同伴**不接续**。
- `claim`：原悍跳者死亡后，首名活匪可公开接续旧目标；不捏造新增验人。
- 全部匪列使用原有 team 投票；本轮不新增匪策略，不择优丢掉不接续列。

## 信息、权限与具体动作

只在第2日及以后启动委托，使首日全部轨迹可逐种子核对相同。原警察的 report/shortlist 均保留；同一正常发言槽增加 `delegate(B, [C,D])`。A必须在此前亲口给B报过真实金水、今天自己报过验人，且B尚有正常发言机会。只委托已验好的非警队队友，不凭上帝身份选平民。真正警察根据私人验人可知其非匪，但公众不因此认证A。

B在自己的普通发言槽接受时新增 `relay(C, source=A)`。不新开一轮、不安排额外警察跳警；新增声明内容是本轮干预的资源成本。授权只限当天、单层、名单内；不递归委托、不允许名单外改归。多来源同时委托时保守拒绝，不靠“谁说得晚”决定。

每名旁观者按自己的信息检查：A是否已被自己反证，A此前是否公开验好B，委托是否在接力之前，当天是否存在有效接力。A后续亲自发布新归票、内推或委托则撤回旧授权。接力解释成**A原建议的替代值**，不新增一个独立“警察来源”、不双计支持，不把B直接认证为真好人。已知匪优先、私有好人保护、公开金水保护、PK合法候选限制均由原路由保留；若目标不在PK名单，不强行投非法票。不认证死亡身份、不恢复机械轮出。

例：A今天报“昨晚验5好，内推3/7；我此前验好的B，请你稍后在3/7中定一个”。B没有收到警队私有信息，只能按自己掌握的信息选3或7，或在出现私人硬冲突时拒绝。公众可把B的有效接力当作A授权的单一归票；并非所有人必须无条件相信A。

## 预设比较与统计

9好人行 × 8匪列，72单元；开发每单元256局，种子182000000起；验收每单元2048局，种子183000000起；调试使用184000000起，不与正式样本复用。两阶段共165888局。所有行列同一 seed 共用发牌及按决策键固定的随机流；不保证后续轨迹一致。比较前核查首日全轨迹相同。

q50三对比较（base→fixed、base→local、fixed→local）×8匪列构成同一个24项主要比较族。按成对胜负翻转的两个边际二项率，使用Clopper–Pearson区间和union bound给同时95%区间；不把零翻转写成总体严格相同。q0/q100为预定敏感性，不择优宣布最佳比例。报告无条件全局胜率、委托/接力覆盖、投票变化、目标身份（仅裁判事后统计）、警民分票描述；有利分支不替代总体估计。

开发集不用于拟合参数，只检查流程；不查看结果后更改策略再复用验收。不得因低覆盖或不显著追加种子找正结果。

## 预设验证及边界

人工验证：非法模板；委托前无公开金水；受托人在委托前已经发言；多来源；被查杀平民私有反证；范围外拒绝；后续撤回；PK；相同Observation换隐藏角色不变；来源死亡不自动认证；影子指令不新增警源。冻结前跑适当测试；冻结后核查资产哈希、所有单元计数、异常标志、每单元首/中/末样本的无审计器重放，及 base 对 v26 兼容。

案例按固定顺序选：每个刀法×接续模式下，q50 local相对base的首个胜转负、负转胜，以及首个确有接力且改变票的seed；同一案例只记一次，不按故事好坏筛选。样例是机制解释，不是独立确认样本。

当前仅真实警队会发委托，匪方可维持原有回应或不接续，**尚无假金水+伪造授权的专门反制**。观察者可拒绝已反证来源，但此实验没有证明授权能抵御所有伪造。未经反制不能把“金水归票权”写成无条件认证。顺序限制、已公开同来源真金水、授权名单与仅day2+均可导致低覆盖；负结果应先区分没机会、未采纳与采纳后无增益。后续独立研究：名单外改归条件、首日接力、可持续委托、伪造授权、金水假跳挡刀及其对现有真警信息逻辑的影响。
