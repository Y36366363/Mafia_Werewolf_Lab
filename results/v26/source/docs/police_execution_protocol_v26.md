# v26：警方执行归票与来源条件票型试验（2026-10-31，正式训练前）

## 字典、单项比较与顺序

- `legacy_q0/q50/q100`：v25的gate接收规则、双修复、私人记忆原样；q为0/50/100%的既有单警可选回应节点。不是信用或全局跳警率。
- `aligned_q0/q50/q100`：保留真实验人和原内推，在第二天起已经报验人的警察自己的普通发言扩展里，若存在私人已知活匪，补一句“今天出X”。X按原本私人已知匪排序选择。警队在投票时，只要该合法目标仍是私人已知匪，就跟随当天首个真实队友的明确执行目标；否则按原规则，尤其PK不能投候选外的人。旁观者不会被告知来源是真是假，仍通过v25建议路由接收accuse。验人报告不等于当天执行目标。
- `history_q50`：仅在aligned基础上，加入下述来源条件票型计数；这是预定小试验，不根据主实验的训练数字决定是否运行/晋升。
- `*_team`：原v25匪队投票；`*_bus`：只在两个预定条件late_far_claim、decoy_far_claim加一个伪装回应。最后发言的存活匪若从已公布实时票数可证明队友无论剩余票怎样投都必然被放逐，则可以跟票队友，不改变当日放逐对象。这只是不增加当日放逐损失的倒钩，不是整局零成本/最强反制。
- late/decoy、near/far、restate/claim均继承v25含义。不是按真实警民标签选目标。

首先比较aligned−legacy，随后单独比较history−aligned；不揉成一个改善数字。主实验6行×8原匪列48格；小试验增加history在两个claim条件及两种投票下4格、aligned对应bus两格，共54个实际单元，不是全7×10矩阵，不求均衡或GTO。

## 执行归票的信息与预算

采用已有同一次发言扩展容器：**原report和shortlist/扩展保留，再加明确accuse执行字段**。不新增发言轮次、不招募第二名真警、不改发言序；增加一条声明内容是此协议的干预之一，不声称与旧策略语义预算相同。动作模板对匪同样合法，当前匪仍能重申/接续并冲票，未声称已学最优回应。

只从第二天开始，保留首日跳藏比较。不是强迫“最新报5就投5”：多匪已知时，报5、明确今天出3、实际投3可以一致。分别统计“验人报告与票不同”（可合法）与“有合法、私知匪的执行目标却投别处”（目标为0）。姓名只由警队自己的互认确认，平民没有隐藏警队名单。金水接力归票本轮尚未加入；不把所有被报金水者自动认证成好人。

## 票型计数：值、时点与优先级

仅使用Observation中**已经完整公布**的vote/pk_vote；忽略本轮尚未完成的live票。同一日最新完成轮次覆盖首轮，每名投票者每天最多计一次，弃票记0；不是因“改口/改投”本身加分。

从历史投票时点的保守信息前缀重建观察：只用当时已有验人；排除同日白天被放逐者事后遗言；普通首投不能读后来的PK发言。PK则可读PK发言。后续新验人不回填成过去已知。这一版刻意保守，后续可以独立研究合法的回顾更新。

对每张历史票：
1. 投观察者当时私人已知匪：−1（降低对投票者的怀疑排序）。
2. 否则投私人已知好人：+1。
3. 否则跟随被该观察者合法反证的来源之当天目标，且没有未反证的警察声明来源也提同目标：+1。
4. 其他/弃票：0。

每个+1/−1是人工等权的一个“日证据计数”，不是概率，不是校准信用；每日最多一项，不按重复声明叠加。累计范围[-已完成天数,+已完成天数]。只在原建议池/冲突候选/位置回退有至少两个可选目标时，按计数更高者先投，同分沿用旧排序；不越过金水保护、不覆盖私人已知匪、不打破单一明确建议。来源信用仍冻结。这是来源条件规则更新的小试验，不能称学得最优信念。

公开金水不直接变私人已知好人；死亡不翻身份，不能按真实放逐身份自动加减。普通平民往往没有足够信息为别人确证阵营，覆盖不足也应如实报告。匪可倒钩，本轮小对照仅检验上述一种有保证的跟票，未测试更强主动卖队友/分票/诱饵。

## 种子、统计和停止条件

训练179000000起512局/格；新验收180000000起2048局/格；smoke181000000起。54×(512+2048)=138240次正式模拟。固定全部条件/q/小试验，训练不选策略，不调整q，不搜索seed；训练后保存不选择声明再验收。

主比较q50八个原匪条件aligned−legacy为一个8项族：配对正常近似、Hoeffding、二项Clopper–Pearson正负翻转概率组合（每尾.05/32）；票型四项history−aligned是独立声明的另一个4项族（每尾.05/16）。两族不能合称12项整体95%。CP要求每个比较跨seed iid模拟假设，列共享seed不需独立。全部区间在训练前规定，零翻转不等于总体精确零。

第一天全轨迹、第二夜与第二天普通发言前前缀：同q的legacy/aligned必须一致。aligned/history直到第二天首次投票前必须一致。cross-q首夜/首验/假查杀/机会相同，可选回应节点外不应有跨q终局差。原有两漏洞、已知匪优先、私人好人不投、非法票继续核查；call合法时警队必须跟call，但不能用旧“报验人与票不同”指标宣称失败。

票型若低覆盖或无收益，保持小试验，不晋升为主模型；即使有效也不称抗全部伪装。所有数字是完整模拟的固定策略评价，不是人类真实胜率。本轮不接LLM API；LLM何时适用在结果报告中讨论。
