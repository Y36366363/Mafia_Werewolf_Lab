# v15 活警带队、基础 PK 与位置认知冻结协议

## 核心问题

在4警4匪8民、首夜未死警的分支中，一名活警公开首验结果，并在全员普通发言后给出内推或双人PK名单，能否打破匪方通过首刀位置制造的公共首位目标优势？若警察只使用合法可见的首夜死者、发言方向、警队座位和首验金水计算位置后验，是否进一步回收胜率？

本轮不加入一般化票型学习、公开“怀疑/好人”声明、全员遗言或白天报匪。这些机制留给后续独立消融。

## 时序和公开协议

沿用夜间同时验人与刀人。首夜死者不是警察时，警队按公开发言顺序选择第一名存活警察为唯一发言人；其他警察保持隐藏。发言人公布共享首验的查杀或金水。全员完成一轮普通发言后，发言人可执行一次公开最终归票：

- `report_only`：只报验人，不另给内推；
- `nominate_*`：查杀时归查杀，金水时给一个内推；
- `pk_*`：查杀时仍直接归查杀，金水时给两个PK候选；
- `hidden_naive`：首日活警不跳，作为控制组。

公开投票按发言顺序逐票公开且不可撤回。双人名单下，好人选择当前票数较少的合法候选，尝试形成平票；匪方知道队友，可把票集中到名单中的非队友以破坏平票或保护队友。第一轮最高票平票时，最高票候选各进行一次PK发言，全场再投一次；第二轮仍平票则无人出局。所有玩家可在无法或不愿合法投票时弃票。

这是一套有限、可审计的公共协调协议，不模拟自然语言说服。发言后最终归票在本轮只能读取已经实现的验人声明和普通身份发言；“根据复杂发言内容改归”仍未实现，不能作为结果解释。

## 位置后验及信息合法性

`naive` 内推按首夜死者之后的公开发言顺序选取未被警队确认的座位。`posterior` 内推枚举所有与以下信息相容的四匪座位组合：

1. 首夜公开死者；
2. 警察私下互认的四个警察座位；
3. 首验金水座位；
4. 固定规则和发言方向。

对每个候选匪位组合，计算观察到该首夜死者的似然。公开元策略先验在 `kill_random`、`safe_middle`、`safe_late`、`safe_mix` 四种刀法上等概率；`safe_mix` 内部继续等概率混合五种安全几何。策略不知道本局真实采用哪一列，也不读取未知玩家的警/民/匪标签。最终按座位为匪的后验概率降序内推，同分按公开发言序打破。

该后验是模型内的精确枚举，不是从留出结果拟合出的分类器。它回答的是“若所有人预先知道这组固定刀法可能被使用，死者位置能提供多少结构信息”，不代表现实玩家已经知道真实匪方策略分布。

## 冻结矩阵

主矩阵固定警察使用 `inspect_gap` 首验，避免同时改变验人规则。6种好人协议与4种匪方首刀形成6×4矩阵：

- 训练：每格1,024局，seed 从130,000,000开始；
- 留出：每格4,096局，seed 从131,000,000开始；
- 同一列和阶段共享身份发牌 seed，使好人协议比较可配对；
- 先求训练有限经验矩阵的精确有理数受限均衡并冻结，再读取留出矩阵；
- 留出矩阵的事后均衡仅作漂移诊断。

主要对比分为：活警报验相对隐藏、单内推相对只报验、位置内推相对顺序内推、双人PK相对单内推、位置PK相对顺序PK。每个比较同时报告全体、首夜未死警、未死警且首验查杀、未死警且首验金水四个分支。分支资格由相同开局决定，不按终局结果筛选。

## 独立位置刀确认区块

另使用从132,000,000开始的8,192个全新 seed，在 v14 原规则（首轮平票直接平安日）下固定 `inspect_gap + hidden_naive`，仅复核 `kill_random`、`safe_middle`、`safe_late`、`safe_mix`。该区块不训练、不选择候选、不求新的机制最优策略；它只检查 v14 大效应能否在新种子上复现。

## 解释边界

模拟胜率是固定启发式代理人在研究规则中的结果。位置后验的数学计算可以精确，但其输入的元策略先验仍是研究假设。矩阵线性规划只证明采样经验矩阵上的受限解；留出收益有Monte Carlo误差，候选池外仍可能有更强反制。任何结果都不能称为完整杀手游戏GTO。
