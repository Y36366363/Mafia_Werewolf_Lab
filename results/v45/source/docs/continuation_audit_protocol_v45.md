# v45：六局协调损失的续局审计协议

本轮只审计 v44 已读数据，不训练、不新增胜率比较、不改变策略。
对象是 `copy_shared → copy_both` 中全部六个由胜转负的种子；同时重放不启用共同查杀的两个对应组，共24局。
选择依据为历史终局结果，因此它们是失败机制案例，不是随机样本，也不是新留出集。

## 冻结与核查

运行前冻结本协议、配置、审计器、运行器和测试；核对 v44 及其父版本冻结源码。
被动记录每次发言者自己的 Observation、输出和每次投票的依据，不能读取全局角色。
完整对局结束后才为分析附上裁判身份。24条完整重放哈希必须与 v44 原始记录一致；确认六局覆盖全部损失而非另选例子。

## 事先指定的审计问题

1. 两组首次在何时改变公开行动？第二天究竟换出了哪名匪？
2. 第三天夜刀、真实验人、公开验人、正式归票、平民实际票分别是什么？
3. 是否存在已知匪不投、警队分票、共同查杀未执行、死者被认证、或者平民读到未公开私人信息？
4. 留下哪名匪是否改变接续发言资格及内容？复制是获得额外信任，还是仅取消唯一匹配／满足发言资格／回退位置排序？
5. 真警是否重复旧查杀而未公开已有的新金水？公开信息与私人信息必须分开分析。

## 局部诊断，不作为策略晋升

对协调组第三天，若发言真警报告的并非当晚最新验人，且最新验人对象仍活着，做一个只读“同一投票时点”的影子计算：
在原有一个报告字段中替换为该警察当时实际知道的最新验人，保留正式归票及所有其他发言；重新计算平民首轮票，警匪票保持原记录。
检查私人反证、合法候选与共同查杀优先仍生效，报告票数及最高票集合。这个诊断允许警方使用自己的信息；平民只能看到替换后的公开报告。
它不是完整续局实验，不含匪方对新发言的事中回应，不估计终局胜率。六局是选择性失败案例，不能把局部纠正率外推。

## 过程评价

保留终局0/1为主要任务目标，同时记录每日夜刀、出局对象、警匪存活数、实际信息发布、警方归票跟随情况和首次关键分岔。
“多出几匪”不定义为新的效用；不声称某局“只差一步能赢”或“无论如何找不到最后一匪”，除非另有完整反事实续局或可达性证明。
本轮不改变 q、信用分、公共共同查杀、验人策略、匪方策略、PK、遗言或归票选择。
