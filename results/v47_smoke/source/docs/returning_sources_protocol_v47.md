# v47 两名原对跳者续报的条件实验

主板4警4匪8民。筛入条件为首日普通发言恰有两名报验人者、报告对象或结论不同、两人首日投票结算后仍存活。由公开记录筛选，不按真实身份或终局筛选。全部方案用同一份首日；筛查在第二夜决策前停止，未入组种子只计覆盖。

自然夜刀通常优先杀公开来源。四组在第二夜使用相同约束，若原刀会使对跳者不能发言，从仍活着、并非匪队、也不是两名来源的玩家中均匀改刀。其他夜沿用原策略。两名来源在第二天各一个普通报告槽，真警报当晚验人，第二天其余警员不公开跳警。两名来源之外的行动沿用原策略。第二天首轮之前行为在同对手的两组逐局一致。若同一来源在归票时没有合法建议，双方比较规则均让位给原接收器。

匪方在第二夜已选自己的刀口后，以首日发言、首日实际第一轮票、公开存活名单及匪队身份准备一个报告和一次归票。两种对手尽量选此前未公开报过的非同伙座位，排除自身拟刀玩家，同样以1/2概率报假查杀（否则报金水）。普通对照随机抽候选，归首日原建议（若非法则首个合法目标）。准备策略有查杀时归查杀，报金水时归原对跳者，优先选择能避免当日金水与昨日实际推动目标冲突的候选；无法改写昨日票。两组匪队都可跟随后当日公开归票，PK候选不允许时回到原投票。没有读取真实验人，也未见第二天遗言或真警发言。新目标有可能与未知真验人偶合；不使用全局标签强制不同。

两套接收器只处理第二天平民首轮票。当且仅当恰好这两个合法来源竞争不同归票，接收器原本仍在两个来源间未决时，对照按唯一新座位优先。试验先看三项公开迹象：昨日报出的正式目标与已结束的第一轮实际票不同；今日把昨日公开且实际推动的人报金水；今日正式归票既无本人历次公开查杀支持，也没有直接选择原对跳者。仅当一方标记是另一方的严格子集时优先采纳较少的一方；其他情况回到仅看新目标规则。标记是可解释的行为信号，允许诚实来源因新信息而改判，不能当身份认证或概率。无唯一新目标时原规则回退。共同查杀、私人反证、金水保护和合法候选优先，PK保持原规则。当天实际票用于赛后检查，不用于同轮平民选择；昨日第一轮实际票可用。共同查杀及接续预警沿用v46，冻结q=1/2与既有信用设定。

预检后核对假金水候选，排除两种策略可能使用的当日归票目标，确保不会同一天给一人金水又归票出他。修订前的预检和未用于评价的运行不进入证据。正式运行使用236000000起连续8192个新种子，不追加样本。修订后预检使用237000000起96个独立种子。固定条件样本内，对两个对手各报告一项配对终局效果及同时95%区间，另外报告首日筛入、夜刀更换、报验组合、触发和改票、第一轮实际跟票、第二天出人及事后来源角色。若条件或触发覆盖不足，发布原分母。历史测试结果仅作背景。
