# v12 冻结协议：首夜死警声明与自刀可信度

日期：2026-10-17。主配置为4警4匪8民。本轮回答两个分开的研究问题。

第一，首夜自然刀中警察后，在完全相同的首夜状态中，只改变死警遗言：沉默、报告真实验人；若首验为好人，再加入“不给真实验人、改给一名存活警察队友金水”。首验中匪与首验好人使用两个分别筛选的自然状态队列。筛选标签仅由裁判用于建立评价队列，不传给策略。四项预先指定的终局胜率配对比较为：中匪真报减沉默；验好真报减沉默；验好队友金水减沉默；验好队友金水减真实金水。续局中活警首日隐藏，第二日起由一名活警代表释放当前结果；平民按冻结规则接受死者报告。匪方不自刀、不作活体悍跳，夜间优先公开声明者，否则随机。

第二，从首夜行动前比较普通刀与四种100%自刀计划：自刀沉默、自刀死匪随机向未知非匪发假查杀、自刀给存活匪队友假金水、自刀给随机未知非匪真金水。最后一种不能写成“指定平民金水”，因为匪徒只知道对方不是匪，不能区分警察与平民。自刀沉默是机制负对照，即使预计较差也保留，用于分离牺牲成本与声明收益。

好人回应池固定为：相信死者且活警隐藏；不相信死者且活警隐藏；相信死者且一名活警在确认死者不是队友时公开反驳；相信死者且四名活警全部公开反驳。被假查杀的平民知道自己不是匪，警队知道死者不是警察，但其他平民看不到这些私人事实。即使出现五名公开反对者，公共历史也只显示声明和站队，不能自动认证这五人都是好人。

自刀矩阵先在1024个训练种子上求有限4×5经验收益矩阵的精确有理数混合解，再把该混合冻结到4096个全新留出种子。留出报告固定混合的下界、上界和间隙，同时给出留出矩阵的事后诊断解。这里“精确”只指对已估计的有理数矩阵求解精确，单元胜率仍有蒙特卡洛误差，策略池外仍可能存在偏离。

原定正式死警评价从111000000扫描、自刀训练使用112000000—112001023、留出使用113000000—113004095。首次执行后审计发现，`hidden`错误地同时关闭了第二天以后的活警报告响应，使首日反驳开关混入续局差异；该批结果整体标为无效诊断并保存在`results/v12_invalid_pre_fix`。第二批使用114000000、115000000和116000000种子块；审计发现赛后指标错误地把首日被放逐者遗言当成首夜死者遗言，胜负路径未受影响，但目标身份分解失真，因此整批保存在`results/v12_invalid_metric`且不进入结论。修正后死警评价从117000000扫描，自刀训练为118000000—118001023，留出为119000000—119004095。预检使用110000000附近的小样本。每次重新运行前提交源码；不根据无效批次的胜率选择策略或样本量。

主要结果为好人终局胜率。辅助指标包括首日放逐匪／警／民／无人、第二夜刀中警察、首日公开报告人数、死者报告目标真实身份，以及假查杀目标为平民或警察时的描述性分层。处理后分层不得解释为新的随机因果效应。

本轮不搜索自刀概率，不声称100%自刀会出现在完整均衡中，不把有限矩阵均衡称作GTO，也不把固定话术下的“五人站队”写成现实玩家必然识别。
