# v29 冻结方案：内推语义 × 来源冲突的2×2接收器消融

2026-11-03，正式开发/验收前冻结。先使用v28旧案例验证实现，再用全新种子测试。主板4警4匪8民。没有新匪策略、没有策略扩池或均衡求解。

## 策略与参数字典

| 行 | 死警新增内推/委托 | `typed_advice` | `conflict_guard` |
|---|---|---|---|
| `anchor` | 无，v28 reference | false | false |
| `plain` | 有，v28 notice | false | false |
| `typed` | 和plain相同 | true | false |
| `guard` | 和plain相同 | false | true |
| `both` | 和plain相同 | true | true |

两个开关均为布尔协议选择，不是身份概率/信用分。

- `shortlist`：怀疑备选名单，尚未承诺今天必须放逐其中某人。
- `claimed_hit`：未经认证的“我验X是匪”声明；来源若真则是事实，但公众不能直接当私有已知匪。
- `execution`：明确“今天出X”的建议或合法受托接力；这是执行意图，不等于验到X是匪。来源自己的明确归票仍优先于自己较早的查杀目标。
- `typed_advice=true`：含备选名单的重合不能直接获得“明确共同建议”优先级，先进入原有来源冲突比较；没有可比较冲突时仍可把名单重合作弱的备选破同分。不删除内推，不自动相信更强硬的声音。
- `conflict_guard=true`：如果参与合并的来源之间有公开报告不相容边，不能仅因建议有交集就优先接受共同目标。保留来源/冲突/建议，继续原有比较及备选处理，不认证其中任何人。

这里对两类不同机制分别开关。实际池里若它们阻止了同一路径，可能出现两个单开和双开行为相同；这应解释为覆盖重叠，不能将收益相加，也不能据此证明整个游戏中二者等价。人工测试另含“互相冲突但都给明确目标”的合法声明场景，使语义开关与相容性开关能被区分。

列保持v28的8种：late/decoy为safe_late/posterior_decoy位置刀；near/far为早悍跳假查杀的后续非队友近/远位；restate指原人活着重申、死后队友不接续，claim指原人死后队友接续跳警；team为原队伍投票。所有列首日都早悍跳，不接续不是首日不跳。

## 范围及控制

只在第1日、观察者本地存在有效的首死者金水委托时启用新接收器。触发条件是公开消息和自己能否反证来源，不把真实首死角色标签交给策略。事实、可用动作、原RNG、遗言、验人、刀法、后续接收及跳藏都不变。

plain/typed/guard/both同局第一日投票前的**全部公开发言轨迹必须相同**。主实验只改如何合并已看到的信息，不新增任何信息或发言资源。anchor少了新遗言名单/委托，是净效果参考，不属于2×2等信息对照。

首日新增金水最终归票槽本轮不启用（dead_gold=notice），以免稍后把软名单变为正式归票掩盖接收器效果；不是删除金水接力：既有第2日起活警接力保留，v28的首日金水接力/有依据改归代码保留，类型识别也测试合法relay的明确归票语义。接力恢复到主实验需下一轮独立验证。

q0/50/100仍为合法策略参数；本轮正式主样本固定q50。因为只在首夜死警报金水分支产生新干预，原可选跳藏节点不出现，三档在该分支应逐局一致，人工和控制测试验证，不重复跑三档当三份独立证据。不重新选择q，不宣称本轮测出了三档总体最佳比例。

私人合法已知匪、私人已知好人、PK合法候选、来源反证、死亡不翻身份、同一遗言预算及原次日起不机械轮出规则均保留。这里延用的“比较存活冲突来源”是行动策略，不是证明活来源为匪；原来源死亡不认证任何人。信用冻结、票型学习冻结。

## 两个开关的具体区别

例：A遗言验好B，只内推C/D；F报C是匪。旧规则把C当共同建议。typed先看到“备选+查杀”不等于两份正式归票，转入原冲突比较。guard检查A/F的首夜验人叙述是否能同时为真，若不相容也阻止该共同目标抢先。这两种单独修正可能都恢复原参考。

若B已合法接力出C，且F也报C是匪，那么A的受托执行建议和F查杀都是单一明确目标；typed不再仅凭语义阻止它们合并，guard仍可因A/F报告叙述不相容阻止。兼容来源的明确建议及无冲突的软备选仍可正常使用。该额外场景用于方法校验，不追加到主矩阵。

## 样本与主要比较

5行×8列=40单元，开发188000000起128个seed，新验收189000000起2048个seed，调试190000000起。正式87040次实际模拟，跨策略配对的2176个基础seed；不把所有调用当独立发牌。

按同一匪列、同一seed连续跑5个接收器，以复用确定性位置似然缓存；每个版本都实际完整模拟，绝不复制“推测等价”的结果。分组执行方式须与独立/无审计器重放相符。

预定五对：plain→typed、plain→guard、typed→both、guard→both，以及anchor→both。主要评价范围为首死确实是警察且首验好人这个干预前条件；该裁判mask所有版本相同。每对×8匪列×两个共同主要指标（终局好人胜、首日出匪）共80项，Clopper–Pearson配对正/负翻转边际区间+union bound给名义同时95%，尾部α=.05/(4×80)。不根据终局或过程选mask。

总体率、首日出警/出民/平安日/PK、次日结束前累计出匪数及警存活数、语义/冲突阻断和改票数、同终局但异过程局数均报告。后两种资源指标只是过程量，不是局面胜率估计；过程不同不自动是优势，优势也不能由这几个指标完全衡量。

有两个开关的交互点估计（both−guard−typed+plain）；如给区间，只由已同时覆盖的两条边区间相减得到保守范围。负交互可表示重复覆盖，不能误读为两项修正互相伤害。总体比较作描述，不另挑显著数字。终局不显著不等于严格无效。

所有候选在开发前冻结；开发不选阈值/q、验收不再优化，不新增seed或匪列。本轮匪不知新接收器也未针对它训练；无自刀/假金水授权、无首日沉默对照，所以仅为冻结策略评估，不是抗所有反制或完整GTO。
