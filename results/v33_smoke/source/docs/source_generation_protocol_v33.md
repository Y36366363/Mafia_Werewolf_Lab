# v33 冻结协议，2026-11-07

问题：补足自刀后活匪配合与真警条件回应，使相同公开声明能够在更多来源解释下被生成；同时保留终局指标衡量暴露的长期代价。不是训练来源信用，不是求GTO，不把平衡理解成强制轮出。

## 行动字典
- hide：完全复现v32 restrained；真警队友已遗言报告后，不再普通轮补跳；其他分支继承q50规则。
- self：已有活警队友公开则不再新增普通轮警察；自己在此前被外部来源查杀且仍有普通轮发言机会时，保留真实验人回应；真警队友已遗言时其他情况隐藏；其余保留原q50。与hide差异包含对非首位、本人被查杀的及时防御。
- available：同样最多一个普通轮活警公开；只要此前已有非警队来源声明，第一名实际仍有普通轮发言机会的警察就报告真实验人。没有外部声明时按self；不加场外插话，不改PK发言。不是全队对冲。
- late_old / late_copy / late_quiet：v31已有safe_late位置刀＋远位假查杀／复制死者金水后错误归票／首日静默；三个完整普通刀计划原样保留。为隔离生成机制，本轮不同时改变刀法；伪装刀旧证据仍保留，后续迁移。
- self_quiet：原false_grant，自刀假金水、名单、授权；活匪首日静默。
- self_copy_early / self_copy_late：同一自刀开局，第一／最后一个活匪在自己普通轮复制死者金水，正式错误归票；其余活匪静默。early/late是匪队内部顺序，不保证全场第一／最后。
- self_hit_early / self_hit_late：同一开局，第一／最后活匪向合法非匪发假查杀并明确归同一目标；目标不等于死者金水。匪知道对方非匪，不知道其警／民身份。
- self_copy_team：死匪把首个活匪报金水，再由另一个活匪复制这个金水并错误归票；用于覆盖两来源均匪且所谓共同金水也为匪的解释。死者和接续者不把自己报为金水。
- q=50%只继承原局部适用分支；本轮不选择q。所有普通轮新回应保留真实验人、原内推和明确归票；投票仍用v31 aligned，信用冻结，私人反证和PK合法性不变。

## 冻结设计与统计
3警策略×9匪计划=27单元；每单元训练256、全新留出2048，合计62,208次完整终局模拟；2,304个不同发牌种子跨条件配对，另54局smoke。训练不拟合行动器、不选赢家；留出后不调规则或换种子。先存源码、配置、协议和哈希。

预设主要比较hide→self、self→available，9条件×2比较×终局胜率／首日出匪=36项同时95%区间，配对正负翻转Clopper–Pearson加联合界。主比较所有发牌，首死真警验好人只作描述分层。进程指标同时记录首日活警公开数、第二夜实际死警数、第二日开始存活警数、完整终局，防止以首日出匪替代长期胜率。不做事后中介因果归因。

## 来源支持审计
固定1号存活平民，在首次投票前采集其合法消息，剔除逐票事件。另截取首个活报告出现时前缀：首死者必须报金水。首报告类型同v32：hit/copy/other_clear；全场顺位1–7/8–15预先分箱。也记录完整发言后共有多少活来源，避免仅看第一人。

离线裁判标签分开统计死／活来源P/M、金水真实角色；不传给行动器。每单元前4个合格前缀做v32必要身份约束枚举（非完整生成似然），同时记录该段的实际来源组合。比较新增真实生成的M/M、假共同金水，以及早晚回应的机会覆盖。表中频率不解释为来源后验；自刀总权重与各配合概率尚未学习。零样本不当作不可能。

“打平衡”本轮仅做信息前提审计，不修改投票。若死／活来源可能均真、均假，或没有相互排斥的主张，就不能把“出活者”说成保证一警一匪。即便采用首日风险控制策略，死亡仍不认证，次日不得机械续轮。被多名未经认证来源共同报金水，也不能逻辑保证该人是真金水。未来若测试，单独冻结首日限定动作及后续更新规则。

每单元每阶段3个预定种子重放，hide普通刀与v32 API直接对照；验证所有新增行动只用Observation、无普通轮第二警察新增、无场外回应、私人反证及PK约束保留。按预先类型选少量首例作事后解释，不作为新增独立证据。
