# v18 真警回应悍跳与金水来源约束：冻结协议

日期2026-10-23；主配置4警4匪8民。首要疑问：当普通发言轮仍有真实警察尚未发言时，单人回应已知假警是否改善好人终局胜率，能否成为当前受限池中的默认策略？本轮不声称证明完整游戏中必然最优。

## 底层声明假设

本轮排除平民假跳，真警公开验人均如实（允许对自己知道的好人作真实非匪声明），不把匪报金水。假警由匪徒担任。保留该限制不是证明好人假跳无收益；若以后开放此类动作，逻辑约束必须重审。

在这些假设下，A报B金水蕴含 A为好人 ⇒ A为真警 ⇒ B为好人，所以在任何一致证据E下 P(B好|E)≥P(A好|E)。别人额外查杀B不会推翻这个不等式，而会改变不同真假声明假设的权重。投票候选中来源A与金水B都存活时，优先考虑A；多条相互假金水造成环时不让保护链清空所有候选，环内保持风险排序及公开同分规则。该程序优先级不越过本人私人查杀、自己不能投自己或PK候选限制。

两支声明队伍共同给C金水：只有假设集能保证至少一个来源为真时，C才被逻辑保证非匪；本轮允许两个假来源、真警仍隐藏，因此不无条件认定共同金水必真。

## 策略名称字典

五个好人行均使用二人非约束内推、新发言时序、equal首夜位置模型、inspect_gap，关闭票史评分，以免把先前40%特定票型利用混入回应问题。

| 行 | 来源推理 | 遇假警动作 |
|---|---|---|
| fixed_keep | v17信用0.5/0.75，采纳门槛0.6 | 延续原发言，不额外对跳 |
| fixed_answer | 同上 | 由下一名有发言机会的真警回应 |

keep不代表警队从不报验：首夜幸存分支原有发言人与后续共同验人报告仍会出现。它只不因看到悍跳而增加额外对跳。

## 回应动作与信息权限

真警通过警队互认知道外队警察声明不真；普通平民无此能力。轮到普通发言时，若已看到外队report或police且随后还没有警队成员回应，就公开police角色声明，附一条accuse指出假声明者；该指认不是新验人结果，不能伪装成查杀。若后续出现新的假声明，可以再次形成一个回应回合。没有轮到警察的机会时不添加出轮次发言，不改变游戏规则。self策略只针对本人被公开查杀。

投票时私人查杀优先；实际已回应的真警反对可见假声明者。普通平民在fixed版按旧信用处理，在logical版按下面的组合参考信念选择高风险目标，不因最新发言自动覆盖。响应者只是候选真警之一，没有自动最高信用。记录当日首个假声明之后是否还有真警发言机会，避免把无法回应当成选择沉默。

## 组合参考信念与数值来源

logical版枚举已出现声明者及被报目标的可能匪位标签，按均匀Nature发牌完整角色分配的数量加权：真正声明者必须是警察，假声明者必须是匪，真警金水非匪、查杀为匪，观察者知道自己是平民；其余身份分配按4警4匪8民计数。所有可见report/police（含此前遗言）参与一致性；重复声明仅作为同一约束，不重复乘似然。

分数是该参考假设集中的匪方边际概率，非信用0.5/0.75的累加。它没有使用不同角色选择声明、回应或沉默的战略似然，也没有把未回应解释成真警不存在；因此不能称为对真实策略生成过程已校准的贝叶斯后验。首夜位置分数只作为同风险目标的排序参照，没有把同一发牌先验重复相乘。警察投票继续使用合法警队私有信息。

## 六个匪方列

safe_late：争取末段发言控制；posterior_decoy：首夜抑制旧位置后验，后续无公开声明者可追时用late。分别配三种发言：

- quiet（无主动悍跳）：仍公开怀疑、保护队友并集中投票，不表示无行动。
- counter（末位反查杀）：最后一名匪看到警察声明后假报该声明者为匪；可能在最后一名真警之后，无法当轮回应。
- early（首名匪主动假查杀）：当日第一名匪直接假查杀发言顺序中的首位非队友，不读取其警/民身份；产生更多可被真警当轮回应的案例。

同一刀法三种发言的首夜状态完全相同；同一匪方列各好人行共享种子。非匪真假身份不交给匪方策略。
