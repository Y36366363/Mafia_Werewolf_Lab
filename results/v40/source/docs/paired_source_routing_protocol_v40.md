# v40 冻结方案

2026-11-14。4警4匪8民，四组共同沿用 v37 首日保留查杀候选、v35 的 q=1/2 及 v38 的固定普通后位刀（late_copy）。数值信用继续冻结。首日出匪及完整轨迹是配对校验。

- `merge_control` 沿用 v37 的续局建议合并。
- `source_exile` 对照 v39 的来源放逐思想。第二日起，若平民本来会合并建议，恰有一对已申明的正式对立活来源、无其他历史活冲突边、两方今天最后的直接正式归票各有不同目标并获现有规则接收，则进入配对。两名来源及两份归票目标都须符合个人私知保护、金水保护、自投限制及实际PK名单。仍由原排序选一个来源作为放逐目标。
- `call_mapping` 在完全相同的资格和排序中，先算出原本要出哪名来源，再跟另一方当天的正式归票。举例，旧排序原要出A，则按B的归票出C。来源排序不使用模型外身份。资格不足沿用原投票。正式归票通常可与查杀分开，本实验以当前正式归票为准，未把软内推、接力转述或只存在历史的放逐建议视为直接正式归票。现有接收后的目标仍与直接归票相同才可参与。
- `succession_report` 好人使用原合并。匪方在 v24 既有同一接续条件、同一普通发言槽内，将“我是警察”换成“验旧存活查杀目标为匪”。原有归票扩展继续指向同一目标。它是重复验人说法的假报告，有报验人资格及报告冲突两条可能路径。源声明来自该匪的队友和公开历史，不能读取警民具体身份。此对照与候选映射分开。

在相同的观察里，前两种配对策略的来源选择逐票相同，只有投出的座位映射变化。候选限制发生在个体投票时。首轮票数决定真实PK名单，绝不在模拟器里强制送人进PK。同一份整体最终放逐抽样下，若把出A事件直接替换成出C、其余事件不变，则精确保留分支概率a。这是另一个放逐层干预，不能用本轮逐票映射替代。匪方目标合法性沿用旧策略，此处不加倒钩查杀。

新种子219000000–219004095，共4096组、16,384局。冒烟220000000–220000003，另16局。三项事先指定的配对终局比较是来源放逐→正式归票映射、原合并→正式归票映射、原合并→接续编验人。配对二项边际精确区间以联合界覆盖三项95%。首日日轨迹四组一致，来源映射对照还要求第二日首轮前公开前缀逐局一致，且触发机会逐局一致。记录真警归票的平民票、第二日出警出匪、PK次数、每日放逐身份、接续覆盖和合资格匪建议。全续局及跨接续条件的跟票机会可随轨迹变化，属描述。身份标注只在终局后用于评价。案例使用v39两局及新样本首次终局改变的例子，不参与择优。
