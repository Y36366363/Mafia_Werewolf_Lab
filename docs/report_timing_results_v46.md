# v46 报验人时点与警队的接续风险

2026-11-20。4警、4匪、8民，两项独立实验。

## 私人反证

例如11号跳警说“我验到16号是匪”，16号自己是平民。在本次模型的设定下，真警诚实报验人，平民也不冒充警察。16号因此知道11号在说假话，可以投11号。旁边的8号听到的是同一句查杀，但不知道16号的身份，无法照搬这个判断。前一轮六局里，投接续匪的那一张平民票就来自被假查杀的人。警察也有各自能用的私人反证，例如自己知道发言者根本不在警队，或警队真实验人推翻了发言者的说法。

即使每个玩家都照策略执行，这种信息不对称依然存在。面杀可使用的犹豫、口误和对熟人的了解没有进入模型。报验顺序、旧报告和正式归票是模型内可见的线索。同一条公开轨迹能由多个身份假设产生，找到更好的行动规则也不会自动让平民识别全部角色。

## 策略及参数字典

| 名称 | 实际行为 |
|---|---|
| `greedy` 当天票数 | 沿用v44 `copy_both`。从警方已知活匪中，选当前预测能获得最多平民票的人归票。 |
| `lookahead` 接续预警 | 当天票数规则加一项第二天预警。若改归旧悍跳者只多预测一张平民票，其旧假查杀仍可推，且会留下经两名警员公开报告的真实查杀，则保持原归。 |
| `echo_control` 重报对照 | 现有活警报告槽报昨夜真实验人。仍在归票的原悍跳者或接续匪，优先重报自己发言前已听见的活来源报告，没听见则尝试重报当夜遗言，再退回原假查杀。平民用原接收器。 |
| `echo_timing` 重报对手＋时点 | 对手和报告预算同重报对照，平民用下述时点规则选归票。 |
| `distinct_control` 新编对照 | 同一报告槽改为优先编一个此前未被公开报告的非同伙座位，并报假查杀；按当日发言顺序选第一个，找不到才退回重报。平民用原接收器。 |
| `distinct_timing` 新编对手＋时点 | 对手和报告预算同新编对照，平民用同一时点规则。 |
| `q=1/2` | 特定首日警察可选回应节点的50%抽样概率。六组继承同一设置。 |
| 信用与共同查杀 | 数值信用继续冻结。合法的共同查杀优先于时点规则，私人反证、金水保护、PK候选约束按既有规则处理。 |

预警中的一票是预测人数之差，属于本轮预设的狭窄测试范围。警察只读自己的验人和队友身份，以及当时已发生的公开发言。预警没有预测谁会接续或会刀谁，也没有使用未来验人。预警应用于归票选择，发言中原来的验人字段保留。

时点规则只调整第二天起的平民首轮票。在恰好两名合资格活来源给出不同合法归票、且原规则仍无法明确取舍时，做两种检查：

1. 两人当天报告完全相同。若在第一名活来源报出前，场上还没有人公开同一句话，则优先采纳先报者的正式归票。如果两人可能都在复述遗言或更早的公共报告，则不依据他们之间的先后给额外优先。
2. 两人此前都在普通发言里跳过警。若今天只有一人报告此前无人公开报过的座位，则优先采纳这名来源的归票。真警在实验中确实报当晚验人，但“座位从未公开报过”只是平民用于判断新增信息的线索，造假者也能做到。报名重复不会直接触发放逐。

警察共同验人，所以真实警员在不同发言里报同一个结果完全可能。同一句话能否被模仿，取决于后报者当时能看到什么。“复制概率低”需要明确条件：独立编造时碰巧同报，与看完以后有意复述的概率不同。规则只给窄条件下的投票优先，也允许先报者是假警。两种对手都保持原正式归票目标，报告字段可以不同。继续使用原有发言位与一名主要真警报告者，回访假警只在原本继续归票或接续的节点补报告。因此，本轮检验的是**仍在场上提交竞争归票的来源**，尚未给每个历史跳警者新增每日发言义务。

## 实验设计

基于 `e371600`。2048个全新种子（231000000起连续2048个）各运行六种固定策略，共12288场。三组配对共享首夜状态和首日完整轨迹。来源时点的每一组配对还共享第二天首轮投票前轨迹。同一对来源实验只改平民的投票规则，警队的归票预测维持原接收器。风险组保留v44报告机制，来源组统一换报当晚真实验人并给匪方配套行动。两区块的绝对胜率不能用来推断其中任何单项改动的收益。

终局用增胜与失胜衡量，三项区间同时控制95%覆盖率。先对两组翻转比例各求精确二项区间，再用联合界相减，结果偏保守。第二天出匪、第三天接续和改票是过程指标。旧六局只用于机制复验，新数据没有用于训练和选阈值。冻结协议、代码、种子、原始数据和哈希见结果归档。

接续预警触发93场。全部换成另一个匪出局，第二天各有93场出匪。第三天接续由93次降到0次，出匪从14场增至48场，终局从0胜增至5胜。原本的第二天跟真警归票计数反而少了93票（12078→11985，分母均12399张可比较票）。这正是实验要量化的取舍：少争取一张当日的票，仍能放逐一个匪，并减少次日接续。全批终局区间仍跨零，接续减少在所测对手下最明确。机制规则针对旧例设计，在六局旧例中确实全部赢回，不能把这六局计入新胜率。

重报对手中，时点规则实际改了230局的1412张首轮票，全部进入“当日活来源先报、后来复述”的分支，优先来源在赛后均为真警。这里报告的是票和对局，重复同一发言的多张票不是独立证据。该对手遇到前面活来源报告时，会跟着复述。由此得到的顺序信号与对手策略直接相关，不能当成先报的一般可信度。相对原接收器，230个过程改变中有160局最终仍输。

对手能另编新目标时，两组2048场轨迹逐局相同。匪方在884局共提出2357次新编报告。同一个时点规则没有额外改票，说明报一个新目标可以让对手绕开“谁在跟着复述”的区别。两组的平民继续交由原接收器决策。新编策略由本轮显式设定，不能据此推断真人对手一定会如此调整。

为区分“有证据但没用”和“规则没有覆盖”，额外逐局重放了2048场新编对照。6568张首轮平民票通过双来源、合法归票与私人反证等前置检查，但没有一张同时满足“两人此前都在普通发言中跳过警”。5742张面对两个新目标，826张只面对一个新目标，但至少一方是当天新来源。**这批完整对局并未测到两名原对跳者都回来、只有一人交出新目标的分支。** 人工测试确认该分支会按规则改变票，也展示了新目标可由假警编出。不能用这个完整对局的零增量判断那一分支在更广发言协议下有多大作用。

## 看得见的对局分岔

### 第二天少跟一票，第三天避免接续

新种子231000220。4号死警、5号真警都报16号匪。5号也知道6号旧悍跳者是匪，对16号预测有7张平民票，对6号预测有8张。两边的第二天都出匪。

- 当天票数策略出6号。第三天12号匪接续6号，继续推15号平民。警方归16号，但15号出局，最后好人输。
- 接续预警出16号。第三天6号仍在，12号没有触发这次接续。警方归6号并成功出匪，第四天出最后一匪。

另一个新种子231000110里，预警也阻止了接续，但留下的原悍跳者仍能误导放逐。两边第三天都出6号平民，第四天各出一名不同的匪，终局都输。它说明“阻止接续”和“平民因此做对选择”是两件事。

### 两份同样的金水，两个不同的归票

新种子231000021。第三天5号真警先报12号金水，明确归1号匪。后发言的9号匪也报12号好人，仍归8号平民。原接收器允许这两条不同归票竞争，最后8号出局。时点规则让六名平民改投1号，第三天正确出匪。这一局第四天又出现一次重报引起的改票，最终好人胜利，不能把整局翻转全归给第三天那一次改票。

新种子231000003有相同的公开结构，但好人最后还是输。第三天13号真警先报4号好人、归1号匪；1号随后也报4号好人，转归13号。时点规则改了六张票，第三天从错出13号真警变成出1号匪，两个版本仍同输。它与上轮的过程观察一致，终局相同也要检查当天保住了谁、收回了什么信息。

## 现在能对你的判断说什么

在模型里，不应给看过同一句话的后报者算第二份独立支持；如果双方都可能读到遗言，两个活来源之间的先后也未必有辨别力。本轮对固定重报策略验证了有限的先报优先，在固定新编策略下则没有识别力。第二天有新报告的要求可以迫使原悍跳者提供可比较的叙述，但一条全新的叙述也能是假的；存活且同报不构成放逐条件。若下轮继续验证，最有区分力的是比较新叙述能否与此前公开承诺、已获得的信息及后续行动相容，允许匪方同预算提前准备不同报告，再看平民是否有超出位置的可用依据。
