# v50 反推要付一张票时，以及第三人有当天支持时

2026-11-24。4警4匪8民，主要对照仍是首日两名原对跳者都能在第二天续报的条件板子。单边查杀另作首日只读审计。

## 策略字典

| 名称 | 动作 |
|---|---|
| `original` 原首日策略 | 继承v48和v49对手，首日没有专门增加匪徒反推，次日报告与归票提前准备。 |
| `always` 有机会就兑现 | 被普通活来源直接查杀的非匪队首发者，若在自己普通发言前听见，便提名该来源，并实际投它。 |
| `protected` 保护原目标的领先 | 同样有机会就提名。第一轮轮到自己投票时，若改投会让原目标失去当前领先或并列领先，按旧策略投原目标。本轮不改PK。 |
| `neutral` 平民基线 | 取消“第一次公开提到某座位就优先跟票”的加成。其余原接收规则照常，包括可能由位置破同分。 |
| `evidence` 平民读反推记录 | 在 `neutral` 上读取首日已完成记录。若两名来源继续提交不同的合法归票，且只有一名来源被它查杀过的人在其后提名并实际投给它，就优先采用另一名来源的归票。 |
| `protected_current` 按当天表态改归 | 首日及平民规则同 `protected_neutral`。次日若原悍跳者已报假金水，并在自己归票前看见一个合法第三人得到至少两位非匪队、非对跳者的公开支持，且人数多于原对跳者，就归第三人。两组使用同一份假金水，没有新增发言。 |
| `q=1/2` 和共同查杀 | `q`仍是特定首日警察可选回应节点的50%抽样概率。数值信用冻结。私人反证、金水保护、共同查杀、票型及PK原规则的优先级照旧。 |

组合名中的后缀 `neutral`、`evidence`指第二天平民接收方式。`protected_current`是单独的匪方归票改动，平民仍用 `neutral`。

**票的局部代价**在玩家自己第一轮投票时计算。把此前已经公开的第一轮票作为同一前缀，分别加上自己的一张原票或反推票。比如当前A与B各有2票，原本自己投A，改去反推B后，A就会从3比2领先变成2比3落后。保护组遇到这种情况保留原票。若后面还有玩家，这不是已知终局，也未保证谁最终出局。改掉一张票、让当时的领先改变、以及实际威胁一个匪队目标是不同的概念。

**当天支持**是该发言位之前已经出现的普通提名或归票，按每人最后一项算一个人。它可以是软提名；未投的票不算作兑现。排除原两名来源、本次金水和当前受保护者等非法候选。已有两个支持人尚且不够，还要多于原对跳者。多目标合格时比较人数，再按当日发言顺序。这个门槛以人为单位，未换算成概率或信用分。先前的v49用昨日报票支撑，本轮用当天表态，两个版本各自有独立对照；本轮未对两种信号做直接胜率差检验。

## 预先冻结的设计

从242000000起筛查8,192个独立新种子。对每个种子分别执行三套首日策略。三边在首日结束都留下同一对原报告者时进入主分析。公开存活名单和声明足以筛查，真实阵营只在赛后评价阶段使用。与v49一致，第二夜在必要时人为调整刀口，让两名原来源都能续报。同一首日策略下两种平民策略共享第二天首轮投票前的完整轨迹。第三人对照锁定首日保护策略和好人基线，固定相同第二天假验人和夜晚状态。

三组平民证据配对各在固定匪对手内进行，外加一组独立归票比较。使用同时95%区间，先分别求增胜和失胜的精确二项区间，再用联合界计算差。全程公开票，但保护组只根据当前已投的前缀决定。统计时区分可发言、已提名、实际兑现、是否牺牲原票、当时失去领先、第二天证据指向和终局。来自同一局的多张票只作过程数。

另从原策略截取完整首日公开历史，检查恰一名公开报验人者为活来源、且普通发言直接查杀一名仍活玩家的局面。发言先于目标普通发言，才算目标有合法发言窗口。记录目标能否提名并在第一轮兑现，赛后按真实角色分层。单边局不执行双来源比较，不赋予单边反推权重。

## 正式结果

三种首日策略对同一批种子的入组结果一致。8,192个种子中，2,743个均保留相同两名来源并入组，另5,449个均未入组。七组共19,201场完整对局，入组局第二夜全部调整刀口以保留两名来源。因此下表是这个条件板子的固定策略结果。

| 配对，每组2,743局 | 好人胜局 | 由负转胜／由胜转负 | 好人胜率差及同时95%区间 | 第二天出匪 |
|---|---:|---:|---:|---:|
| 原匪首日策略，加入反推记录 | 420 → 599 | 184／5 | +6.53个百分点，[+4.93, +8.08] | 1,783 → 2,138 |
| 有机会就反推，加入反推记录 | 420 → 455 | 41／6 | +1.28个百分点，[+0.34, +2.20] | 1,781 → 1,848 |
| 保护当下领先，加入反推记录 | 420 → 455 | 41／6 | +1.28个百分点，[+0.34, +2.20] | 1,781 → 1,848 |
| 保护当下领先，匪归对跳 → 允许按当天支持改归第三人 | 420 → 493 | 75／2 | +2.66个百分点，[+1.60, +3.70] | 1,781 → 1,935 |

### 反推的机会和票的代价

有1,368局（49.9%）触发反推提名。全额兑现组每次都投给自己提名的来源，其中884次改变了按原规则会投的座位，另外484次本来就会投给该人。**愿意真的投反推票和为此放弃原目标不同。** 在884次里只有5次会让原目标失去当时的领先资格。保护组保留了这5张原票，所以实际兑现有1,363次，实际改票879次。

这5次在两种好人接收器下都改变了完整轨迹，没有改变任何一局的终局胜负。当前首日打法中，当下领先这条保护条件覆盖很窄，不能用它估计所有实际付票成本。后续可以在公开票差不同、原票目标已经成为正式归票的条件下，比较首日保护范围。

对好人，反推证据在三种固定对手内都仍有终局增益。有机会就反推时，净增胜从179降为35，约剩19.6%。在可比较票上，两边都有反推的记录从1,661张升到4,914张，单向记录支持真警／假警的票从5,415／344变为2,156／853。这同时解释了为什么证据会更少触发，以及为什么触发后更容易误判。这些是固定策略生成的频率，不能直接用作信用概率。

**一个局部代价例子，242002184。** 7号真警查杀12号匪，12号在自己的发言位提名7号。轮到12号出票时，1、7、12号各有2票，原本想投的5号有1票。投5号会让5号加入并列领先；改投7号会让7号3票领先，5号退出领先。无条件组兑现反推，保护组按原想法投5号。后面的玩家改变了票势，两个版本首日都出12号，第二天都出11号假警，最终都赢。这个例子把当时能看见的代价与实际终局分开了。

### 单边查杀先看发言机会

在8,192条原首日记录中，335局符合这次审计的单边查杀条件。这个固定对手中，335局全是匪方单边查杀平民，目标均在自己还未发言时被查杀，也都完成提名和投票反推。这个分布受既定首日报告策略塑造，未覆盖“真警报验而匪保持沉默”的单边主张。它能证明在本策略生成器里确实有单边假警，不能推出真实桌游中单边来源为假的概率，更不能用来定一个反推折扣。

单边判断仍建议分开记录两件事。被查杀者自己有没有来得及回应，以及另一名警察是否仍有机会跳。没人对跳时，若其他人都已发言完，沉默的信息量与有机会却主动隐藏不同。后续应加入首日会藏的匪和会延后公开的真警，先检验两类单边局的实际覆盖，再调权重。

### 当天公开表态扩大了覆盖，仍没有带来投票支持

在1,417局预备假报告为金水的局面中，531局（37.5%，占全部条件局19.4%）有合格第三人。v49使用上一日已结算的票，在其独立批次仅触发7局；两者的出现率可描述比较，不能直接相减推断规则效应。

| 仅531个能够改归的同局比较 | 归对跳者 | 归第三人 |
|---|---:|---:|
| 第二天平民实际投匪方明确归票的合计票数 | 1,423 | 0 |
| 匪方明确归票的对象实际出局 | 261 | 0 |
| 第二天出匪 | 270 | 424 |
| 好人最终胜局 | 42 | 115 |

531局共记录2,022次此前支持第三人的发言，随后无一变成给该第三人的首轮实际票。条件局好人净增73胜，描述性胜率差为+13.75个百分点，区间[+9.38, +17.83]。当前条件下，按这种表态改归反而给好人带来收益。程序把当日表态分作不同用途，软提名可以形成候选，原平民接收器并不据此承诺投票。对跳双方的明确归票及来源冲突仍有更高优先级。下一步若测试更强证据，先明确哪些公开承诺在进入对跳比较后仍保留约束力，再给匪方相同的伪装机会。

**一个转票例子，242000037。** 1号悍跳匪宣布13号金水。其发言前，11、12、13、15、16号五个座位都软提名10号。原版归14号真警，14号获9票被放逐，好人输。改归10号后，五名原提名者都没有投10号，只有四张匪票给10号。14号保留了4票，1号获5票却被先放逐，终局好人胜。公开提名统计没有错，错误在于把软提名当成了对抗正式归票时仍能兑现的支持。

## 阶段决定与可复现性

保留取消新座位优先的比较基线。对双来源局保留反推证据候选，并保留会按合法时点反推的匪对手。对单边局先建立有代表性的生成对照，当前不设固定折扣。第三人分支已经有足够机会显示，当前按软表态改归对该匪策略不利；没有证据将这一结论外推到带投票承诺的另一种机制。

在三组固定的预备编报对手中，加入反推记录的区间均为正。这是可用于下一轮冻结对照的方向信号。当前试验没有在同一发言预算、相同触发条件下分别评估重报和预备编报，也没有训练池外对手的独立验收，故没有可解释的早期稳定混合权重。下一轮若要估比例，先补全两端策略的机会、实际动作和终局收益，再隔离训练与留出。q、信用和共同查杀均沿用。

- 起点 `c9c88f3`，Python 3.12.3，SciPy 1.16.3。`python -m pytest -q tests` 通过459项，145.59秒。新增3项测试覆盖已公开票的时点、旧票或后置发言不计入当天支持，以及公开改归和实际匪票对齐。
- `python scripts/run_response_cost_v50.py --smoke` 筛查96个种子、25个入组、175场；正式运行 `python scripts/run_response_cost_v50.py` 约339秒，19,201场。另做21条首中尾重跑、12条兼容v49重跑和22条案例重放，全部一致。
- `python scripts/verify_response_cost_v50.py` 从归档复算四个区间、筛选、覆盖和过程数据，并核对快照、原始文件和案例哈希。第三人条件区间另作描述性报告。最终结果不用于调整门槛或追加种子。
