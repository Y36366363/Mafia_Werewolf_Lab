# v28 方法边界澄清：改归规则包不等于纯名单外权限

2026-11-02。正式策略已经冻结、开发已查看、验收仍在运行且尚未读取时，由代码审计发现以下解释边界。策略、比较、样本及统计族均不改变。

`list`沿用旧信息路由在名单内选人；`evidence`先按新增的公开反证/条件共享验人冲突选择目标，该目标可以在名单内，也可以在名单外。因此，list→evidence同时引入：

1. 对明确依据的新优先级；
2. 在有依据时选择名单外对象的权限。

二者都有相同投票前公开归票槽，但本轮不能单独识别“仅开放名单外”的效果。冻结方案中“只比较权限”的描述过窄，应以实际代码为准，称为**有依据的改归规则包评估**。名单外实际发生次数不能代替一个严格的单变量消融。

如果后续要分离纯权限，应先让两版使用相同依据优先级，再仅对一版限制目标范围，并使用新冻结样本。本轮不追加新版本，不因当前或后续胜率改动策略，不把较好数字当作纯权限效应。
