# v14 不暴露匪徒的位置刀：完整方法与结果报告

日期：2026-10-19  
主配置：4警、4匪、8民  
证据类型：固定可审查策略的完整终局模拟、配对机制比较、有限经验矩阵受限均衡、独立留出  
结论边界：不是完整游戏GTO，不是候选池外最佳回应证明，也不是现实玩家胜率估计

## 研究问题与上一轮缺口

v13 测试的 `first/frontload` 刀法会主动让匪徒成为第一位发言者，而固定公共协调规则又高度集中投第一公共目标。因此“位置控制”被错误地实现成“把队友送上公共归票位”，好人首日出匪率达到100%。这不能说明随机刀最优，只能说明该目标函数错误。

v14 单独回答：**匪方能否选择一个使首位发言者为已知非匪的刀口，同时控制其他发言区段，并取得比随机刀更低的好人胜率？**

本轮没有加入活警带队、隐式内推、PK策略、票型学习、公开怀疑/好人判断、更多遗言或白天报匪。投票仍透明，但玩家沿用 v13 的固定投票规则；`tie_rule` 仍为 `pass`。这是为了只识别位置刀修复的效果。

## 玩家知道什么、如何选刀

匪方知道四名匪徒的座位，所以知道其他活人是非匪，但不知道其中谁是警察或平民。每个合法非匪刀口都会决定次日从死者旁开始的完整发言顺序。所有安全刀首先最大化“第一位发言者不是匪徒”，再使用不同的座位目标：

- `safe_front`：最大化第2–4位的匪徒数，再看前六位；
- `safe_middle`：最大化第4–8位的匪徒数；
- `safe_late`：最大化最后四位的匪徒数，并争取最后归票位；
- `safe_sandwich`：优先让第2位和最后一位为匪，再优化前后两端；
- `safe_balanced`：最大化前段和末段匪徒数的较小值，避免只控制一侧；
- `safe_mix`：每夜在上述五种规则中等概率抽取一种；
- `kill_random`：从当前合法非匪目标中均匀选择，作为对照。

如果之后出现活着的公开警察或验人声明者，所有刀法先把目标限制到公开声明者，再按相同几何评分。首夜不存在这类声明，验人与刀人仍同时作出。评分并列时才随机选座位。局内没有AI或语言模型，真实警察/平民身份只由裁判用于状态转移和赛后评价。

在冻结前对全部 `C(16,4)=1,820` 种匪徒座位组合做了几何核查：五个安全目标在首夜都能令首位发言者为非匪，而且每一对策略至少在一种座位组合中选择不同刀口。更换未知警察与平民身份不会改变匪方动作。

## 实验与统计设计

四种警察验人规则沿用 v13：随机、警察先于目标、警察后于目标、最大警察空隙。与7种刀法形成4×7根节点矩阵。

- 训练：每格1,024局，seed 从128,000,000开始；
- 留出：每格4,096局，seed 从129,000,000开始；
- 总执行量：`28 × (1,024 + 4,096) = 143,360`局；
- 同一阶段各格共享发牌 seed，可进行配对比较；训练与留出完全分离；
- 先求训练有限经验矩阵的有理数受限均衡，写入冻结选择文件，再读取留出；
- 留出矩阵事后重新求解只诊断漂移，不改变训练选择。

主要终点是好人终局胜率。机制指标包括首位发言者是否为匪、首日放逐身份、首位发言者是否被放逐、前/中/末段匪徒密度、首刀中警率与第二夜刀警率。六个主对比预先固定在 `inspect_gap` 行，分别比较新刀法和随机刀。

实际执行：

```sh
python3 scripts/run_position_repair_v14.py --output results/v14 --workers 4
python3 scripts/verify_position_repair_v14.py results/v14 --replay --output results/v14_integrity_audit.json
python3 -m unittest discover -s tests -v
```

## 留出胜率矩阵

下表是4,096局/格的好人终局胜率。行方希望越高越好，列方希望越低越好。

| 警察验人 | 随机刀 | 安全前段 | 安全中段 | 安全末段 | 安全包夹 | 安全均衡 | 安全混合 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 随机验 | 5.27% | 2.08% | 1.83% | **1.20%** | 1.49% | 1.71% | 1.78% |
| 警先定调 | 3.39% | **0.56%** | 0.76% | 1.37% | 1.71% | 0.95% | 1.10% |
| 警后回应 | 4.37% | 1.59% | 2.15% | **0.12%** | 1.22% | 0.95% | 0.88% |
| 最大空隙 | 5.91% | 5.13% | 2.54% | **1.15%** | 4.05% | 3.20% | 3.86% |

所有六种安全刀在每一条验人行都低于该行的随机刀。位置并非没有区别；此前失败的是“把匪徒送到第一位”的具体目标。

不同安全刀之间也存在明显差异。`safe_late` 在随机验、警后回应和最大空隙三行最低；`safe_front` 在警先定调行最低。这说明刀口价值与警察验人位置存在交互，不能单独宣布一种固定刀法是所有警察策略下的绝对最优。

## 为什么安全位置刀有效

下面固定上一轮表现最好的 `inspect_gap`，比较随机刀与安全末段刀：

| 指标 | 随机刀 | 安全末段刀 | 变化 |
| --- | ---: | ---: | ---: |
| 好人终局胜率 | 5.91% | 1.15% | −4.76个百分点 |
| 首位发言者为匪 | 25.81% | 0.00% | −25.81个百分点 |
| 第2–4位平均匪数 | 0.80 | 0.63 | −0.18 |
| 最后四位平均匪数 | 1.08 | 2.27 | +1.19 |
| 首日出匪 | 34.52% | 8.94% | −25.59个百分点 |
| 首日出警 | 22.22% | 31.27% | +9.06个百分点 |
| 首日出民 | 43.26% | 59.79% | +16.53个百分点 |
| 首位发言者被放逐 | 89.04% | 91.06% | +2.03个百分点 |
| 首刀中警 | 33.76% | 32.98% | −0.78个百分点 |
| 第二夜刀警 | 34.11% | 34.96% | +0.85个百分点 |

核心机制很清楚：安全刀没有识别谁是警察，只是保证公共锚点是一个已知非匪。当前好人和匪徒固定投票规则大多仍围绕发言顺序首位归票，于是匪方把原先可能打到队友的公共锚点系统性转移给好人。胜率下降并不是来自首刀更常命中警察：两者首刀中警率接近三分之一。

安全刀之后首日仍有8.94%出匪，是因为死警报出真实查杀等公开声明有时会覆盖默认锚点；因此模型并非无条件把第一位出局。安全末段进一步把平均2.27名匪徒放到最后四个发言位，但当前模型尚未让他们充分读取实时票型，所以“末段控制”收益不能被解释为现实中的完整归票优势。它同时改变了被刀者、公共锚点和后续各夜顺序，当前证据只支持整体机制，不支持单一中介的完全因果分解。

在 `inspect_gap` 的六个预声明配对比较中，新刀法相对随机刀的好人胜率变化均为负：

| 刀法 | 好人胜率变化 | 配对改善/恶化局数 | 多重校正探索性正态区间 |
| --- | ---: | ---: | ---: |
| 安全前段 | −0.78个百分点 | 182 / 214 | [−2.06, +0.50] |
| 安全中段 | −3.37个百分点 | 95 / 233 | [−4.53, −2.21] |
| 安全末段 | −4.76个百分点 | 40 / 235 | [−5.81, −3.71] |
| 安全包夹 | −1.86个百分点 | 141 / 217 | [−3.07, −0.64] |
| 安全均衡 | −2.71个百分点 | 116 / 227 | [−3.90, −1.52] |
| 安全混合 | −2.05个百分点 | 135 / 219 | [−3.26, −0.84] |

“改善/恶化”从好人角度计数。例如安全末段相对随机刀使40局由负变胜、235局由胜变负，其余3,821局不变。最保守的六比较 Hoeffding 同时区间对安全末段为 `[−9.93, +0.41]` 个百分点，仍略含0；因此报告同时保留宽的有限样本保守界，不把探索性正态区间当成总体证明。

关键格的 Wilson 95% 区间为：`inspect_gap × random` 5.91%，区间 `[5.23%, 6.67%]`；`inspect_gap × safe_late` 1.15%，区间 `[0.86%, 1.52%]`。

## 训练选择、留出评价与矩阵证书

训练经验矩阵的受限解为混合策略：

- 好人：随机验 `59/132`，警先定调 `173/528`，最大空隙 `119/528`；
- 匪方：安全中段 `13/44`，安全末段 `107/176`，安全混合 `17/176`；
- 训练经验值：`3043/180224 = 1.688%`，该有限训练矩阵内 gap 为0。

冻结这套训练混合后，在独立留出矩阵上：

- 好人冻结混合最坏列：安全末段；下界 `26845/2162688 = 1.241%`；
- 匪方冻结混合面对的最好行：最大空隙；上界 `1193/65536 = 1.820%`；
- 留出 gap：`3131/540672 = 0.579`个百分点。

因此训练混合没有在留出上保持零gap。策略家族的方向稳定，但具体混合权重存在样本漂移。

留出矩阵事后诊断解为：好人混合警先定调 `57/82`、最大空隙 `25/82`；匪方混合安全中段 `9/82`、安全末段 `73/82`；经验值约1.300%。这是看过留出后的描述，不能替代冻结评价，也不能用于声称获得新的未读测试表现。

## 可以成立的结论

1. **位置刀有很大影响。** 在当前固定公共协调规则中，多个不暴露首位匪徒的刀法稳定低于随机刀。
2. **v13 的反常结果来自错误目标，而非位置无效。** 抢首发把匪徒送上公共锚点；安全刀反向让非匪承担该位置。
3. **收益主要来自公开顺序和白天误放逐，而非更准确地首刀警察。** 安全刀并不知道警察身份，首刀中警仍约三分之一。
4. **控制哪个区段很重要。** 安全末段整体最强，但在警先定调行，安全前段更低，说明验人位置与刀口布局存在交互。
5. **当前好人策略缺乏针对性反制。** 受限矩阵把好人胜率压到约1–2%，不能把它解释为真实游戏天然平衡。

## 不能成立的结论与限制

- 不能声称 `safe_late` 是完整游戏最优刀法或GTO。匪方策略池仍很小，好人还没有学习“第一位总被当靶子”的反制。
- 当前公共锚点放逐率约86–91%，明显强于现实玩家的机械程度。结果证明模拟器内部存在可利用结构，也提示下一步必须允许活警带队、名单外改归、PK和票型更新。
- 末段匪徒还不会充分利用透明实时票差；因此当前“末段”只是座位几何与固定后续的组合，不等于已验证现实冲票。
- 训练与留出混合权重有漂移；冻结留出 gap 为0.579个百分点，而非0。
- 各格共享开局 seed，适合配对比较；不能把28个格视为28组独立开局。
- 抽样重放使用冻结的同一模拟器，不是第二套独立裁判。

## 对下一阶段的含义

按照已保存的研究顺序，下一阶段应进入“活警带队与隐式内推”。v14 已证明一个不作反制的公共首位锚点会被匪方系统性利用。下一阶段最有价值的问题是：首夜未死警时，活警跳警、公布查杀/金水、给出内推并允许根据发言改归或进入PK，能否打破这种机械锚点，从而把好人胜率从约1–2%的受限局面恢复到更合理范围。透明票型学习、公开怀疑/好人声明和遗言数量仍应在之后分别加入。
