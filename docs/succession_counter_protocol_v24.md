# v24冻结实验协议（2026-10-29；正式训练前）

## 策略／参数字典

- `repair_q0/q50/q100`：v22两项修复、v23信息路由和跨日私人记忆全部保留。q分别0%、50%、100%，仅控制首夜未死警、首位真警尚未发言、假查杀已公开且没打中警队时，由这一名警察在自己普通轮次抽一次的回应概率。不是全队跳警率、身份概率或来源信用。
- `late/decoy`：继承safe_late后置结构刀／posterior_decoy位置伪装刀；`near/far`：首日首位发言匪按公共发言序选其后最近／最远非队友假查杀。不读取未知警民标签。匪实际刀未加2%扰动；2%仅好人继承位置似然假设。
- `quiet`：v23原固定续局；`restate`：仅原悍跳仍活且旧目标活时自己重申。
- `support`：保留restate；原悍跳已死且原目标仍活时，当天发言序第一名存活匪在自己普通发言扩展说“今天出旧目标”。普通发言仍为原平民占位，不冒充额外验人或新警察。
- `claim`：与support同条件、同发言者、同accuse建议；唯一即时区别是普通占位替换成“我跳警”（police模板）。这是新说话者承担警察身份的公开接续，不是死者身份认证，不是新验人报告，也不是将转述升格为独立证据。

四组刀/假查杀目标×四模式，共16匪列。三好人行训练1024、留出4096局/单元，共245,760局；如训练q不等于现有行，按相同留出独立模拟该实际局部q，额外65,536局并单独计数。端点矩阵为2×16，q50行是直接模拟对照，不扩增可搜索策略。

## 研究问题与主要比较

问：允许旧悍跳死亡后由队友公开接续，是否覆盖原本有胜算路径，并降低双修复的固定策略胜率？不继续加策略、不换好人接收规则、不按胜负选择触发时点或seed。

主要比较固定q50下claim−restate，四刀/目标组为一个比较族；报告配对正常近似（探索性）及同时95% Hoeffding有界区间。若零翻转，补充事先指定的并集二项零计数上界：|E[D]|≤P(D≠0)，每项上界1−(.05/4)^(1/n)；非零时不套零界。support−restate与claim−support及q差异为解释性比较，不把逐项区间当多项同时保证。

配对共享Nature和决策键随机数，但反制可改变后续路径。固定q各模式day1完整哈希必须相同；restate/support/claim在首接续机会前完整哈希必须相同。day2开始原悍跳已死且旧目标仍活的分支在处理前确定，可作分支评估，报告实际n。动态触发、控制世界赢局的机会覆盖只作描述，不将处理后子群的胜率差冒充总体因果效应。

## 信息权限、预算与来源

只向策略传Observation。匪知道自己的队友，公开历史的原假查杀/死亡/当前存活/发言序；不知道剩余警民标签。首存活匪由同一可知队伍与公开发言序确定，不借助阵营秘密相关随机信号。原目标死后不另换目标。每个接续者在普通轮次至多一普通消息+一扩展；不加PK轮次、不允许死人重新说话、不改旧消息日期、不声称新夜验。

support和claim都使用accuse通道，让匪队同样能归票。这样不会将“只有一边能够集中匪票”的混杂误认成来源资格效应。claim会被真实警察凭互认私下识破；原目标平民能否定旧查杀，但不能单凭自己是好人否定一个普通投票建议。两种声明的来源仍是接续者；旧人不因此变真。

当前router只把公开report/police声明者纳入建议来源。support并不因此获得来源资格；claim获得资格不等于认证身份。claim的police+accuse没有新report，因此未必建立report矛盾冲突边：这是待测协议边界，训练后不临时修补。
