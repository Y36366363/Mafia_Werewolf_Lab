# v19：保留验人和内推后，真警是否应回应假查杀？

## 先读策略字典

胜率表中的百分数指好人胜率，其他比例另有标注；胜率与出人率“差值”的单位为百分点。没有训练策略或求解均衡。行名不是信用等级，也不是概率。

|代码|白话含义与实际动作|
|---|---|
|`old_keep`|原信用＋平民自辩|
|`guard_keep`|金水保护＋原流程|
|`guard_answer`|金水保护＋及时回应|
|`guard_selective`|只在查杀警队时回应|
|`guard_bait`|选择性回应＋存活怀疑|
|`answer_no_denial`|及时回应但无平民自辩|

共同底座：4警4匪8民，位置验人、等权位置后验、二人内推、原信用门槛、关闭票史加分。`keep`保留原有警察报验和带队，只是不额外因假警起跳；`answer`增加首个有合法发言机会的真警回应，仍报真实验人并保留原内推，再指认假警；`selective`只在假查杀命中警队时回应。平民被查杀后只能用自己的身份反驳，旁观者没有角色认证。

|列名|具体策略|
|---|---|
|`safe_late_forward`|按匪座位挑后置优势刀；第一个匪查杀之后第一个尚未说话的非匪|
|`safe_late_last`|同后置刀；最后一个匪若已看见报验，查杀最后报验者|
|`posterior_decoy_forward`|选择削弱旧位置后验的伪装刀；同早跳|
|`posterior_decoy_last`|同伪装刀；同末匪跳|

这些匪不知道警民具体分布；并非上帝视角挑警察查杀。实际刀法在最高评分刀位之间随机破同分；2%均匀扰动只存在于好人计算位置后验时的假设似然中，不是匪方实际刀法的2%随机偏离。后续所有列都停止新增假跳，继续用共同公开信息刀法与原投票策略，因此不是学习过的最强反制。

## 数值规则：哪些是铁约束，哪些仍是粗糙权重

来源信用是行动权重，不是身份概率。平民看普通来源为0.50；被他人报金水且没有被另报查杀为0.75；自己为1。警察对队友为1，其他来源为0。建议权重至少0.60才进入正式选择；取最高，仍沿用旧规则同分较晚者优先，本轮未证明这个破同分合理。

金水保护有两层：A报B金水，把B的来源权重提升到至少A（重复传播至稳定，最高1）；公开候选池中若A、B均可出，先考虑A，环路不把全部候选清空。这是在不允许平民假跳、真警不乱发身份下实施的关系约束，不是用“均匀数世界”给单警贴坏人概率。私有查杀和当事人对假查杀的自辩另外处理。

来源权重只决定建议是否被采用；位置怀疑决定没有可采纳建议时的候选排序；内推是候选名单而非强制放逐；最后每人独立按固定程序投票。本轮关闭额外票史怀疑，不把这四者合并为一个“身份分”。

`guard_bait`在第二天起，将仍活着的第一天跳警者信用先限制为不超过0.50，然后再做金水传播，可能由支持关系重新提升。对真警假警相同。这是未经校准的探索性怀疑规则，不是“没死就是匪”的逻辑。

例：A假查杀民C，C知道A是假警，可以提名、投A；旁观D并不知道C确为民。真警B若接着回应，报的是自己实际首验，再声明A是假警，不伪造“验A为匪”。若首验是金水，还能保留原来的内推名单。

## 先看结论：解决了什么，尚不能回答什么

1. **完成公平一些的回应比较。** 本次不再用v18的均匀声明世界计数给单警定罪；保留旧信用，加入金水关系保护、真实验人、原有内推、合法发言机会和平民自己的反驳。不能用这些绝对胜率直接与v18比较，它们是不同策略条件。
2. **早假查杀后“总要回应”仍没有稳定胜率收益。** 后置刀下A/B差值分别为-0.08／+0.68个百分点；伪装刀下为-0.37／+0.26。方向翻转，不足以确定必回或必藏。
3. **已有真警公开后，再暴露一名队友，需要单独权衡。** 伪装刀／末匪跳分支，额外回应A/B胜率差为-1.59／-1.18个百分点，每局多公开一名真警。正常近似区间为负，但保守区间仍跨零；这是固定续局中的负向证据，不能当全策略定理。后置刀／末匪跳没有后续真警发言机会，不能伪造一个回应结论。
4. **“被错查杀的平民知道假警是谁”确实可影响首日。** 在伪装刀／早跳主条件中，加入该平民的反驳提名和优先投票后，首日出匪率A/B增加+4.20／+4.48个百分点；整局胜率只增加+0.11／+0.15个百分点。不能把局部选票优势等同于已经赢局。
5. **没有验证完整沉默钓鱼。** 原keep仍让首名真警报验；因此另用全新C/D种子补测真正暂缓首个跳警，结果在文末v19b。存活信用封顶对照本轮没有有效触发，不能据其零差异否定存活推理。

**真正隐藏的补充结果：** 当假查杀中民、无真警先公开且确能回应时，后置刀下暂缓跳警在两批均更好；伪装刀下回应明显改善首日出人，但整局胜率增量仍不确定。详见文末独立新种子C/D表，不能据此定出必跳或必藏的统一规则。

**模型限制直接影响解释：** 原信用给未获金水支持的真警来源0.50，低于0.60建议采纳门槛；真警出来反驳，不意味着旁观平民会听从。于是观察到的无收益可能来自信息没有转化为合理投票，不能直接归结为对跳战术不好。

**建议下一步先做：** 保存跨日的私人“我知道此人是假警”证据，区分无人回应与无机会回应，给有无对跳和存活信息建立可触发的更新，再验证原来的信用门槛是否阻断了真实信息。完成这些基础核查后再决定是否增加策略；跨日联盟、公开怀疑、遗言制度和白天报匪继续分开保留。

## 本次方法与证据边界

预先冻结6行×4列，A、B两个互不重叠区块，每单元各4096局，总196608局。A种子156000000起，B种子157000000起。不用A挑策略再跑B；两批配置运行前一并冻结。相同列跨行共享发牌、首验、首刀与假跳时点和目标，程序检查所有分层掩码一致。进入续局后行动不同会自然导致轨迹不同。

主分层：首夜死者不是警察，并且假跳之后确实有活警尚未普通发言。再按假查杀实际命中民或警分层；角色标签仅供评价统计，不输入决策。首夜死警且有回应机会另列。“末匪跳”并不必然是全场末位；仍需逐局检查实际机会。没有假跳的局面不计入有假跳但无机会分支。

差值采用同种子配对。正态近似95%区间是探索性、未校正多重比较；另给保守有界变量Hoeffding区间。两批方向一致支持可重复性，但不是证明总体收敛、所有匪策略下成立或达到GTO；条件样本量远小于4096时尤其要谨慎。

## 无效干预必须单列

存活降权对照在本轮组合中没有形成有效干预：第一天的跳警来源没有获得额外金水支持，原信用本来就为0.50，再封顶0.50不会改变建议资格。当前数据中的零差异不能说明存活信息无用，也不能否定沉默钓鱼。需要先设计确实可触发、不会自动判假的跨日规则再研究。

## 仍未解决的限制

1. 固定信用0.50/0.75和0.60门槛不是学到的身份概率；未对跳的单警仍不自动获得高权威。首验金水支持、警察队友信用、PK候选限制都会影响回应能否转化为选票。
2. 本轮保留原来同分较晚建议优先，尚未专门验证其后置匪风险；跨日存活怀疑只是粗规则，没有建模匪方自刀或故意留真警。
3. 匪不根据本轮结果学习，只有两种刀、两种固定假跳；真警回应、隐藏均不是完整策略空间。仅限首日干预和既定续局。被假查杀平民的显式优先反驳只读取当日声明，尚未加入跨日保存“已知假警”的私人记忆，因此不能把本轮选择性隐藏当作完整钓鱼执法策略的检验。
4. 不允许平民假跳或警察乱发身份，才能使用当前金水逻辑；金水关系不意味着来源已经真警认证，也不证明某个放逐次序全局最优。
5. 本轮保持三死亡遗言、自刀候选不加入。透明票型的可信度、跨日投票联盟、公开怀疑声明、遗言制度差异、白天报匪仍待分开研究。

## v19b补充：这次确实比较暂缓首个跳警

这是查看v19两批结果后新增的探索问题，使用另外两批新种子C/D；不是原实验的留出检验。策略和C/D在读结果前同时冻结：每单元4096局，两行×两种早跳刀法×两区块，共32768局。

`conceal`：此前没有真警公开、假警查杀未中警队时，首名真警暂不报验或跳警，仍能表达普通怀疑、保留私人验人并据此投票。`answer`：立即报真实验人、内推并指出假警。其余同v19。警察只看队友位置，不看未知目标真实身份。比较的是完整的这组行动差别，不能单独归因于某一条发言。

主条件还要求首夜未死警、确有回应机会、假查杀实际命中民。目标民身份只供评价统计。此条件下实际公开警察人数差必须为1，否则干预没有成功。

这不是说警察可以直接“见后置刀就藏、见伪装刀就跳”：实际对局不知道匪方使用哪条策略，本表是研究者分组评价。未来只能根据当时可见历史作判断，或在未知刀法混合下评估稳健性。
