# v09 多区块复验、自然开局与公开反制协议

主配置固定为4警、4匪、8民，采用公开顺序投票。v08交叉拟合表在本轮开始前冻结，不读取任何v09结果重新调整。

## 外层复验

四个独立外层区块各含768个自然开局。每个区块完整评估4种好人策略和8种匪方策略。新增`echo_det`从公开发言历史中优先追踪重复既有提名目标的非匪玩家；`echo_mimic_det`还会公开跟随最近的合法非队友目标，制造伪对齐。两种策略都只读取公开历史和匪方本来知道的队友身份。

主要复验指标是每个区块内各好人策略面对扩展匪池的最差胜率、排序和跨区块符号稳定性。合并结果用于提高精度，但不能替代逐区块报告。这里不训练新表。

## 平民首发拆分

所有首发比较改用未经首验结果筛选的自然开局。`probe_w4_diverse`与`probe_w8_diverse`比较窗口覆盖；`probe_w8_anchor`和`probe_w8_pair`保持同一8位窗口与近似提名数量，但把目标集中到一个或两个公开锚点，用于区分“发言数量”与“目标覆盖”。

三个互不复用的384局拟合折分别计算候选对5种匪策略的最差胜率，以最差折中的最差对手胜率选候选。独立1,024局验证集把候选与静默、警察早释放中较强者比较；最差胜率至少增加0.25个百分点且平均胜率下降不超过0.25个百分点才接受。最终2,048局留出在选择冻结后读取。

报告同时给出首验中匪/好人、首死身份、启动率、查杀目标覆盖率、平均提名数和平均不同目标数。这些分层只用于解释自然开局根胜率，不参与晋级。

## 证据边界

外层复验是已冻结策略的可重复性检验；新增匪策略是候选池反制；自然开局胜率是完整对局策略评估。它们均不是受限混合均衡、CFR收敛证书或完整游戏GTO。
