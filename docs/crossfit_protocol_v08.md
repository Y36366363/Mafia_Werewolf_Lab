# v08 公共确定性主目标、交叉拟合与平民探测覆盖协议

主配置固定为4警、4匪、8民，并沿用v07的公开顺序投票变体。

## 匪方公共确定性主目标

所有存活匪先按冻结评分排列好人候选。评分同分时依次使用当前公开发言序位和座位号破同分，不再调用行动者自己的随机数。匪方成员知道完整匪队友集合，因此在相同公开历史下排除的候选集合、评分和破同分键完全一致。

`deterministic`全部投主目标；`deterministic_one_decoy`让公开序位最后一名存活匪固定投次目标；`deterministic_live_margin`仅在该匪行动后主目标仍是当前唯一领先时装饰；`deterministic_live_final`还要求其为全场最后一名投票者。

## 条件概率表交叉拟合

表结构和概率网格沿用v07。每个“轮次×表格单元”获得自己独有的96个拟合种子和192个验证种子，任何两个单元都不复用。拟合子批次只提出候选概率；验证子批次只有在最差对手胜率至少提高0.5个百分点，且平均胜率下降不超过0.5个百分点时才接受。最多两轮，最终表在读取6500万号留出段之前冻结。

该设计减少同一批128个开局被九个单元反复利用的问题，但仍是顺序坐标搜索，并不消除有限样本选择偏差，也不是CFR。

## 平民公开探测覆盖

候选从首位单平民扩展到公开发言序列前2、4、6、8位中的每个平民。每个行动者根据自己的公开序位采用下一位、第二位、对座或稳定散列规则；警察仅在某个公开目标与私人查杀一致时跟随。

选择指标只使用全部首验中匪开局的无条件完整游戏胜率。1024个拟合开局选出最差对手胜率最高的窗口策略；2048个独立验证开局要求其相对静默最差胜率至少提高0.25个百分点且平均胜率不下降，否则冻结为静默。最终4096个开局仅作留出评价。启动率、探测次数和偶然对齐率只用于解释收益来源，不参与晋级。

完整游戏胜率仍是冻结启发式策略评估。候选池回应、交叉拟合选择和完整游戏GTO必须分别表述。
