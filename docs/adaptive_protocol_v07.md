# v07 公开票差、平民首发规则与训练生成条件表协议

主配置固定为4警、4匪、8民。本轮把v06的同时投票作为历史对照，另定义公开顺序投票：玩家按公开发言顺序逐一投票，每张票立即公开且不可撤回，完整票表收齐后仍由同一裁判结算。

## 无成本装饰票

`live_margin`只允许公开顺序中的最后一名存活匪考虑次优目标。若把该票投给次优目标后，匪方评分的主目标在当前已公开票表中仍唯一领先，则允许装饰；否则投主目标。这个“无成本”只针对行动时已经公开的票差，无法保证后续好人票不会改变最终结果。

`live_final`更保守：除上述条件外，行动者还必须是全场最后一名投票者，因此装饰后主目标的唯一领先就是最终票表结论。`one_decoy`保留为不读取实时票差的固定3+1对照。

## 平民首发规则

首验中匪后测试五种无需验人信息的规则：发言序列下一名、第二名、环形对座、对公开状态做固定SHA-256映射，以及按首位平民座位与公开死者锚点在前四条规则间轮换。只有首位发言者为平民时规则才启动；警察仅在公开目标恰好等于私人查杀时跟随。

主报告使用全部4,096个首验中匪状态的无条件结果，同时报告规则启动率、偶然对齐率与对齐条件结果。后两者用于解释机制，不能替代无条件可实施胜率。

## 训练生成并冻结条件概率表

条件表含九个公开信息单元：当前同目标支持数为1或至少2，分别乘以行动者公开发言序位的早、中、晚三档；另有警察无查杀时按早、中、晚三档的提名概率。候选概率网格为0、0.25、0.5、0.75、1。

在训练种子上依次更新九个单元。每次固定其余单元，对四种匪方回应执行完整游戏，先最大化最差对手胜率，再以平均胜率和保持当前值破同分。最多进行两轮坐标回应。完整表在读取留出结果前写入`table_selection_before_test.json`，之后不得调整；留出种子与训练及平民首发实验均不重叠。

该方法生成的是有限网格、固定更新顺序下的经验回应表，不是CFR遗憾收敛结果。公开顺序投票是新增规则变体，不能与v06同时投票胜率直接作因果比较。所有结果仍是冻结启发式续局的策略评估，并非完整游戏GTO。
