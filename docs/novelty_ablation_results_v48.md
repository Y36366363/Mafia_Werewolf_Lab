# v48 删掉新座位优先，再核对查杀后的反推记录

2026-11-22。4警、4匪、8民，两名首日原对跳者都在第二天续报。

## 匪方应如何把报告和归票连起来

匪队知道自己的队友，因而知道哪些座位属于好人阵营；仍看不到警察与平民的区分、警队验人和其他玩家的私人推理。它可以围绕预期出人，先考虑谁有机会被投出去、怎样保护队友，再选择支持该归票的报告和措辞。例如报8号金水之后归16号对跳者，旁观者能理解两条信息为何并存。如果改归既非查杀、也非对跳者的1号，则需要依据，例如此前可见的反对票或明确的备选轮次。否则，首日沿用的目标容易与当日目标脱节。

本轮以可提前对齐假验人、归票和实际票的策略作为主要压力条件。简单沿用旧目标留作固定对照。它有助于检验接收器能否识别这种破绽，不能代表匪方总会这么行动。真实可抗推的非对跳目标属于另一个条件策略，需要定义当时可见的跟票依据，再和出对跳比较。这个实验不为旧目标或混合重报定权重。

## 策略和参数字典

表中每个对手都搭配三种平民接收器，形成六个固定策略组合。

| 名称 | 实际行为 |
|---|---|
| `prepared` 预备编报 | 继承v47。匪队第二夜先定假验人和归票。报查杀时归该座位；报金水时归原对跳者，并使当天实际匪票跟明确归票。 |
| `unlinked` 沿用旧目标 | 继承v47。报告尽量编一个没被公开提过的座位，正式归票沿用首日目标，目标失效时换合法备选，实际票也跟正式归票。 |
| `novelty` 新座位优先 | 两份相互竞争的合法建议中，某人今天报告一个历史未被公开提过的座位，而对方没有，则优先采用该人的正式归票。两方都新或都旧，回到继承的接收器。 |
| `neutral` 取消新座位优先 | 删掉上面这一条。若没有共同查杀、私人反证等优先依据，采用原接收器的结果。在这类冲突中，原接收器仍可能用候选位置排序。名称表示对新座位不加优先。 |
| `challenge` 加入公开反推记录 | 从`neutral`出发。如果只有一名来源首日被自己查杀的人公开反推并实际投票，则优先采用另一来源已有的合法归票。两方均有记录或均无记录时，和`neutral`一样。 |
| `q=1/2` | 继承的特定首日可选起跳节点的50%抽样概率。信用分不干预。匪方报告类型沿用v47的50%假查杀、其余报金水。两种50%分别属于不同决策。 |

**公开反推记录**需要同一个被查杀者在首日普通发言中听到自己被查杀后，投票前明确提名该来源，并在已结束的首日第一轮实际投给该来源。只有提名或只有投票不够，PK和未完成的即时票也不算。它比比较号码新旧多看了一条来自另一席位、在第二天编报之前已经发生的记录。它仍然是当事人的自辩。被真查杀的匪也可以反推真警，已出局玩家的历史行为也不随死亡变成身份认证。本轮只新增对这条公开历史的使用，发言槽和模仿能力照旧。

## 方法

复用v47的公开筛选条件。首日普通发言恰有两条互不相同的跳警报告，且两人首日结束后均活着。第二夜统一保留两人，若旧刀法要刀其中一人，则在剩余合法非匪中重抽。这是人为控制的条件板子。每个入组种子在六组共享发牌、首日及第二夜；同一匪策略内，三种接收器还共享第二天首轮投票前的全部记录。条件筛入不读取角色，赛后才用角色判断跟的是谁、放逐的是谁。

干预只会发生在第二天首轮的平民票，且两名原对跳者必须有不同的合法正式归票，原接收器也仍处于来源未决。共同查杀、私人反证、金水保护和合法候选均先处理。警察、匪队和PK沿用同样的投票规则。第一对主体比较只关新座位；第二对在已经关掉新座位后再单独开启反推记录。

正式筛查238000000起连续8,192个独立新种子。每个入组种子的六条路径配对运行。两对接收器比较各跨两个固定对手，一共四个预设终局差及同时95%区间。区间由增胜、失胜两项各自的精确二项界相减。复核报告的票数以票为单位，同局多票作为过程记录，终局统计仍以对局为单位。

## 结果

共2,704个种子入组，占筛查种子的33.0%，六组共16,224场完整对局。每个入组种子都需要调整第二夜刀口，才保留两名对跳者。下表胜率变化因此都限定在该条件板子。

| 固定对手 | 接收器改动 | 好人胜局 | 由负转胜／由胜转负 | 胜率差及同时95%区间 | 第二天出匪 |
|---|---|---:|---:|---:|---:|
| 预备编报 | 取消新座位优先 | 343 → 412 | 75／6 | +2.55个百分点，[+1.38, +3.70] | 1,554 → 1,791 |
| 预备编报 | 在取消后加入反推记录 | 412 → 574 | 166／4 | +5.99个百分点，[+4.46, +7.49] | 1,791 → 2,151 |
| 沿用旧目标 | 取消新座位优先 | 434 → 484 | 66／16 | +1.85个百分点，[+0.58, +3.10] | 1,670 → 1,925 |
| 沿用旧目标 | 在取消后加入反推记录 | 484 → 554 | 71／1 | +2.59个百分点，[+1.57, +3.58] | 1,925 → 2,109 |

### 为什么删掉新座位优先有用

预备匪对照里，11,650张票符合双来源比较条件。其中1,635张遇到唯一的新座位，来自320局，全是预备匪报告的。若去掉优先，实际改变的为240局的1,225张票。剩下410张票在继承规则下本来就会投给相同的人。第二天原来错出警135局、错出民102局，改后均出匪。另有3局仍出警，但换了人。沿用旧目标的对手同样可以利用该优先，取消后实际改变287局、1,245张票。

v47发现对手能利用“唯一新座位”。这次让两个接收器从同一公开前缀实际运行，确认在这个条件板子上，去掉该优先能提高终局胜率。查验历史仍保持可见，变化只来自是否用首次公开提及来决定跟哪一条归票。

### 当事人反推提供了什么，又丢掉了什么

| 双来源比较中的记录 | 预备编报 | 沿用旧目标 |
|---|---:|---:|
| 至少一票可比较的局数 | 2,205 | 2,073 |
| 单向反推支持真警的局数／票数 | 1,117／5,613 | 1,044／4,500 |
| 单向反推支持假警的局数／票数 | 55／313 | 57／323 |
| 实际改票局数／票数 | 638／3,154 | 586／2,496 |
| 改票局里，两边仍都输 | 335 | 300 |

在预备版中，改动的3,154张票里，2,925张改为跟真警，229张改为跟假警。对照到试验，392局由出警改为出匪，也有16局由出匪改为出警、16局由出匪改为出民。这说明它既能找到有信息的旧记录，也会把假警自洽的归票接进来，个别时候更糟。两名原来源当日都按各自公开归票出票，因此“谁言行一致”在这批对局中没有进一步区分能力。

反推记录先于第二夜的预备报告，匪方无法靠把今天的叙述写得自洽而改掉昨日已投的票。当前匪方没有为这个信号重新设计首日动作。比如被真查杀的匪若也点名反推并同步投票，信号可以被伪装，下面的实际反例已经出现过。表里的比例是固定首日策略生成的赛后频率，没有写入信用分或解释为实战身份概率。

## 用三个对局理解不同作用

所有人身份均为裁判赛后标注。以下座位用1起算，归档用0起算。

**移除新座位的例子，238000330。** 第一天，3号悍跳查杀11号。第二天，16号真警实际验到11号为好人，归3号；3号匪报5号查杀，报告和归票都指向5号平民。由于11号早就被提过，5号成为唯一的新座位。新座位优先版出5号，票比8比5，最终输。取消后，原接收器让五名平民改投3号，3号以10比3出局，之后好人出完剩下两匪。这里的改变发生在使用反推记录之前。

**双方都报新座位，238000169。** 第一天6号匪查杀15号；15号听完后提名6号，首轮也投6号。第二天，真警4号报11号金水、归6号；6号匪报4号查杀、归4号。两人报告的座位都是新座位，报新规则无法区分。仅取消新座位优先时，4号真警8比5出局。纳入15号的旧记录后，五张票改投6号，6号10比3出局，最后好人胜。

**当事人的反推也能误导，238002496。** 首日1号是真匪，被5号真警查杀后提名并投了5号。另边16号假警的被查杀对象虽投了16号，却没有满足“听到查杀后公开提名”的完整条件。第二天16号报11号查杀并归11号，5号归16号。原接收器会以10比3出16号，好人最终赢。把1号的反推作为区分依据后，四张平民票从16号改到11号，7比6推出平民，终局由胜转负。

## 接下来怎样处理

在“两名原对跳者都活到第二天”的模型里，**建议把取消新座位优先作为新的比较基线**。反推记录可作为备选策略，下一轮应先给对手同样的首日反推能力，查看这点收益能保留多少。只有当对手选项的收益与覆盖都清楚后，才适合研究什么时候混入重报、什么时候预备不同验人。关于不出对跳的匪方选择，可以用“另一个目标有公开跟票依据”来界定，再和归对跳做独立比较。本轮没有测到相关最优频率。
