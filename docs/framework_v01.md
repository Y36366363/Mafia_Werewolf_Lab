# 可运行框架 v0.1

## 模块与信息流

```text
Rules + 随机角色分配
        ↓
engine.State（仅裁判知道真实身份）
        ↓ observe(player)
engine.Observation（各角色合法信息）
        ↓
policies（有限模板、可解释固定策略）
        ↓ 提交行动
simulation（阶段调度、同时行动、随机流）
        ↓
真实终局 → experiments（配对评价、独立种子）
        ↓
JSON结果 + 配置/源码哈希 → 教学候选证据

tiny：独立的小模型枚举 → 精确矩阵求解 → 最佳回应证书
                     ↘ 与通用裁判交叉核对全部144个收益
```

裁判保存全部角色；策略的所有决策函数只接收不可变观察。阶段调度器负责先收齐夜行动和选票再发布结果。裁判原子API负责对应动作合法性；单独直接调用裁判API并不等同于一个封锁所有非法阶段调用的完整状态机。

## 回合

1. 从同一夜前状态分别选验人、刀人。
2. 警队获得验人结果，处理一名夜死，立即判断胜负。
3. 若未终局且遗言名额未用尽，死者说一条声明。
4. 从死者邻座按固定方向跳过死人，存活者各说一条。
5. 从同一公共历史收齐所有存活者选票，再公开票型。
6. P0最高票唯一则放逐；并列无人出局。P1并列进入PK发言和复投，再并列无人出局。
7. 白天死亡先判断终局，再处理符合名额的遗言，进入下一夜。

首版每晚必须杀一人，不包含空刀或夜间队内投票失败。因每晚至少减少一人，不需要用任意轮数截断来伪造终局收益。个人与团队利益以阵营最终胜利为准，没有个人存活奖励。

## 动作空间

声明模板：过、报民、跳警、报告某人匪/非匪、指控、提名。公开声明不附带真实性认证。任意角色可说假话；当前候选策略只覆盖部分合法动作。报告允许提及已经死亡的验人目标；首版内推只有一名对象，没有自动锁定其他人投票权。

策略的随机选择来自按“试验种子、天数、阶段、行动者”区分的随机流。策略不知道种子，新增一次发言随机选择不会消耗之后投票的随机流。

## 好人策略池（所有名称均为实验标签）

所有警察在投票时先使用私有验人；优先投已知存活匪，排除已知好人和警队。无剩余合法嫌疑人时弃票。首验在未验、非警活人中均匀选择；验完后允许重复。

| 标签 | 警察公开信息 | 公共声明的使用 |
| --- | --- | --- |
| hit_trust | 只报查杀 | 接受所有验人声明 |
| all_trust | 报所有验人 | 接受所有验人声明 |
| dead_only | 仅在自己死亡遗言中报告 | 仅接受死者验人声明 |
| hit_skeptic | 只报查杀 | 忽略陌生人验人声明 |
| all_corroborate | 报所有验人 | 同目标同结论至少两名不同发言者 |
| all_water | 报所有验人，平民随机提名 | 接受声明，加弱提名协调分 |
| covert_nomination | 不报警身份，警队共同提名同一合法目标 | 平民按提名协调 |

除共同提名策略外，存活警队每天由当前发言顺序中的第一名警察代表发言；其他警察过。死警可独立留遗言。一个人的重复声明不会被算作多个证据，自己捏造的报告也不会成为自己的证据。警察认得同伴，只把同伴的验人声明视作警队结果；队外报告不能向警察自证。

共同提名策略按同一份警队记录和公共顺序选目标，各警察都提名该人；平民不需要看到警队身份就能回应公开提名。`covert`只是历史代码名，**没有保证隐藏身份**：若只有警察提名，提名者的角色会泄露。v03额外测试了杀手追刀公开提名者。

普通信任评分为：被接受的查杀+2，非匪报告−1，当日每个提名+0.25；最高分并列随机。这是冻结的行为模型，**没有宣称这些权重符合最优贝叶斯更新**。不采用不加解释的“好人全知”协调。

## 杀手策略池

| 标签 | 白天声明 | 夜晚行动 |
| --- | --- | --- |
| quiet_random | 报民 | 随机刀非匪 |
| hunt_claims | 报民 | 优先刀公开跳警者，否则随机 |
| fake_hunt | 一名代表假查杀 | 优先刀跳警者 |
| counterclaim | 已有敌方跳警时对跳 | 优先刀跳警者 |
| self25_fake | 假查杀，含死匪遗言 | 首夜25%自刀，其余同上 |
| self50_fake | 假查杀，含死匪遗言 | 首夜50%自刀，其余同上 |
| mimic_nomination | 匪队各成员提名同一非匪目标 | 优先刀跳警者 |

后续 `signals` 刀人规则把公开提名者也列为优先目标，只读取公开行动，排除自己的匪队。它检验新策略暴露的新信息，不是直接使用裁判身份。

匪队代表同样按发言顺序选；假查杀优先针对非匪跳警者，否则随机选非匪。投票不投同伴，优先投己方声明指控对象和非匪跳警者。杀手不能直接读取非匪中的警察身份。25%和50%是探测参数，不是求得的最优频率。

机制实验另加“自刀但不悍跳”和“相同刀人策略、既不自刀也不悍跳”，用以拆分票数损失与信号收益。

## 三层求解与验证

- 精确层：1/1/2的固定首夜、受限策略池，按全部机会分支计算整局有理数收益。用有理数LP求解，逐行逐列复算响应上下界；SciPy是额外交叉核对。
- 评价层：2/1/3、2/2/4及4/4/8跑到真实终局，胜率用Wilson区间；同一开局的策略差使用逐局配对差值区间。
- 反制层：7×7候选池先用训练种子寻找匪回应，再寻找好人回应及保守纯策略；用从未用于选择的测试种子评价。候选枚举不是完整最佳回应。v03对提名泄露另加一个冻结反制实验。

16人首日分支先按共同首夜生成状态，再改动首死遗言。固定后续好人政策为“仅死警报告，接受公共验人声明”，分别对沉默随机刀匪和假查杀追刀匪测试。活警的私有验人投票不变。这一设置用于隔离遗言影响，其他公开报告政策需要另试。

每项比较都报告好人胜率。好人胜率上升等价于匪方胜率下降，不能把自刀的正差写成匪方自刀获益。规则、开局或自刀率改变时从根节点比较，不按不同干预产生的首死角色强行配对筛选。

## 规则来源与选择理由

用户提供的胜负、允许自刀、不翻身份和死亡邻座发言优先。可找到的公开玩法有差异：[游戏运营方说明](https://www.16vs.com/16vs/html/xinshouzhinan/xinshouzhinan_youxi.html)展示了同伴互认、每夜一次角色行动、公开投票等结构，但其目标限制和投票门槛与本研究不完全相同；不能整套搬入。

[《天黑请闭眼Online》规则说明](https://games.sina.com.cn/o/n/2007-07-19/1650206111.shtml)列出了16人4/4/8、平票PK后仍平则平安日、四次遗言等变体；其“平民全灭也输”没有采用，因为用户已规定警察全灭为匪胜条件。采用同时投票、一次PK、固定代表等，是首版可复算的研究抽象。

## 后续接口

下一批扩展可依次增加：真假警的历史一致性推断、票型引起的后验、多个提名及两人候选提案、死者选方向、非均匀首夜位置策略、更多完整局部策略的回应搜索。每次记录动作树、观察与规则变化；有新规则就重新评价。

狼人杀应作为新的规则适配器增加女巫、守卫等技能及夜间结算次序，不能简单往当前“每晚必死一人”的假设塞角色。

教学导出将绑定观察、候选行动、数值来源、条件后续策略、误差和证据等级。眼下产生的是教学候选材料与反例，尚无正式题库评分资格或人类能力提升证据。
