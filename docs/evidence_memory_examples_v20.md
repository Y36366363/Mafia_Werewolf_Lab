# v20 手动理解示例：以下是规则演示，不是人类最优战术证明

## 例1：私人事实跨天保存

A跳警查杀C。C是平民，知道自己不是匪，因此在本项目排除平民假跳、真警乱报身份的前提下，C知道A是假警。

- 当天：有无跨日记忆的版本都允许C提名、优先投A。
- 第二天：A还活着，且在当前/PK合法候选内，今天未重新查杀C。记忆版C仍优先投A；只读当天的版本可能转而跟随其他候选。
- D旁观了全部发言，但不知道C确为平民，不能自动得到C的私人结论。
- 如果PK只允许B与E，C不能越过规则投A。统计“旧证据机会”只在A仍是合法候选时计数。

数字信用和这个逻辑事实是两回事。C不需要因A信用从0.6降至0.4才知道A是假警；更不能把C的确定性传给D。

## 例2：取消门槛有好处，也有风险

A是场上唯一的跳警来源，建议今天投B。D没有足够私人证据排除A。

- 旧信用：A若没有得到金水支持，来源权重0.50，低于0.60门槛，D可能不采纳A的建议。
- 信息协议：允许D采纳唯一未排除来源A的合法建议。A若是真警，信息更容易进入投票；A若是假警，这条通道也可被匪利用。

所以不能预先认为“去掉机械门槛”一定提高胜率。要测的是新的采纳规则相对于旧规则的净收益，而不是规则听起来更符合人类就宣布胜出。

## 例3：第一名警察回应与第二名警察补跳

A先假跳查杀民C；警B是预定首位警察，尚未发言：

- q=25%：B在自己的轮次私下抽一次，有25%概率报真实验人、保留内推并指出A，75%暂缓身份、仍可表达普通怀疑。
- 后面的警E不再重新抽一次，不会发生“前一个藏了，后面轮流再试”而提高全队实际起跳概率。
- 如果A查杀到了警队成员，这个可选沉默开关不适用，B按本轮预设回应。
- 如果B早已公开报验，A后来再悍跳，本轮不为了拍A再机械拉E起跳。此时的收益问题与“第一名真警出来”不同。
- 本轮没有多匪公开拉团队的动作，因此没有实现你提出的“多匪站队后接受4v4对冲”。这项例外保留为后续独立机制。

q=0或q=100不是全游戏必藏/必跳，只控制一个窄条件的行动。对手固定时q的总体收益是端点插值；对手会选最不利回应时，最坏收益的折线可能在内部最优，也可能端点最优。内部混合需要证据，不由“混合更像GTO”自动成立。
