# v48 公开新座位消融与旧票反推核对

复用v47的4警4匪8民条件板子、公开筛选器、第二夜存活约束、报告生成、续局与固定q。首日恰两名活人报告互不相同，且首日结束后均存活。第二夜在必要时避开两名来源，接收器配对必须共享该夜及第二天第一轮投票前的完整记录。角色只用于赛后评价。

两个固定对手分别为夜间预备报告与归票的`prepared`，以及独立编报告而沿用旧归票的`unlinked`。以预备版作为主要压力条件，普通版用于历史可比性。两者照用v47代码，不重新估计混合概率，也不设置新打击目标。q=1/2、信用分、共同查杀、私人反证、合法候选、公共金水保护、PK和警队归票规则均继承。两类对手可以在同一个公开前缀外生成不同归票，因此策略改动的因果对照只在同对手内解释。

依次比较三种接收器。`novelty`严格复现v47的新座位优先。`neutral`删掉这条优先，进入原接收器的结果。`challenge`在`neutral`上增一条早已完成的可核对记录。仅在v47原双来源比较门内生效，某来源首日普通发言报查杀后，被查杀的非来源玩家在自己的普通发言里点名提名该来源，并在已完成的首日第一轮实际投给该来源。只对一方有这种记录时，优先另一方当日已有的合资格归票；两边都符合或都没有时仍回退。昨日提名不是翻牌或证词，经常可由被真查杀的匪自辩模仿。玩家票权、身份、信用和策略均未改变。本轮没有为匪增加首日专门模仿协议。只用已完成的第一轮，PK、首轮顺序票的部分票、次日即时票、身份标签以及发言前提名均不算证据。目标已经出局也不清除历史，死亡不加权。

先预检239000000起96个种子，正式从238000000起连续8192个种子筛查，入组全部运行六种组合。四个预先指定的配对终局比较使用同时95% Clopper–Pearson联合界。第一阶段比较`novelty → neutral`，第二阶段比较`neutral → challenge`。报告实际改票、第二天出局对象、公开信号指向的来源角色及终局；不把票作为独立样本。第三天及以后的同输差异可作机制证据。保留固定代表例、最早改票、最早各方向终局翻转。全程保留两个对手，待后续再设计混合。
