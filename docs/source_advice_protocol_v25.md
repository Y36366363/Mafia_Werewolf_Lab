# v25：来源建议资格单项消融协议（2026-10-30；新训练前冻结）

## 字典和单一研究问题

- `base_q0/q50/q100`：v24双修复与信息路由原样，局部回应概率0%/50%/100%。
- `gate_q0/q50/q100`：其余完全相同；仅第二天起，将只有police身份声明、从未以本人来源提出report验人声明者的建议，从当日建议集合中移除。他的声明、历史冲突、私人反证全部保留。以前有本人report但今天重申旧建议仍可进入；旧死者无今日新遗言/建议仍不可凭历史指令归票。
- `restate/claim`：原人重申／死后队友自己跳警并提同一旧目标；沿用v24，不新增匪策略。四刀/目标组late_near、late_far、decoy_near、decoy_far不变。
- `q`不是身份概率、信用度或全游戏跳警率，仅首夜没死警、首警有自己的发言机会、假查杀没中警队的既有单节点局部抽样。其他必答/已公开警队/后续跳警规则不改。q始终是常用可变参数，本轮不训练/选出最佳q。
- gate是二元结构性建议资格，没有数值权重，不累计、不衰减。report真假没有认证；匪可以伪造report绕过，所以即使恢复胜率也只是机制诊断，不是最终抗反制方案。本轮手工测试明确展示此边界，不往矩阵加一批新伪造策略。

问题：在保持来源历史、身份冲突和原反制不变时，只限制无本人验人声明者的建议资格，能否改变接续跳警造成的终局损害？不同时修警队目标一致性，不加票型评分。

## 先审计后选择的依据

固定旧留出前512seed×4组×2模式，共4096完整重放。claim组出现打散共同建议动作86/178/235/285局（对应具体组以results/v25_source_audit.json为准），restate均0；警队公开目标不一致也存在，另记不合并。这些是开发证据，不是新验收。新消融优先作用于高频来源敏感路径；未按新种子胜率选参数。

## 冻结设计与种子

6好人行×8旧匪列=48格。训练176000000起512局/格，仅描述与检查，不用于选择任何策略或q；验收177000000起2048局/格；smoke178000000起。正式实际模拟122880局，另有4096旧轨迹重放，分开计数。所有来源/规则/q/主要比较在读新训练前冻结；训练和验收之间保存no_selection_before_holdout文件，不改规则。

主比较：q50下gate−base的四个claim匪条件。同时报告原定配对正常近似、Hoeffding，以及正/负翻转概率各自的Clopper–Pearson区间组合；4比较×2概率×2尾，每尾.05/16，通过并集界得四差同时至少95%。CP用SciPy数值分位数，独立binomtest反演检查；不是有理数证书。需要同一比较跨seed独立同分布模拟假设，列间共享seed不要求独立。零翻转不能当精确零总体差。

其余q、restate负对照、回应端点差、窄条件分支只作解释性比较，不能借留出挑“最佳q”。各格胜率给Wilson区间；q0、q50、q100的经验最坏列不是完整均衡、不新求矩阵，不替换旧均衡证书。

## 信息与配对不变量

策略只收Observation，无角色裁判标签；gate对真假警对称，不按死活认证，不按阵营选择提案。私人已知匪优先、私人好人排除、金水顺序保护不变。来源历史及全部冲突边在同观察的base/gate中完全相同，仅建议资格可变。

同q的base/gate首日及第二天投票前完整轨迹应逐局相同；只从第二天投票开始可能分叉。跨q首夜、首验、假警/目标/机会mask一致。节点外若未触发可选回应，跨q终局应一致。抽样完整无包装器轨迹核查审计不改决策。两项旧漏洞、非法票、忽略合法已知匪、投私人好人继续单独统计。

## 票型与理解边界

本轮只审计已公开的历史票，未部署票型学习。下一次可能有效的信号应以玩家自己当时可获得的来源反证、金水关系、提案变更、候选限制、跨日联盟为条件；不能使用赛后匪标签，也不能把“抱团”自动变成匪。警队也抱团，跟错票的民也会进入匪主导票组；假金水不能当认证，死亡不翻身份。匪未来必须能分票、诱饵、伪装反制，但本轮不扩策略池。

## 成功与失败的解释

gate若改善claim而restate不变，支持来源建议资格是本池敏感环节，非完整胜率改善或已抗伪造report。如果无改善，应据具体轨迹判断来源历史冲突/夜刀/目标协调，而不继续试门槛和seed。警队“公开查杀A但投另一个已知匪B”本轮不修，后续单独比较；信用分仍冻结，跳藏与条件混合继续待办。
