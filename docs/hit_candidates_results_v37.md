# v37 完整方法与结果报告：活来源冲突中保留查杀对象

日期：2026-11-11。代码/配置/原始结果冻结在 `results/v37/`；本轮没有用结果修改规则、扩池或调q。

本轮结论：查杀目标可以重新进入候选集，但“加入后按旧位置排序选人”没有带来统一收益。两个自刀条件终局变化很小，两个普通刀条件下降约9.13个百分点；不能把“有查杀优先处理”直接升为强制投查杀铁律。也不能因此证明原候选集就是最优。

## 1. 策略与参数字典（先读这一节）

| 名称 | 实际动作、继承与对照 |
|---|---|
| `original`／原规则 | 继承v35完整行为。首日已有活来源冲突时，从仍活着、可投且通过保护约束的来源端点中用旧位置排序选人。 |
| `retain_hits`／保留查杀对象 | 只在上述投票分支，把当前仍有效的公开查杀对象加入原候选集；排序函数不变。不是新增“必须出查杀”优先级。 |
| `self_copy_early` | 首夜自刀；死匪给非匪报假警金水并给内推/授权，一名活匪在其可用较早位置复制该金水并提出错误归票。 |
| `self_copy_team_relay` | 首夜自刀；死匪给一名活匪同伴金水，另一活匪复制；假金水也可发接力归票。 |
| `late_copy` | 不自刀，首刀继承`safe_late`位置规则；存在死者金水时可复制，否则仍可能假查杀。它不是“永远只发金水”。 |
| `late_old` | 同类普通位置刀，使用既有悍跳/归票规则；与`late_copy`只在既有开局回应条件上不同。 |
| `safe_late` | 优先让次日首个公共目标不是匪，再优先让更多匪落在发言末四位、末位等位置；并列用原有随机打破。后续优先刀活着的公开跳警者。只用匪队和公开信息，不读取警察身份。 |
| `q=1/2`，亦称q50 | 在警察私知“首死跳警者不在警队”分支，首位有资格警察抽一次50%是否回应，不重复抽；被查杀自卫等继承v35。50%是固定对照，未求最优。 |
| `day1`／`pk` | 首日／一轮平票PK；再次平票平安日。投票可弃票，新增候选不能越过当轮PK名单。 |
| `admitted_hits` | 某个观察者在本次首日活来源冲突中，可合法纳入的查杀对象。不是已证实匪名单。 |
| “真实警察查杀” | 仅在终局后按实际身份核查的分析标签，平民决策无法读取。 |
| 旧位置排序 | 继承已有Nature条件化、等权匪方位置模型的排序；本轮未重估先验。原始`inspect=random`字段被位置模块覆盖，实际验人仍为`inspect_position=gap`。这不是融合查杀真假后的完整后验；自刀、公开声明的似然仍未完整建模。 |

规则：4警4匪8民；警队互认、共同验一人；死亡不翻身份；前三名死亡有遗言；允许自刀；匪杀光警察获胜，好人出光匪获胜。每一回合的信息权限和后续规则均继承冻结实现。本轮没有加入真人/LLM发言。

没有新增分数、阈值或身份概率。来源信用、目标怀疑、归票资格、实际票仍为不同概念；信用分没有重新启用。虽继承配置里`source_credit=true`，实际`routing=evidence`分支不按数值信用决策；两条完整重放将数值信用函数替换成报错函数，未触发。

## 2. 到底改了什么，哪些前提成立

例：A查杀C，D报E金水。由于本模型首夜共同验一人，这两份首日验人不能同时为真，形成来源冲突。原程序可能只比较A、D；新程序可比较A、D、C，但若C被私人好人信息或既有金水保护顺序排除，仍不能强行加入。若有多个公开查杀，则都按相同条件考虑。

这次没有进一步缩成只比较A、C。两者是在不同信息下排除候选的另外一项干预，不能混进这次结果。A是警察且诚实报告时C为匪；A假时C可为任意合法对象，因此“优先审视A/C”有逻辑依据，“一定投C”仍是策略选择。即使假查杀错推平民，白天轮次及其后的假警控场都可能造成损失，不能只与错出警察比较。

查杀只从当前日普通或PK发言提取，来源须仍活着、仍为原接收器认可来源且未被该玩家私人信息反证；目标须合法、不在私人已知好人中，并通过原有金水保护。私人已知匪优先，不因为公开信息换成投好人。第二日起选择器完全不变，死亡不认证身份，不恢复历史轮出。

这是**投票接收器**单项消融：普通发言、最后金水归票、警方公开目标都不改。首次投票前公开前缀必须相同。首日选人可能因新增候选与原公开目标不一致，这是一项隔离实验的限制，不能称为已经统一好的完整归票协议。后续发言当然可能随出局对象变化。

关于金水双目标：你说“跟最后正式归票”是合理的，此前重放中的实际票已经跟最后relay。本轮不改那一机制；待办是区分前一个accuse究竟是分析/怀疑还是正式归票，并明确同源更新如何覆盖旧指令。不能把“最后一句话”泛化为任意后发玩家都有改归权。

## 3. 方法、样本和统计边界

每个匪方条件2,048对相同种子，四条件×两接收器，共16,384局新完整终局。新验收种子为211000000–211002047；各格复用这些相同种子做配对，因此不是16,384次独立发牌。开发冒烟212000000–212000001共16局。没有训练阶段、没有种子筛选、没有新增匪方训练。

冻结规则、参数、源码后运行验收。逐局比较开局、首轮投票前全部公开事件和警方局部抽样记录，共8,192对全部相同；旧接收器12次抽样完整重放与v35原API一致。因此本轮没有先给好人额外验人或信息。

预定8个主要比较：四匪条件各比较终局与首日出匪率。每个差值使用配对胜负翻转的两个二项边际Clopper–Pearson区间，再用union bound构造8项同时95%区间。每个边际尾概率为0.05/(4×8)=0.0015625；单位为概率，表中换成百分点。它是保守区间，不是收益估计精确证书。

配对对终局差值的实测方差，相对忽略配对协方差的估计，四条件比值约0.008、0.009、0.308、0.315（按下表顺序）；本批配对确实减少误差。该比值是描述量，不是额外显著性检验。不同匪方列共享种子和大量行为，不能把相近结果视为独立复现。

## 5. 为什么：真查杀得到采纳，但假查杀也进入来了

下表是终局后识别“首日投票前确有真警公开活匪查杀”的固定条件分支；每一行两边的前置事件相同。身份标签只用于审计，不是平民可用条件；此表是探索性过程描述，未另外宣称显著性。

| 匪方条件 | 条件局数 | 该真查杀目标被放逐：旧→新 | 条件终局好人胜：旧→新 | 平民第一轮跟该真查杀票数：旧→新 |
|---|---:|---:|---:|---:|
| 自刀＋活匪复制非匪金水 | 278 | 42→138 | 107→106 | 298→923 |
| 自刀＋同伴假金水接力 | 278 | 61→103 | 84→85 | 417→713 |
| 普通后位刀＋复制回应 | 675 | 95→352 | 241→97 | 706→2151 |
| 普通后位刀＋原悍跳 | 675 | 95→352 | 241→97 | 706→2151 |

查杀采纳遗漏确实发生了改变；“更好采纳真查杀”仍未保证终局改善。普通复制条件甚至出现真目标出局95→352，而条件胜241→97。这不是把查杀排除的旧程序正确之证明，而是提醒我们：信息采纳方式、真假对称处理、剩余匪的接续策略和续局规则一起决定终局。

普通复制条件的进一步计数：平民第一轮投向实际为好人的已纳入查杀对象，从177票增至3,256票（跨局相关票数，不是独立样本）；对应对象当日被出24→430局。这是新规则同时放大假查杀的直接路径。另一个普通旧悍跳条件对应911→3,990票、122→528局。不能把这全部叫“平民无逻辑乱投”：它们是在未认证来源时按同一公开规则处理真假信息。

更关键的是，并非所有损失来自假查杀。普通复制条件949局过程改变的分解如下；各行新增/丢失胜是配对完整终局，不能当作这些中间事件的独立因果效应。

|---|---:|---:|---:|
| 匪→民 | 174 | 0 | 84 |
| 匪→匪 | 398 | 0 | 91 |

其中398局两边都出匪，仍丢失91胜；354局原出匪变为出好人，丢失106胜；另101局由出警变为出匪，新增10胜。既有保护逻辑未保证团队协调和续局转化。不存在“只要第一天出了匪，后续就等价”的简化。

具体例：seed211000017（普通复制）中，8号真警查杀5号匪，9号假警查杀4号民。旧规则首日出9号假警，新规则首日出5号真查杀；两边当晚都刀8号真警。旧支中，11号匪第二日接续跳警，警队由私有队友信息知道他是假警，第三日能明确归11号；新支中9号第二日仍在，11号没有同样接续暴露，第三日警察改为报新金水、给内推，最后错出13号民。旧支最终赢，新支最后剩11号匪而输。

这说明当前冻结匪策略的接续时机是实质因素。它不是新匪方针对本批重新训练，反制算法和种子均未调；但此处收益仍依赖既有接续/归票模型，不能推广成“查杀匪不如出悍跳匪”的普遍铁律。其他自刀例也有“本日救警出匪，后续反而输”的变化，见逐局阅读版。

## 6. 回应本轮意见与下一步（尚未执行）

1. 查杀对象进入候选的逻辑已经可独立开关测试，私人反证、金水保护和PK限制保留，没有认证死者或活来源。它保留为研究对照，当前证据不支持直接替换成所有局面的默认规则。
2. “有查杀先出查杀”应拆成候选资格与最终优先级。本轮只测前者与旧排序的组合；尚未检验更谨慎的A/C轮次选择、来源时点条件以及公开归票一致的完整协议。不能据此同时肯定或否定它们。
3. 金水最后归票的解释得到澄清：旧例实际按最后relay投票，前一个accuse为何也被当正式建议仍待独立语义审计。本轮未修它，不宣称已统一所有公开目标与实际票。
4. 建议下一步先在已保存的“首日同为出匪、终局却翻转”案例中，审计真假来源接续与警方正式归票依据，弄清何时是保留活假警的代价、何时是续局接收器的限制。也可讨论如何在不读真实身份的前提下比较A/C轮次；先写清信息条件再决定实验，不立刻追加策略或改q。
5. q后续按信息集q(I)研究的方向保留，不要求一个全球固定比例，更不预先保证一定存在内部最优混合。这轮仍固定50%，无新混合均衡。打平衡维持小型条件候选；信用、金水双目标、day2自动公开、跨日票型、公开怀疑、遗言制度、金水假跳挡刀继续分开待办。
