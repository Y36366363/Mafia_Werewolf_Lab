# v04：16人局的掩护、局部随机化、票型与反制

日期：2026-10-11。主要配置4警、4匪、8民。本文先明确实验合同与解释边界；最终策略名、参数、种子和实际执行量以冻结配置及结果清单为准。

## 1. 本轮问题

v03表明，当警察共同提名、平民全部过时，匪徒把提名者当作夜刀信号即可大幅削弱原有优势。本轮在16人完整终局模拟中测试三个改动：平民也提名以提供掩护；警察按本人合法私有信息决定是否提名；双方读取声明与历史票型后继续调整。所有改动必须有对应匪方回应。

研究对象是可执行的局部策略及其固定对手胜率。策略只读取玩家观察；禁止用裁判全体身份、真实存活警数或未来验人构造行动。本轮不把大配置策略池称为完整均衡，也不以小配置替代16人测试。

## 2. 规则与终局

沿用已冻结规则：警匪互认并共享本队允许的信息；每晚共同验一人、刀一人；验人返回匪/非匪；被刀警察取得当夜结果；不翻身份；匪全灭好人胜、警全灭匪胜；允许自刀；同时投票；终局后不再允许遗言改变胜负。基线前三次死亡有遗言、固定方向、最高票唯一者出局，否则进入夜晚。PK、四次遗言或12人配置属于另外标注的敏感性对照，不能混入同一策略收益矩阵。

每局必须运行到真实终局。夜晚至少死亡一人，有限人口保证终止；触发预算上限应作为错误，不按“存活更多的一方”填写胜负。

## 3. 事前选定的比较结构

| 研究因素 | 最小对照 | 保持不变的条件 | 可以回答的问题 |
| --- | --- | --- | --- |
| 平民掩护率 | 0、25%、50%、100% | 警察提名率、目标规则、投票规则、同一匪方 | 掩护增加是否改善整个策略组合的终局收益 |
| 掩护目标 | 随机合法目标、跟随公开提名 | 同一掩护率及其余参数 | 有无混淆身份与有无公共协调分别造成的变化 |
| 警察局部随机化 | 100%提名、50%提名 | 同一平民掩护和投票规则 | 降低公开信号强度的收益/成本 |
| 按私有信息调整 | 固定50%、有活查杀时100%否则50% | 同一平民掩护、目标和投票 | 查杀时主动协调是否值得额外暴露 |
| 历史票型 | 关闭、开启同一有限票型评分 | 发言率、私有信息条件、对手不变 | 当前启发式的票型利用有无增量价值 |
| 匪方读取信息 | 普通信号追刀、频率评分、历史票型评分 | 匪发言和自刀率不变 | 加入新公开/己方信息的反制增量 |
| 匪方模仿 | 假查杀、共同提名 | 同一夜刀规则、同一自刀率 | 信号模仿及公共协调改变的收益 |

有限预算下不需要穷举全部参数笛卡尔积，但每个要解释的特性至少保留一对只改该特性的方案。只在多个参数同时变化的方案之间比较，可以称方案对比，不能独立归因于“掩护”“混合”或“票型”。

平民跟随第一条提名并不保证帮助真警：最先发言的匪可能利用同一个协调机制。它应被保留为可失败的候选，配合随机提名和匪先手提名对照。平民无法通过裁判标签选择“跟随警察的提名”。

## 4. 局部混合不引入秘密团队装置

每次角色条件行动，玩家依据自己的观察和自己的决策随机数抽样。例如警察知道己方验到活匪，所以可以把提名概率从0.5调到1；平民没有该信息，所以不能同步切换到同一概率或目标。各玩家随机数按开局、天数、阶段、玩家及用途区分，不共享隐藏随机索引。

共同确定目标可以依赖警队合法共享信息和公共座位顺序；这与所有好人秘密抽取同一个团队计划不同。人类玩家若事前知道整套角色条件策略，其角色相关行为频率仍能成为对手推理依据。记录“50%提名”只是行动参数，不能自动解释为均衡混合频率。

新增策略应接受与旧策略相同的 `Observation`，裁判/执行器可以选择当前行动角色但不能把隐藏名单作为额外函数参数传入策略。声明、投票历史及死者信息均保持原有公开权限。

## 5. 频率与票型评分的约束

匪徒知道谁是匪，因此可以在非匪目标之间比较发言频率，也可以判断某人以前是否投过己方成员；平民没有匪队名单，不能使用同一真实标记。警察只可依据已验匪的记录给类似历史赋予意义。

观察到同票可能来自共同阵营、公开提名、跟风、候选限制、查杀或巧合。它是策略可用的历史信息，不能直接当作因果证据或身份认证。若评分只记同票次数而不对公开协调机会和候选数归一化，必须称为有限启发式，并保留不用票型的对照。

已知策略参数可以形成简单似然评分，但存活者已经历夜刀和投票筛选，消息还依赖历史与查杀。只把提名次数套入独立伯努利公式、使用初始人数比例的模型，属于简化预测模型；不能宣称得到完整博弈的正确贝叶斯后验。尤其不得从裁判读取“还活着几警”再计算先验。

票型只能读取已经公开的完整轮次：第一轮投票正在收集中时不得读其他人的当轮选择。PK之前公开第一轮票型则合法，必须区分这两个阶段。声明率也应按真实可发言机会定义，不能让多一次PK发言被误当多一个独立玩家或完整独立证据。

## 6. 抽样、选择与保存

冻结候选为11个好人方案×6个匪方案；每格训练256局、独立评估1,024局。训练种子从21,000,000开始，评估从22,000,000开始，结构敏感性另用23,000,000起的1,024个种子；准确范围写入 `configs/large_game_v04.json`。主矩阵共84,480条完整对局路径，但每阶段所有格子按同一组开局种子配对，不同格子不能计作额外独立开局。

训练阶段选择候选集内匪方回应、好人回应和最大化最差训练胜率的纯策略。选出的名字应在读取留出集结果前落盘。评估只计算固定方案及事前对照，不按留出集最优值重新改名为“已验证最佳”。若后续观察结果提出新策略，它必须另定版本和新种子。

可在训练后冻结少量12人结构敏感性对照（例如3警3匪6民），以及PK/四遗言变体；选择依据只来自训练集。12人结果不外推成16人最优，不因新增规模自动增加研究可信度。本轮没有必要增加20人。

每格保存完整二元胜负、种子区间、终局夜数摘要和固定策略参数。主指标好人终局胜率；差值使用同种子配对。报告改善/恶化/不变计数、配对正态区间和保守有界区间。全零差值不证明普遍等价。对冻结的10组好人对照×6个对手与5组匪对照×11个对手，共115个配对比较，额外报告经联合界调整的家族95% Hoeffding 区间；它覆盖这个事前声明的比较集合，允许各比较使用共同种子。另由训练选择的回应链对比独立标记为逐点区间，不冒称也包含在115项家族保证内。

本轮归档并记录三类来源：源码包、启动脚本、规范化配置 `source/config.json`；不把规范化配置称为原文件字节副本。源码包运行前后核对，启动脚本在运行前归档，配置对象在启动时固定。保留旧版本来源及原始结果；新增策略实现不得覆盖已有v03源码证据。抽样期间源码改变应中止，不把中间结果拼接成一个版本。

## 7. 信息与有效性检查

1. 对平民交换未知警/匪身份，合法观察相同则声明、投票及其随机分布相同。
2. 对匪交换非匪中的警/民身份，合法历史相同则频率、票型评分和刀人相同；但本队名单相同且可用于排除匪及解释历史投票。
3. 对警交换未知匪/民而保持队友与验人记录相同，声明、目标和投票相同。
4. 概率0/1边界确定；不同玩家局部抽样不借隐藏身份种子同步；有活查杀/无活查杀的混合率差只在警察私有记录中触发。
5. 平民跟随公开提名可以跟到匪的提名，不能在暗中拒绝真实匪说的话。
6. 一次发言重复或一次PK复述不应意外增加独立发言者计数；过去投票只从公开记录读取。
7. 匪方新评分只改变预先声明的夜刀选择，若还改发言、自刀或投票，要明确列为组合变化。

## 8. 推进标准

有可靠正差的候选应保留，同时搜索利用其公开规律的匪方回应；无显著收益的候选记录为未证实，不永久删除。特别关注“平民掩护是否同时降低警察身份可识别性、损害白天有效协调”“降低警察发言率是否拖延放逐已验匪”“票型推理是否只在某一固定对手上有效”等交互。

最终输出需要同时展示完整矩阵和事前对照，给出当前池内回应链及其局限。可执行策略、一次学习所得的改进、受限均衡和真实教学效果分别报告；本轮不新增人类学习有效性结论，也不将胜率最高的启发式作为德州扑克迁移题的认证答案。

## 9. 实现审阅中的具体约束

11个好人候选包含同一掩护率下的随机目标对照，因而可以把“参与提名”与“跟随公共提名”的方案差异分别呈现。`ballot_low25` 同时降低平民和警察常规提名率，属于组合改动，不能将其差值只归因于某一个参数。

匪方 `inference` 评分同时用于夜刀、白天提名/假查杀对象及投票优先级。`signals`、`history`、`votes`、`combined` 的比较是整套信息利用方式改变后的收益，不是仅改变夜刀模块的干预。各评分只使用本角色已知队友和公开记录；它们是有界的排序分数，不是身份概率。

票型开关必须只增加历史证据项。若开启后还取消警察原有的目标选择捷径、启用此前没有的公开提名评分，那么“历史开/关”在第一天没有历史时也可能不同，无法解释增量。独立测试为此构造首日没有公开票型、但已有提名的局面，要求开启/关闭票型评分时的同随机流动作一致。

该项在生成数据前发现并修复：警察未知目标只加入票型历史分，原共同目标在并列最高时优先保留；没有新增历史证据就保持原目标，不同时启用公开提名评分。平民的公共评分基础在两个开关状态中也相同。

生成数据前的7项独立测试全部通过，覆盖三种身份在含历史局面中的不可区分隐藏世界、仅警察私有活查杀触发行动率变化、平民能够误跟匪方公开提名，以及完整执行器中的票型时机。后一个集成测试强制首轮平票：15名首轮投票者看见相同投票前历史，15名PK投票者看见完整已公开首轮结果，同时没有任何未收齐的PK选择。测试没有对策略优劣预设期待，也不把通过权限测试当作均衡证书。

数据生成前另统一了未提名时的公开声明：v04警察和平民都使用 `civilian` 模板，包含普通发言、PK、遗言、无目标回退与 `pass` 干预。此前警察使用 `pass`、平民使用 `civilian` 会形成与提名概率无关的角色标记，使对手仅凭模板名称识别角色。统一后仍保留玩家知道自己的身份及合法角色条件行动；消除的是实验模板意外产生的额外公开线索。旧版本策略源码和数值证据保持独立归档。
