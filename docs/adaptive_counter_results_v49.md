# v49 匪也能兑现反推时，首日记录还值得看吗？

2026-11-23。4警、4匪、8民，固定两名首日原对跳者都能在第二天续报的条件局。

## 策略和参数字典

本轮正式比较一律采用v48的**取消新座位优先**。平民遇到两份相互竞争的报告时，不能仅凭某个座位首次被公开提及，就把票交给该来源。若条件仍未决，沿用原接收器，其中仍可能出现位置排序。下表所说的基线是对新号码取消优先的规则。

| 配置 | 实际行为 |
|---|---|
| `original_neutral` | 平民用新基线。匪用原首日行动，第二天提前准备假验人。报查杀后归被查杀者，报金水后归原对跳者。 |
| `original_evidence` | 同一匪策略。平民增加v48的首日反推记录。 |
| `counter_neutral` | 平民仍用新基线。匪方非首个发言者若在自己发言前看到活来源查杀自己，可以公开提名它，并在首轮实际投它。第二天仍按原方法归票。 |
| `counter_evidence` | 同一首日反制对手，平民增加首日反推记录。 |
| `counter_backed` | 从`counter_neutral`出发。只在第二天预备假验人是金水时，若有公开旧票支持，可把归票从对跳者改为第三人，报告内容保留。 |
| `q=1/2` | 继承特定首日警察可选回应节点的抽样概率。匪方第二天预备报告仍以50%概率报假查杀，其余报金水。这两个概率对应不同决策。 |

**反推记录**从首日已经结束的发言和首轮投票取证。两名来源都有合法但不同的归票、原接收器仍未决时，若只有一方符合“被它查杀的人听完就提名它，随后真的投它”，则优先采用另一名来源的当日合法归票。两方都有或都没有，则回到基线。非首发匪使用自己的公开提名位置，首轮票投给刚才提名的来源；若查杀出现在自己发言之后，没有补发机会。PK仍按旧候选限制投。提名及一票来自同一人，属于可查证的行为承诺，不能当两条独立见证，也不能当身份认证。

**有旧票支持的第三人**由假警在第二夜准备好。候选要是预计仍存活的非同伙，排除对跳双方、己方拟刀的人、本次假金水和在该候选集中受金水规则保护的人。候选必须至少有两张昨天已结算的首轮票，出票人也是预计仍存活、且不属于匪队或两名对跳者的座位；支持人数还必须严格多于对跳者。如果多个候选符合，先取支持人数最多者，再按当时发言顺序破同分。两张是预定门槛，单位是人，不是信用分。旧票只是公开支持线索，不能保证第二天继续跟。假查杀照常归该查杀；金水报告内容和报告时点在对照间一致，匪队只改明确归票和对应实际票。

## 设计与比较范围

首日普通发言恰有两名玩家报出不同结果、且两人首日结束后仍活着，才有机会进入条件板子。同一批种子分别运行原首日策略与可反推的首日策略做筛选。反推会移动一张真实匪票，可能改变放逐和能否继续入组。主分析只使用**两种首日策略都保住相同两名来源**的种子，并单列其他筛选结果。即便两边都入组，首日公开历史仍可能因反推而改变。对反推记录收益的因果比较，在每个固定首日对手内用相同前缀完成。

第二夜在必要时改变刀口以保留两名来源，和v47、v48一致。条件续局的绝对胜率可能受到这个限制与共同入组影响。第三人归票的比较共享首夜、首日、第二夜和假验人的全部字段，固定为有首日反制、好人用基线。改变归票后的发言与投票允许自然演化。另在首轮投票前已经确定的有备选局中，比较实际跟票与放逐。

筛查从240000000起的8,192个新种子，预检用从241000000起的96个。三个预先写明的全体条件局终局比较，以增胜和失胜的精确二项区间经联合界给出同时95%区间。角色在策略运行结束之后才用于评价，玩家只观察自己当时可见的内容。共同查杀、私人反证、金水保护及候选合法性保持原先优先级。信用分未进入新规则。本轮测两个固定反制动作，混合重报的比例继续留待后续。

## 正式结果

2,786个种子入组，每个种子运行五组，共13,930场正式终局。5,406个种子两边均未入组，这批没有只在一边入组或入组来源不同的情况。所有入组种子都需要更换第二夜刀口，以便两名来源续报。

| 每组2,786局 | 好人胜局 | 由负转胜／由胜转负 | 好人胜率差及同时95%区间 | 第二天出匪 |
|---|---:|---:|---:|---:|
| 原首日对手，加入反推证据 | 406 → 545 | 144／5 | +4.99个百分点，[+3.61, +6.34] | 1,826 → 2,177 |
| 匪能反推，加入同一证据 | 405 → 442 | 43／6 | +1.33个百分点，[+0.43, +2.22] | 1,823 → 1,901 |
| 匪能反推，归对跳者 → 允许旧票支持的第三人 | 405 → 407 | 2／0 | +0.07个百分点，[-0.19, +0.34] | 1,823 → 1,826 |

### 匪也能反推后，收益约剩原来的四分之一

全样本的净增胜从139变37，点估计保留 **26.6%**，少3.66个百分点。这个比例只是本批点估计。用表中两项同时区间相减，收益缩减的保守区间约为 **[1.39, 5.91]个百分点**。首日对子不变并不意味着首日记录相同，因此该差值反映整个可执行反制的影响，包含新增提名、实际票和它们对后续的作用。

| 反推的过程指标 | 原首日策略 | 匪会反推 |
|---|---:|---:|
| 至少一张平民票看到单向反推记录的局数 | 1,199 | 659 |
| 比较时两边都有反推记录的平民票 | 1,417 | 4,557 |
| 单向记录支持真警／假警的平民票 | 5,642／400 | 2,469／950 |
| 加入证据实际改动的对局／平民票 | 633／3,129 | 345／1,768 |

适应者在1,358局（48.7%）确实发出反推并兑现，898局改变了该匪的原首轮票。反推让很多原来的单边证据变成相互反推。单向记录还在时，也更可能指错来源。

依反制动作是否实际出现进一步拆开看：其余1,428局，两种匪策略下加入证据都净增43胜。1,358个实际反推局中，在原首日策略下加入证据净增96胜，匪实施反推后，43个整体新增胜全部发生在未反推的局面，此子样本由胜转负6局、没有增胜。这是固定样本的机制分解，未把子样本区间当额外确认性检验。整体仍有收益，主要来自匪无法在自己的正常发言位兑现反推的分支。我们据此保留它作候选，基线仍采用取消新座位优先后的原接收器。

### 旧票支撑的第三人出现得少，且没有拉到平民票

第二天共有1,365局的预备假报告是金水。符合旧票筛选的只有 **7局**，占全部条件局0.25%，占报假金水局约0.51%。这7个第三人在筛选时分别有3张或4张符合条件的首日票，对跳者在同一口径下是0张。两组共享这些票与假金水报告。

| 仅7个确有备选的局面 | 仍归对跳 | 改归第三人 |
|---|---:|---:|
| 第二天首轮跟匪归票的平民票合计 | 21 | 0 |
| 匪方明确归票的人实际出局 | 4 | 0 |
| 悍跳匪挺过第二天放逐 | 5 | 2 |
| 第二天出匪 | 3 | 6 |
| 好人最终胜局 | 0 | 2 |

对匪方，这一规则的观测方向不利，有机会时反而更容易失去悍跳队友。全样本差的区间仍包含零。7局的条件差也很不精确，描述性95%区间为[-43.98, +75.17]个百分点。当前证据不支持把“昨天有两张以上旧票”单独作为换人规则。更有针对性的依据可以要求今天出现明确的复投或改归承诺，再比较在那些局面里归第三人与归对跳。这里测试的是一条有明确口径的窄策略，未覆盖所有合理的场外目标。

## 两个复盘案例

座位以下从1号起算。角色为赛后判定。

**240000001，双边反推让证据失去区别。** 3号真警首日查杀15号匪，6号假警查杀13号平民。13号提名6号并投6号。未加首日反制时，首轮只有针对6号的完整反推记录。第二天真警3号归6号、假警6号归3号，加入证据让五张票改投6号，6号10票出局，好人最后赢。给匪首日反制后，15号在自己发言位提名3号，把原先投1号的票兑现为投3号。15号首日仍出局，但这张票留在历史里，两方都已有反推。第二天两个平民接收器都回到原选择，3号以8票被放逐，好人最后都输。

**240005863，昨天3张票并未变成今天3张平民票。** 1、7、10号首日都投14号，按筛选都是活着的非匪、非对跳者。3号悍跳匪第二天仍报8号金水。原策略归2号真警，2号8票出局，终局匪胜。备选版改归14号，只有匪队3票投14号，2号与3号各5票进入PK。之后PK出3号匪，好人最终胜。旧票满足预警条件，但多数平民此时按两名公开来源间的冲突投票。这是7例中的一个，不能用来判断所有第三目标的取舍。

## 下一轮的取舍

保留取消新座位优先作为比较基线。反推记录的新增证据仍有条件价值，下一次优先区分哪些情况下对方当时有合法机会、又愿意为反推实际付出票的代价。对第三人归票先提高证据质量并明确测试覆盖，再决定是否要继续扩展。现有7例不足以给这一策略稳定权重，重报和预备编报的混合比例也尚待测试。

- 起点 `1b6afc8`，Python 3.12.3，SciPy 1.16.3。`python -m pytest -q tests` 通过456项（116.60秒），新增测试检查查杀出现的时点、提名兑现及备选支持来源。首次单测因模拟匪行为时传入好人配置失败；修正测试配置后通过，正式对局使用原匪方配置。
- `python scripts/run_adaptive_counter_v49.py --smoke`，筛96个种子、29个入组、145场完整预检。`python scripts/run_adaptive_counter_v49.py`，筛8,192个、2,786个入组、13,930场完整对局，约218秒，15条首中尾全轨迹、6条v48兼容重跑和16条案例重放均一致。
- `python scripts/verify_adaptive_counter_v49.py` 复算配对差、条件覆盖与筛查全记录，核对冻结源码及结果哈希。另以第一条符合标准的种子重放4条完整路径，对照同局有无反制的过程，均匹配正式记录。重放不计入新对局。
