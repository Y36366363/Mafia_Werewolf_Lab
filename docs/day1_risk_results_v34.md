# v34：首日风险控制、条件金水归票与假接力（2026-11-08）

本轮将假金水的接力能力接入同一公开窗口，再比较首日三种平民接收策略。所有对局完整运行到终局。首日出匪、终局胜率、资格覆盖分别报告，第二日起恢复原有正常信息接收。

## 1. 先读策略／参数字典

- **original：原接收器**。继承v33及v31 aligned；真实金水既有接力保留，仍作为来源建议进入接收器。
- **first_live：首日处理第一活来源**。只对平民、只在首夜死者报金水且存在活报告时，优先投第一位活报告者。私人已知匪优先；私人已知好人、金水保护顺序及PK合法性优先；目标受保护或不在PK候选时回原规则。它是一项有风险的策略，不是判定该来源必匪。
- **conditional_gold：有条件金水归票**。在公开资格满足、B实际发出匹配接力后，其他平民优先接受B目标；私人信息和合法票约束仍在。B自己按原信息接收器选目标，不能把自己的发言当作额外身份证明。此项新增的是接力的优先级，不是新增金水私人信息。
- **公开资格**：A为首死者且报B金水并给匹配授权；B存活；至少一个普通轮活报告；所有活报告都报同一B好人；无尚未给验人的纯跳警者；来源之间没有公开相互归票质疑。PK出现新的冲突也撤销资格。只读当时消息，不读身份。此资格是保守、未经概率校准的设计门，不是“B肯定好”的逻辑结论。
- **self**：已有死警队友报告后，本人被查杀才防御；其他首日分支继承原规则及适用q50。**available**：外部来源跳警后，第一名仍有普通轮机会的警察回应。两者普通轮至多一名活警公开，均保留真实验人、内推及警方明确执行目标。此处是两个冻结情景，不求最优混合。
- **q50**=原局部回应分支概率50%；不代表全体警察独立50%跳警，也不控制所有首日行为。
- **fake_relay关／开**：在copy_team中，活匪B可以不接力，或使用与平民同一final_call窗口，选择自己团队公开建议中的合法非匪为错误目标，发同样格式的relay。不知道非匪中警／民身份。其自身投票继续使用原匪方策略，不强迫匪队所有票与口头目标一致。
- **风险控制到期**：第二日开始三套规则均回原接收器。历史声明和私人记忆保留；无“首日死一方就必须轮出另一方”的规则。
- **身份声明限制**仍为真警真实报告、平民不假跳。放开这些行为后，私人反证、共同金水逻辑都需重新检查；金水假跳挡刀继续独立待办。
- **信用分**仍冻结。来源信用、目标怀疑、归票资格、实际票不是同一个量；本轮只有离散资格与动作，没有新增数值信用或身份后验。

## 2. 冻结方法与比较范围

42单元（2警模式×3接收器×7匪方案），每单元训练诊断128、独立留出2048，实际运行 **91,392局完整终局模拟**，耗时385.4秒。独立发牌种子2,176个跨条件配对，不是91,392次独立发牌。训练203000000起，留出204000000起，smoke205000000起。
先过单元／smoke再冻结正式源码、参数、协议。训练不选择策略、不拟合规则；未在验收后调资格或换种子。本批结果公开后属于已查看证据；如果据此选择下一版，下一版需新的独立留出。原始逐局结果从初次正式运行即无损gzip保存，源码及哈希一并归档。另84局最终smoke；PK资格修复前的84局开发smoke单独保留，不计入正式或独立验收。
主要比较每警模式、每匪方案original→first_live及original→conditional_gold共28项；另copy_team不接力→接力6项。两指标终局胜率、首日出匪，共68项同时95%区间，使用配对翻转Clopper–Pearson加联合界。警模式之间不追加显著性筛选。
同一首夜和普通发言前缀逐局核验一致；改变的是已有final_call窗口中的接力选择和首日平民投票接收。来源真假不进入规则，角色仅做离线分层。first_live与conditional_gold的触发范围不同，因此同时报告覆盖率，不把罕见合格分支当整体收益。

## 6. “打平衡”的含义与边界

本轮已经实际测试first_live，但只在首死者报金水的首日上下文，且只改变平民接收；没有改变警方私人判断，也没有扩展到首死查杀或所有桌游情形。它与永久机械轮出不同：次日起立即恢复正常信息更新，旧来源仍可能受怀疑或被新证据支持。
一真一假时处理活者形成一警一匪；两者均匪时可能是两匪出局；若都真且未被策略或信息排除，仍有损失两警的风险。当前冻结警方生成规则限制了某些来源组合，这不构成一般性身份定理。即使B大概率为好人，B也没有自动获得警队私人信息，归票质量仍需终局检验。
统计结果包含首日放逐与此后全部夜刀、验人、投票，因此不会因当天出匪上升就直接将策略保留为100%。局部跳藏混合继续保留，当前未求最优概率。

## 8. 下一步建议

先根据本轮资格覆盖和终局结果决定保留哪些首日风险规则。若真警明知死者不是队友、存在回应机会却仍因继承q50而沉默，应单独研究这个私人条件下的跳藏概率；不必把“首死真警时多暴露一警”的成本一起接受。警察可用其警队身份判断这一条件，平民只能观察其策略所产生的声明，不能直接读取该私人标签。
条件资格中的“来源互相质疑即暂停B优先”是可独立检验的设计，不应凭直觉认定最优。本轮没有放宽这个门来追好数字。后续再讨论来源概率、复杂票型与信用；普通刀／自刀联合先验、假金水跨日委托、公开怀疑、遗言制度和白天报匪仍独立待办。
