# v42 预定方案

2026-11-16。主配置沿用 4 警 4 匪 8 民。

1. 从 v41 冻结的 17 对历史翻转记录检验相同第二日首轮公开前缀、正式归票和首个变化投票。身份只作赛后核查。历史切片用于解释 v40。
2. 普通后位刀 late_copy 下保留完整接续假验人，q=50% 做基线，并单独测试一条公开来源加成。第二日起的平民实际投票，在无私知匪且原规则需择一比较时，若当夜有且只有一份遗言验人结果，且当前有至少两个合资格活来源明确归不同对象，而其中恰一人当天报出相同对象和结论，优先投该来源的既有合法归票。来源可以报假信息，死亡不翻牌。唯一条件不成立则走原规则。法定 PK 名单、本人反证和金水保护保留。加成是条件优先级，无累计信用、概率或训练。
3. q 的局部参数仍是 v35 的“警察知道首夜死者的跳警并非己方”时的主动回应率，0／50／100% 仅比较现有入口。普通刀下复用晚刀基线，并跑两端核对入口覆盖及完整轨迹。自刀复制条件提供正对照，继承原合并与 v33 的 self_copy_early。其他回应路径和玩法照旧。未新增 q 行动时点或估计最优混合。
4. 正式用 223000000–223000767，冒烟 224000000–224000003。七组配对完整模拟。预定同时区间覆盖五项终局差：普通刀公开加成、两个普通刀 q、两个自刀 q 对各自基线。记录公开信号覆盖、同一观察改票、实际出局、终局、q抽样与报告机会。新批仅用于初步比较。A→C严格同概率放逐仍是独立干预。

冻结资产按既有 v41 快照和本轮新增文件哈希保存。案例优先取新批公开加成第一次改变当日放逐的完整成对回放。若不存在，再选第一处改票。历史及案例选择不用于调参。
