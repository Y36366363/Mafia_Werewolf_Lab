# v24配对差精度补充（训练已读、留出未读时固定）

本补充不改策略、q、种子、主要比较和既有区间；训练显示翻转概率很低，因此在留出文件生成／读取前，追加一个比无视方差的Hoeffding界更有分辨力、仍有有限样本同时覆盖保证的区间。必须标为训练后追加，不能称最初预注册。

仅用于四个固定q50主比较claim−restate。对同seed配对差D∈{-1,0,1}，令p+为输变赢概率，p−为赢变输概率，E[D]=p+−p−。分别按n个独立模拟seed中两种翻转次数，给p+和p−各构造双侧Clopper–Pearson二项区间。四比较×两概率×两尾共16尾，每尾α=0.05/16。最终区间[lower(p+)−upper(p−), upper(p+)−lower(p−)]，由并集界同时95%覆盖四个差，不要求不同列独立，也不要求同局两类翻转独立。

使用已有环境SciPy beta分位数（分析附加依赖）反演二项尾；边界k=0和k=n显式处理，以binom.cdf/sf反查非边界分位数。此区间可能保守，零翻转也不写零宽；主报告保留原预定正常近似、Hoeffding和本补充来源。仅约束固定模拟器内胜率差，不验证真实游戏、所有信息机制或策略池外不可利用。
