# v19 冻结比较协议（读取结果前）

问题：首夜没有死警、真警仍有合法发言机会时，保留实际验人和内推的一名真警回应，是否优于原流程或仅在查杀警队成员时回应？查杀平民由当事人自己的身份否定，不给其他人自动认证。首夜死警另列，不合并。

主研究4警4匪8民、死亡不翻身份、前三死亡遗言、按死者后顺序发言、允许弃票、一轮PK再平票平安日。合法自刀未纳入这次候选。其余延续v17/v16，无自然语言AI。

## 行列字典

所有好人：gap位置验人；等权位置模型；发言时给二人非绑定内推；原固定来源信用；关闭票史怀疑。`keep`保留原带队，不是所有警察闭嘴。

- old_keep：原固定信用流程，加入被假查杀平民的自我反驳，不加金水关系保护。
- guard_keep：加金水关系保护，其他同上。
- guard_answer：假警后第一个仍有发言机会的真警，报真实验人、保留内推、再公开指认假警；一次假警只一人回应。
- guard_selective：仅假查杀命中警队成员时回应，否则沿原流程。警察只使用队友位置判断，不能查看未知目标的真实角色。
- guard_bait：selective加第二天存活跳警者信用上限0.5的探索规则，真警和假警一视同仁；不能将存活视为铁假警。
- answer_no_denial：同answer，但移除被假查杀平民的自我反驳提名和优先投假警，用于检查该私人信息的贡献。

刀法 safe_late：根据匪座位挑使匪更靠后且公共首位非匪的刀；posterior_decoy：根据匪座位选择削弱旧位置后验的刀。均不知道警民具体身份。forward：第一个匪假跳，查杀尚未发言的第一个非匪（没有则第一个非匪）；last：最后一个匪在看见报验人者后查杀最后该声明者，没看到则不跳。匪后续都用共同无新增假跳续局，仍按公开跳警信息刀人。

## 数值与行动

信用不是身份概率。平民看普通来源0.5，被他人报金水且未被查杀的来源0.75，自身1；警察给队友1，其他来源0。门槛0.6；最高信用建议优先，同分仍用原来的较晚建议。金水保护逐边把B信用提升到至少A（A报B金水），重复传播到稳定；投票先考虑活着来源A再考虑B，环路不导致全弃票。这不是完整声明似然后验。私有查杀、被查杀平民自辩优先，不把旁观平民变成全知。survival先限0.5再作金水闭包，可能被支持恢复，是粗糙消融，不是学到的推理。全部权重继承或指定，未经校准。

例：匪A查杀民C，C知道A是假警，可以提名投A；旁观D不知道C确为民，不能自动投A。警B若接着回应，必须报真实首验，不能伪造查杀A；可以基于知道警队位置另指认A。
