# 1警1匪2民：可以完整走到终局的精确基准

本模型验证信息权限、真实终局回报、策略反制和求解器。它求的是**固定首夜行动、有限策略池的团队计划矩阵解**。普通警匪游戏的多人纳什均衡、完整 GTO 和 16 人局最优策略均未由此求得。

## 完整规则与收缩范围

- 四席按顺时针排列，身份为 P、M、C1、C2。枚举全部 24 种有标号身份排列；C1/C2 只是枚举标签，玩家看见的身份统一为 C。
- 匪全灭则好人获胜；警全灭则匪获胜。人数相等不提前结束。
- 第一个晚上，警在其他三席中均匀验一人，匪在其他三席中均匀刀一人。这两次选择独立且作为本基准的固定行为，**未优化位置验人与刀人**。故共有 24×3×3=216 个等概率初始分支。
- 允许自刀的原规则在这里只有一匪，自刀立即匪全灭。因此本策略池省略这一不优于任何非自刀选择的动作。只有一警，首夜刀警立即终局，不能测试死警遗言价值；该问题由更多警察的模型承担。
- 不翻身份。首死平民的遗言固定为 PASS；没有遗言后新的角色证据。存活者从死者下一席起顺时针各发言一次。
- 每次发言是 PASS，或者“我是警察；我验了某席，结果为匪/好人”。真实警察可报告被刀平民的验人结果。平民与杀手可假跳警。
- 全员听完后同时投票，只能投其他存活者。唯一最高票者出局；最高票并列不出局。这个小基准不设 PK 发言。
- 首日之后，发言全部 PASS，匪在存活非匪中均匀刀人，所有投票独立均匀选择其他存活者。每条路径最迟第三夜结束；没有按任意轮数截断、没有凭空赋值的非终局叶节点。

一警一匪一民进入首日时，好人获胜当且仅当首日投出匪。若投出警即输；若投出民，次夜只剩警可刀；若平票，下夜刀警即输，刀民则剩警匪互投平票，再下夜警死。代码仍递归计算完整续局，测试核对上述简化结论。

## 信息权限

策略只接收不可变 `Observation`：本席身份、本席号码、存活席位、首夜死者席位、公开发言历史，以及**只有警察收到**的验人目标和匪/非匪结果。传给策略的数据不含完整身份表。首夜死者不公开身份，平民不能读验人，杀手不能读取哪个对手是警。

引擎可读取真实身份以处理机会分支和胜负；该权限没有传给玩家策略。测试构造不同隐藏身份世界，检查相同合法观察得到相同动作。

## 18×8 策略池

好方每个纯计划规定警察行为与每个平民的本地行为。18 行来自下列笛卡尔积：

| 维度 | 选项 |
|---|---|
| 警察报告 | 所有真实验人、仅报查杀、沉默 |
| 平民报告 | PASS、假跳警并查杀发言顺序中第一个可投目标 |
| 听取声明 | 听第一位其他警察声明、听最后一位其他警察声明、忽略声明 |

警察投票始终使用私有验人：已验匪就投匪，已验好人就避开该人。其他选择以公开声明加减一分，平分按发言顺序选前者。自己捏造的声明不会变成自己的证据。这些是明确且有限的候选策略，未声称为合理玩家的全部反应。

匪方八列为：沉默、查杀第一个目标、查杀最后一个目标、给第一个目标好身份、给最后一个目标好身份、反跳并查杀已有第一警察声明者、复制已有第一声明、查杀第一个未跳警目标。没有已发言声明时使用公开顺序的固定默认目标。杀手的投票固定为其第一个可投目标；这个三人首日中，好人赢恰需两名好人都投匪，因此匪投另外哪一名好人不改变胜负。

“第一个/最后一个”均指以首夜死者为锚点的公开顺时针存活顺序，不读取隐藏身份。这个约定会产生位置协调效应，不能把效果全部归因于声明的真实性。

## 团队混合策略的额外假设

每一行纯计划可以分别由警察和平民用合法观察执行；他们不需要知道其他好人身份。但是，把多行**秘密相关混合**起来通常需要可信设备在开局前把同一计划索引私发给所有好人，而不把索引告诉杀手。原游戏没有这个设备。公开随机种子会向杀手透露当前计划，独立本地随机也不等同于相关混合。

因此矩阵解一般只解释为额外允许此设备时的受限团队计划基准。本次找到的鞍点恰好是纯策略，因此执行这一个结果无需额外设备；证书仍然只覆盖所列策略池。没有验证池外偏离，也没有推导普通多人游戏的完整均衡。

## 精确求解与已得结果

每个矩阵元素按 216 个机会分支逐一枚举，以 `Fraction` 保存有理数。求解器把正数平移后的矩阵转为线性规划，用有理数单纯形法求双方分布。随后独立逐行、逐列计算所有已列纯策略的最佳响应；上下界严格相等才出具证书。测试还用匹配硬币、石头剪刀布、负回报矩阵、长方形矩阵与退化矩阵检查求解器；安装了 SciPy 时另外用 HiGHS 交叉核对。

| 比较 | 好人整局获胜率 |
|---|---:|
| 完全忽略验人与声明，三人首日独立均匀投票 | 1/6 ≈ 16.67% |
| 真警报真验人、平民听第一个声明；杀手沉默 | 11/27 ≈ 40.74% |
| 同一好方策略；杀手改为查杀最后一个目标 | 5/27 ≈ 18.52% |
| 当前受限策略池鞍点 | 8/27 ≈ 29.63% |

均匀投票基准有独立解析式：首夜警生存 2/3，随后两名好人各以 1/2 投中匪，故为 (2/3)×(1/2)²=1/6。

鞍点返回“警察报真验人、平民 PASS、两者忽略其他声明且警察保留私有验人”的好方纯计划，杀手采用“查杀第一个目标”。警察报告形式有多个等价最优行；因为此解中的平民忽略声明，不能据此声称报验人有增益。确切的受限最佳响应间隙是 0。

这一反例说明：面向沉默对手测试时显著有效的“听真警声明”，遇到允许模仿的对手后会大幅下滑。它支持把反制纳入验证流程，不能支持“实战应该永远忽略声明”之类外推。

## 复现

在项目根目录运行：

```sh
python3 -m unittest discover -s tests -p 'test_tiny.py' -v
python3 -c 'from mafia_lab.tiny import run_tiny_benchmark; run_tiny_benchmark("results/tiny_exact.json")'
```

`results/tiny_exact.json` 包含完整有理数矩阵、双方策略权重、精确上下界、规则和协调假设。通用 `solve_zero_sum(matrix)` 返回 `Fraction` 的 `value`、`row_probabilities`、`column_probabilities`、`lower_bound`、`upper_bound`、`gap`，以及整数 `pivots`。给定仿真估计矩阵时，它只能求该估计矩阵的精确解，不能消除输入的抽样误差。
