# v50 反推兑现条件及当天公开支持

4警4匪8民，继承v49的两名原来源第二天能续报的条件板子。新座位不加优先，q=1/2，信用和共同查杀沿用。三种首日匪策略分别是原策略、逢合法机会就提名与投票反推、合法时提名但保护当前领先的原投票目标。第三种在实际首轮出票时，从**当时已经公开**的首轮票出发，各加自己原票和反推票各一次。如果原票下旧目标领先或并列领先，而反推会使旧目标失去领先资格，就保留原票。只比较同一前缀下的投票选择；不是实测最终票是否关键，也不使用后续票或PK票。提名不自动转成反推证据。记录合法发言、票的兑现、原票是否改变、保护触发；三种首日策略均让同一对原来源入组的种子进入主分析，独有、其他交集和均未入组另存。第二夜需要时统一避开两名来源。整个过程不按角色或终局入组。

三种匪首日策略各自配对`neutral／challenge`，每对第二天首轮投票前一致。`challenge`仍要求前日受到查杀者随后公开提名并在已结束的首轮投票兑现，只有一方有这种记录才优先另一方的合法归票。第七组独立在保护领先、平民用基线时检验第三目标。预备假金水照报，发言时可以改归另一个活非匪，排除两来源、自己人、本次金水和依旧规则受保护者。只统计该普通发言前，非匪队、非来源席位当天已见的最后提名或归票。替代者至少两人公开支持，且多于原对跳者。选支持最多者，再按当日发言序。票数是人数门槛，未拟合。试验不读取未来发言或票，不使用昨日报数替代今天支持。不保证公开提名一定会兑现成票，分别报告三者覆盖、改票和真实终局。未触发目标更换时要求全轨迹一致，两组固定同一假验人。

另用原策略完整首日首轮投票前的公共历史审计单边查杀：首日恰有一名公开报告者、该人仍活、以普通发言查杀且被查杀者仍活。按报告出现在目标自己普通发言前后分层，再按角色标签事后展示真警、假警覆盖。此审计不更改单边的反推权重或任何首日策略，频率不当作一般身份概率。

正式从242000000起连续8192个新种子，每入组种子七组；独立预检243000000起96个。四个锁定配对差以同时95%区间核对。重报／预备编报混合、跨板迁移和新旧代理混编属于后续独立验证；本轮只有预备编报的固定续局，未形成混合比例训练所需的动作池与独立验收。保留冻结协议、代码、筛选和原始对局。除预先确定的首中尾及首次胜负翻转，复盘可以按同一批机制实例解释，不能用来追加种子或改阈值。
