# v08：公共匪目标、坐标交叉拟合与覆盖收益首发

本轮在4警、4匪、8民上执行225,792局完整对局：56,832局用于互不复用的坐标拟合/验证，33,792局用于平民首发选择，其余为完全未读的矩阵和首发留出。所有对局继续采用公开顺序投票。

## 阶段结论

**公共确定性破同分已修复。**匪方主目标按“共同评分降序、公开发言序、座位号”排序；同阵营成员只用共同身份信息与公共历史，因此得到同一主目标。在4种好人策略×2种确定性匪策略的留出对局中，至少两匪投票的回合共发生散票0次。装饰策略的散票现在是明确策略动作，不再混入行动者各自随机破同分造成的伪散票。

**互不复用的坐标子批次显著收紧了训练更新。**18次坐标尝试只有2次通过独立验证：第二组掩护概率由75%降为0，警察晚位无查杀提名概率由100%降为50%。每个坐标/轮次使用独立96局拟合种子和192局验证种子，36个区间两两不重叠；最终2,048局/格的未读矩阵中，交叉拟合表的候选池最差胜率为27.78%，`confirm_mix`为25.93%，`position_mix`为25.54%。这是本次冻结候选池的纯策略maximin观察值，还不是受限混合均衡或完整GTO。

**扩大平民公开首发覆盖后，无条件收益随对齐覆盖上升。**候选只按全部首验中匪开局的完整对局胜率选拔，启动率与对齐率只用于解释。拟合选择并由独立验证接受`probe_w8_cycle`；在4,096个未读开局上，它的启动率为100%，全部状态对齐率26.34%，三个匪方对手上的最差胜率为4.35%。静默为0.10%，警察直接早释放为2.22%。这支持继续优化“覆盖率×对齐收益”，并淘汰只报告稀有对齐条件分支的评价方式。

**装饰票仍未形成稳定匪方收益。**确定性最终安全票与协调基线在四种好人策略下结果完全相同；实时票差装饰使好人胜率改变0至+0.78pp，固定一张装饰票使好人胜率增加0.29至1.76pp。当前只保留实时约束作为可研究反制，固定装饰不晋级。

## 评价边界

矩阵结果是冻结续局启发式下的策略评估；坐标训练是有限网格回应，不是CFR遗憾最小化。候选池maximin只回答当前6种匪策略中的最差结果，不能外推为完整声明游戏的GTO。首发实验又条件在首验中匪，因此只适用于该信息状态；它没有给出首验好人、首死警察或首死平民的总体开局策略。

独立核验重算476个训练单元、24个矩阵单元、21个首发单元、7,168个开局和36个种子区间，并重放81局；全部通过。
