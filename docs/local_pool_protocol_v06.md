# v06 局部混合、信息时点与增量反制池协议

本轮主配置固定为4警、4匪、8民。目标是检验三类可执行机制：各玩家只根据自己的座位、公开发言序位和公开历史独立抽样的局部混合；首验中匪后的首日信息释放时点；不放弃主要放逐目标的匪方有限伪装及其“首发者可能是诱饵”反制。

## 冻结候选

好人候选包括公开跟随、随机掩护、50%/75%局部跟随、按公开位置决定警察提名、需要两个不同公开发起者才跟随的确认掩护，以及验人历史评分的独立局部抽样。所有随机数由当前行动者、天数与动作阶段索引，玩家之间没有共享秘密策略编号。

匪方候选包括综合评分、追踪第一发起者、完全散票对照、仅一名匪投次优目标的3+1伪装、由公开发言序位最后一名匪承担次优票的3+1伪装，以及第一名匪先发低分诱饵的组合。

训练矩阵每格256局，留出矩阵每格1,024局。增量池从`public_base/random_base`对`combined/origin`开始，每轮在完整冻结候选训练矩阵中寻找当前混合的最强外部回应；收益改善超过1个百分点时，每方最多加入一个。留出结果不能改变池成员或权重。这个流程是有限候选双重神谕类比，不是信息集CFR，也没有给出完整游戏GTO收敛证书。

## 首验中匪时点干预

先用同一冻结开局策略生成首夜状态，再对每个状态复用相同续局随机种子。一般首验中匪队列比较：所有活警早提名、仅公开发言序位最晚的活警提名、首日静默。另选一个合法对齐队列：首位公开发言者是平民，且“提名其后第一名存活玩家”的无秘密规则恰好指向被验中的匪；在这里再加入平民先发、警察看到公开目标后跟随。

所有处理把首夜死者遗言固定为`pass`，避免死警遗言提前释放私人验人。一般队列回答“警察何时释放查杀”的条件因果问题；平民先发只适用于较窄的合法对齐队列，不能外推到所有首验中匪开局。

## 评价边界

终局好人胜率是冻结启发式续局的策略评估。局部混合与有限伪装是可执行候选池反制；增量池稳定仅表示没有冻结候选能在训练误差阈值外继续突破。任何结果都不能称为完整16人行为策略均衡、完整最佳回应或教学迁移证据。
