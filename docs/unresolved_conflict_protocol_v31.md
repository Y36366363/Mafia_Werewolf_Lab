# v31运行前冻结方案，2026-11-05

## 研究问题与可证伪条件

在死亡不翻身份、只有各玩家合法信息的448规则下，能否令授权字段不再单独改变谁被判为冲突来源目标，并避免从“死/活来源不能都真”直接推出活来源该出？在这个接收器基础上，同一信息时点的公开意图与实际投票能否趋于一致？该修复可能降低旧真死警分支的胜率，这是必须保留的负结果，不能为好看数字恢复死者认证。

另核对：（1）当前活警是否真在已死真警后无益补跳；（2）自刀授权相对普通刀是否付出阵营资源成本，不能从“授权有害于好人”推出“自刀为匪好策略”；（3）预设copy/quiet回应在独立种子、固定两半样本中是否仍有作用，不将针对机制的回应等同对测试seed过拟合，不宣称最佳回应、平衡或GTO。

## 策略字典

三行：
- `legacy`：v30的evidence_guard，原金水见证/名单外归票；首日接收器仍以有效授权为触发条件。旧版本兼容对照。
- `neutral`：所有首日声明统一接收，不以授权启用。保留冲突边；仅两端都活的来源冲突可作为直接比较对象。死/活冲突未决，改用合法建议并集/位置排序，不从死亡或活着推出谁真。即使选择最终恰好是活来源，也须来自其他独立建议或私人反证，而非孤立边直接指令。软名单不能变成事实；不相容来源不能凭交集互证。金水选择器暂仍v28见证优先级，这是单独保留、待aligned对照的模块。
- `aligned`：同neutral接收器；首日获遗言授权的平民在末尾调用实际投票接收器来选择并公开relay。自己做决策时忽略自己relay对原来源的替代，防止循环自我证明；旁观者把relay解释为原来源建议的更新，不复制支持来源。首日已有公开验人的真警在自己的普通发言内用同一接收器公布已知匪执行目标，警队只有在私下已知该目标为匪且投票合法时跟随。它不会招募新的警察补跳，也不会强制听私人已知错误的目标。后续信息/PK候选改变仍可合法改票，所以不是100%锁票定理。

neutral与aligned对首日遗言授权均明确允许归任何在场非自己的目标，验证授权仍只用公开结果与合法私人反证；neutral的旧选择器只用名单/见证目标，故新增权限通常未用。aligned同时统一选择器和使用更广候选范围，不解释为“纯一致性”单因素；这是可审计实现包，不包装成新算法。legacy权限保持原版。day2+策略三行均不变。数值信用、票型学习关闭。

八列不再加新反制：late/decoy×old/copy/quiet；false_notice/false_grant，与v30一字不改。late是safe_late，decoy是posterior_decoy；old为远位假查杀及旧接续；copy复制已公开首死金水并归远位非队友，未见金水回old；quiet首日不悍跳。copy/quiet不一定产生旧重申所需假查杀记录，比较是整套策略，不把续局变化错归一个首日动作。false列同首个匪自刀、同报非队友金水、同两非队友内推、其余首日过，只有授权字段不同。匪不知非队友警/民。

所有行主q=1/2，仍保留0/50/100参数，真死警分支无可选节点；本轮不选最佳q。两人名单、前三死遗言、规则、后验2%似然平滑均继承；没有新信用阈值或身份概率。2%不是实际匪刀的新增随机性。均匀发牌Nature，警/匪只能得自己队伍知识，平民不得得评价分支。

## 信息时点与资源

警方归票只在既有公开验人者普通发言的追加字段；金水仍用v30已有首日末尾槽，三行都有同样槽，未新增发言回合。发言接收器只见当时前缀；投票见其时合法前缀，PK另传候选。暂不利用实时票去改变这套接收规则。不开警队秘密新协调装置。三行死亡均不认证身份；不存在平民假跳/真警假验候选，故警队私人知道非队友警称假这一前提继续可见。不能将“第二个声明者是警察”的评价标签给平民。

## 样本、指标与冻结

开发194000000起64；新验收195000000起2048；烟测196000000起2。3×8=24单元，正式50688次完整实际模拟，开发/验收无重用。开发后不改策略、q、种子、列；不训练回应，不根据验收继续修。运行前存源码、规则、参数和本方案；派生报告/审计哈希另列。

37对两项主要指标，共74项家族95%同时区间（配对正负翻转的Clopper–Pearson界+union bound）：
1. 8列各legacy→neutral、neutral→aligned：16对；普通刀列首夜死警验好人条件，false列全体。
2. 3行×两刀×old→copy/quiet：12对，同首夜死警验好人条件。
3. 3行false_notice→false_grant：3对，全体2048，用于授权触发损害。
4. 3行×两刀的quiet→false_grant：6对，全体2048，用于自刀整套策略成本。与普通刀必须用全体发牌（非真死警子集），只匹配发牌Nature，首死/首验后果不固定。这不是纯刀成本消融，也不证明自刀在所有信息集劣势。

两项指标=终局好人胜/首日放逐匪；自刀之匪不计首日放逐。点估计并非总体精确收益，区间未排零不证明相等。总体率、过程差异和检查两半（前1024/后1024）的方向仅描述。预设显示aligned全体发牌的old/copy、old/quiet的0/25/50/75/100%整局策略混合期望，线性加权只用于匪队开局共同抽策略的实现假设，不是各匪独立混合，非训练比例或新均衡；若连相关装置/团队开局共享随机性不可用，不声称此表可分散实现。纯端点比较不依赖这种装置。
