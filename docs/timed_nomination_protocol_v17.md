# v17 内推时序、来源信用与公开票史：冻结协议

日期2026-10-22，4警4匪8民，前三死者遗言，公开顺序投票；最高票平票一次PK，再平票平安日。

首要问题：将内推从全员发言后名单内多数选择，改为警察本人发言时的非约束怀疑范围，允许后置位金水及警察声明者提出名单外改归，是否改善终局表现？

## 因子与动作

7行：legacy1/legacy2保留v16一人/二人名单内选择流程（共享本轮匪方策略，非旧数值复现）；timed1/timed2/timed3在警察本人报告之后立即给名单；credit2在timed2基础上增加来源信用；history2再增加跨日票史评分。全部固定equal位置模型、inspect_gap。legacy与timed差异是一个明确的流程组合干预（时点、开放目标、取消公开偏好多数），不能仅称为纯时点因果效应。

所有玩家每次普通发言有至多一条结构化补充。未取得公开归票地位者只能表达怀疑(nominate)。公开被报金水者或已经声明警察者可表达改归(accuse)，名单内外均允许。发言动作顺序固定；前置金水不会获得事后补发言机会；不添加全场结束后的警队秘密改归。警方首验查杀仍使用共享私人结果。隐藏警队成员不因裁判知道其身份而获得公开权限。

投票时有私人查杀的警察优先私人查杀；其余参考当时可见的声明和改归；按来源权重、再按发言先后选建议，无可信建议时回到名单；自己不能投自己，警察不投已知队友和金水。最终是否出人由全体正式投票决定。名单不限制投票范围。

信用均为冻结启发式，不是校准概率。timed行对声明者赋0.6；credit/history行对被他人公开报金水且未被公开查杀者赋0.75，否则0.5；采纳阈值0.6。警察可私下识别真正警队，平民不能。单跳警不自动真实，也不会通过裁判认证。只使用一跳公开支持，自己的声明不作为自己的新增证据，重复声明不累加；该机制仍可能被悍跳发金水污染。

history在day>1正式票史上，统计此前公开怀疑/改归与实际投票不符（含有目标后弃票），最多加0.10怀疑；与当前已怀疑座位至少两轮共同投票最多加0.05。无身份翻牌，不把死亡当身份认证，不把跟同一信号的票当独立证据。它是描述性票史评分，不声称贝叶斯身份学习；本轮尚不在该评分中专门区分警察抱团和匪徒抱团。

## 匪方反制

4列：safe_late/posterior_decoy × quiet/counter。刀法继承v16，伪装只用于首夜，后续优先追公开声明者，无声明者则late。counter使当日最后一名匪在看到外队警察声明后悍跳查杀该声明者，并在自己的补充发言中尝试名单外改归；匪方投票集中跟随队友公开指向的非队友。quiet没有悍跳，但同样可公开怀疑和保护队友。匪徒不知道非匪中谁是警察。

## 待办与限制

公开怀疑是低成本声明，尚无自然语言可检验内容。本轮只研究一个固定信用规则和有上限的票史评分，未完成信用条件概率训练、真实对手最佳回应、自由声明“认为谁是好人”、跨日策略自适应。只报告候选池内经验均衡，不称完整GTO。遗言3/4/全员变化和白天报匪另做独立研究。
