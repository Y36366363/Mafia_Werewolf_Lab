# v47 两名原对跳者续报时，平民如何选择？

2026-11-21，4警4匪8民。

## 上一轮的接续预警怎么走

接续预警是**警察归票时用的规则**。平民看到的只有警方最后公布的归票，仍按自己的信息决定投谁。

1. 真警在第二天发言时，先列出自己确定的活匪。依据可以是真实验人，也可以是“某人公开跳警，但他不在我的警队”。平民拿不到这份名单。
2. 从原本会归的人出发，试算归每个已知匪能吸引多少票。每次只改这名警察的正式归票，公开验人和此前发言不动；让未知座位用平民接收器各投一次。所得是**预测人数**，未看到后置位新发言，也未认定所有未知座位都是平民。
3. 只有换人预估**恰好多一票**时，才看两件事：原目标是否是经两名警员公开报告的真实查杀，新目标是否是首日悍跳、且其原假查杀对象仍活着并未被警队确定为匪。两个条件都成立，警察就保持原归票。这里的两名警员可以是一名遗言死警和一名活警。警察能凭队友身份理解这两份报告，旁观者不能用它认证死者。
4. 预警发生在放逐前。它只根据既有发言提示接续风险，没有提前看到夜刀、接续人或终局。原来的真实验人仍照报，警队实际出票跟明确归票。共同查杀是另一条规则，由平民在听完报告后执行。

例如 v46 的新种子231000220。4号死警和5号真警都报16号匪；5号也知道旧悍跳者6号是匪。原预测归6号得8张平民票、归16号得7张。预警建议先归16号。实际两边当天都出匪；出6号的版本让12号匪次日接走原假查杀，15号平民被推出去。出16号的版本次日出6号，再出最后一匪。

上一轮预警在93局触发，第三天出匪14→48，整批终局82→87胜，区间含零。报验顺序的收益则集中于会跟风重报的对手。两项都可保留为条件策略。匪方仍有理由在不同场合混用重报和独立编报；什么时候混、混多少需要另作配对验证。上一轮的详细数字见 [v46 报告](report_timing_results_v46.md)。

## 策略和参数字典

| 配置 | 实际动作 |
|---|---|
| `unlinked_new` 普通编报、只看新目标 | 假警夜里独立抽一个报告目标，保留昨日归票对象（失效时换合法目标）。平民只有看到一方报唯一新座位才给优先。 |
| `unlinked_consistent` 普通编报、核对历史 | 对手和发言预算相同。平民先比较三项公开异常，再按唯一新座位回退。 |
| `prepared_new` 预备编报、只看新目标 | 假警先设计报告和归票。报查杀时归查杀，报金水时可以归对跳者，假金水优先避开昨日自己实际推动的人。平民只用新目标规则。 |
| `prepared_consistent` 预备编报、核对历史 | 同一预备对手，平民加入公开记录核对。 |
| 新目标 | 此前在任何公开报告中未被报过的座位，不能代表平民确认它确实被验过。两人都新或都旧，就没有唯一新目标。 |
| 50%假查杀 | 两种假警方案共同的固定报告类型概率。抽到另一半报金水。不是对手混合最优解，也与警察首日 `q` 无关。 |
| `q=1/2` | 原有特定首日可选起跳节点的概率。数值信用仍按冻结设定，未新增。 |
| 对局中的原有优先约束 | 共同查杀、私人反证、金水保护和合法候选先处理。只有两条合法不同归票竞争且原规则仍未决，才进入本轮比较。PK继续使用继承规则。 |

三项异常都来自公开历史。① 昨天正式归票与自己实际首轮票不同。② 今天把昨天公开归票且实际投过的人报金水。③ 今天既没归自己曾公开查杀的人，也没归原对跳者。仅当一方的异常是另一方异常的**严格子集**时给它优先。两边异常相同或各有不同异常，回到只看新目标。没有累计分数，也不把这些迹象当作证明。比如昨晚真实验到昨天怀疑的人是好人，本来就应改口；系统只看到行为变化。

第二天平民可引用昨天的实际票。第二天当轮票由裁判事后核对，平民接收器不会用尚未完成的票。首日只读第一轮票，以免把PK候选限制误认成临时倒票。当天报告、正式归票和实际票分别记录。

## 配对实验怎样固定住两名来源

首日普通发言恰有两人报了不同验人，两人首日结束时仍活着，才进入本轮。筛选只用公共记录。自然夜刀通常先刀公开警，因此四组统一给第二夜加限制，保留两名原来源。只有原刀不合法时才从合法非同伙中重抽。这个限制用于构造用户指定的局面，会影响样本胜率及其外推。

两名来源在第二天各有一个普通报告位置，真警报当晚验人。假警决定第二夜刀口后，就根据自己队友、第一天公开记录和预期存活名单定下报告与归票。它看不到当晚验人、第二天遗言或真警发言。假报告尽量换新目标，也可能碰巧同报，裁判不会替它避开真实验人。两种假警都有同样的发言和归票位置，均允许匪队跟随其明确归票。四组第二天后续回到继承策略，本轮平民改动限定第二天首轮票。

正式种子从236000000起连续8192个，预检使用237000000起96个。每个入组种子运行四组，同一对手的两组共享发牌、首日和第二天首轮票之前的轨迹。按两个预先指定的终局比较报告同时95%区间。区间以增胜和失胜的精确二项界相减。过程数另列，不把多张同局票当成独立对局。

## 正式结果

8,192个新种子中，2,720个（33.2%）符合首日筛选条件，四组共10,880场完整对局。**2,720局全部需要改第二夜刀口**，因此这些百分比是保留两名对跳者的条件结果。四组都实际收到两名原来源的报告。每种匪策略均有136局两人碰巧报到同一个座位，按原规则分别处理共同查杀和不同结论。

| 每组2,720场 | 好人胜局 | 增胜／失胜 | 胜率差及同时95%区间 | 第二天出匪 | 第二天出警 |
|---|---:|---:|---:|---:|---:|
| 普通编报，加入历史核对 | 420 → 490 | 75／5 | +2.57个百分点，[+1.53, +3.60] | 1,701 → 2,083 | 861 → 628 |
| 预备编报，加入历史核对 | 348 → 348 | 0／0 | 0.00个百分点，[-0.19, +0.19] | 1,577 → 1,577 | 1,059 → 1,059 |

**普通编报的破绽是归票理由接不上报告。** 共2,134局至少有一名平民能够比较两份合法归票。新规则改动664局的2,859张票，全部转去跟真警，导致233局由出警改出匪、149局由出民改出匪。两个原来源在四组里每次都投给自己第二天明确归票的人，因此单查“说投谁就投谁”并不能区分这批来源。昨日归票与票不一致、把昨日推动者报金水这两项也没有在可比较的票上生成异常。本轮增量来自第三项：今天归票既不是本人公开查杀，也不是原对跳者。这是固定对手的弱点，三项检查的广泛有效性还需分别验证。

**预备编报消除了这项差异。** 仍有2,238局出现可比较的票；11,851张合资格票上双方都没有更少的异常，完整对局逐局相同。这次确实覆盖了原对跳者同时续报，因此与v46的覆盖不足不同。准备好的假警可以把编造的查杀配上归票，或者报金水后直接归原对跳者，再亲自跟票。平民知道对方提出了一个完整说法，依旧缺少证据判断说法是真是假。

**“谁报了新座位”甚至可能把票送给假警。** 在可比较票中，普通对照有1,204张、预备对照有1,439张面对唯一新座位，来源全部是假警。一个实际例子里，警察确实是昨夜第一次验10号，但首日假警早已公开报过10号；新的真实验人于是被程序视为“旧座位”。与此同时，假警可主动选择从没人公开报过的8号。该结果直接支持把“公开首次提及”和“来源获得新验人”分开。这不是关闭新座位优先后的胜率实验，本轮未测删除它可赢多少。

有412对普通编报版本两边最后都输，但完整轨迹发生变化。这一结果继续支持分别记录终局与过程。

## 通俗案例

**236000037，同一份新金水，不同的归票依据。** 第二天，16号真警报10号金水并归4号对跳匪。4号匪报8号金水。普通版本里它归1号，这既不是它公开查杀过的人，也不是原对跳者。只看新目标的平民觉得8号更新，5人跟票，1号警察8票出局；核对历史时这5票改投4号，4号10票出局，好人最终赢。预备版里4号仍报8号金水，但明确改归与它对跳的16号，实际也投16号。两边没有可区分的异常，两个接收器都出了16号，最终都输。

**236000503，第二天出对人也可能最后输。** 普通编报下，只看新目标的版本第二天错出4号平民，却在第三天放逐9号悍跳匪，第五天出最后一匪。核对历史的版本第二天直接出9号，但第三天改出7号平民，第五天错出13号最后一警，终局输。这是五个由胜转负中的一个。过程差异要追到后续，不能把“当天出了匪”当成已赢，也不能仅凭这条完整轨迹把终局原因归给一条后续发言。

## 如何使用本轮结论

报验顺序保留为对重报者的条件回应，接续预警保留为警方狭窄的归票检查。新实验说明，逼对手发出更多内容确实增加了可核对材料；如果对手随时能编出一套没有可见破绽的叙述，闭眼平民仍可能无从区分。下一步可优先用同一条件板子比较“只看新目标”与“没有明确反证时不因新目标给优先”，再单独测试能够支持两份叙述中哪一份的新增公共依据。混合重报和预备编报可作为后续对手，比例仍待检验。
