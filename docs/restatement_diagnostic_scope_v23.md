# v23训练后、留出读取前的反制解释性检查

训练中重申已实际执行，但所有固定q与匪组的quiet/restate终局结果相同；修复q50的执行局最后都输。为防止误写成“已经抗反制”，补充以下诊断，不改冻结策略、q或种子：

- 对训练repair_q50每个组所有实际执行重申的种子，完整配对重放quiet/restate，核对原训练胜负；统计投票/死亡行动链是否改变，区分只多了一句表达与实际行动改变但同样失利。
- 每组只保存按种子顺序第一个“行动链改变”例，以及第一个“执行但行动链不变”例；不按好看胜率选例。数据只作开发诊断，不算新样本。
- 留出读到后，仅用原始记录列出执行次数、执行局中quiet配对原本获胜多少、最终胜负是否改变。执行是处理后变量，因此这些条件统计不能作为独立因果效应或抗剥削证明。

更强反制（队友接力、新查杀/假金水、选择性撤回）不在本轮加入，避免看到零效应就持续加规则直到得到想要的数值。

训练选到内部q=1/2后，再补只用训练数据的配对seed bootstrap灵敏度检查（500次，固定本地RNG seed172000000）。每次同一个seed抽样权重用于全部端点和匪列，保留多解最优区间，不把一个任意最优解当唯一答案。此为训练后、留出读取前的探索诊断，不是校准置信区间，也不用于改已冻结q。它回答当前50%是否容易因有限样本改变，不回答完整游戏的均衡。

另预定补充精度说明：留出8个固定配对反制比较若有0次胜负翻转，令D为配对胜负差，则|E[D]|≤P(D≠0)，零次翻转时可用上界1−(0.05/8)^(1/n)。八项同时95%，只需每项跨seed独立，不要求列间独立；若有任何翻转，该补充程序对该项只给平凡界1，不另挑新检验。此规则在读留出前确定，仅约束本框架下总体终局差，不等于反制全面性或条件行动无害，主报告仍保留原定正态与Hoeffding区间。
