# v05：16人局策略拆分与新反制协议

日期：2026-10-11。本轮延续4警、4匪、8民主配置，依据v04留出结果预先冻结候选、比较、种子与解释边界。

## 研究问题

v04的全掩护方案在训练选定的综合反制下明显优于无遮掩，但不同匪策略下方向会反转；同时，警察和平民共同启用的票型投票启发式整体变差，而“票型投票+票型验人”相对前者回升。本轮拆开以下问题：

1. 票型只用于验人，是否优于完全不用票型；
2. 只有警察、只有平民、双方都在投票中读取票型，各自造成什么变化；
3. 100%平民随机提名与100%跟随公开目标的差异，区分身份掩护与公共协调；
4. 在100%附近将平民或警察常规提名率降至75%，是否改善最差对局；
5. 匪方区分提名发起者与跟随者，或分散己方票型后，原优势能否保留。

这些频率是固定行为参数，不是求得的均衡混合。新匪策略也是候选池内反制，不是完整最佳回应。

## 策略合同

好人候选共11个。`cover100`为训练选择的起点；`cover100_random`只改变平民目标；`inspect_only`只开启警察票型验人；`police_vote`、`civilian_vote`、`both_vote`拆分投票角色；`inspect_police_vote`在验人基础上再开启警察票型投票；`cover75`、`police75`、`both75`分别改变平民、警察或双方常规提名率；`random_inspect`为随机掩护上的验人对照。警察有活查杀时仍以100%概率提名，投票始终优先合法候选中的已验匪。

匪方候选共7个。保留v04的综合和票型评分。`origin`用公开消息顺序区分每个目标每天的第一名提名者与后续跟随者，声明、夜刀和投票共用该固定评分。`split`让存活匪按座位顺序分散到评分靠前的不同非队友目标，牺牲集中票力以改变公开同票结构。半频提名和假查杀是对应发言反制。所有策略只读取本角色观察、公开历史和本队合法名单。

## 预声明设计

主矩阵为11×7。训练每格256局，种子31,000,000起；留出评估每格1,024局，种子32,000,000起。训练阶段选择基线的匪回应、该回应下的好人回应、第二匪回应及训练最大化最差胜率纯方案；名字在首个留出对局之前落盘。

12组好人比较对7个匪对手、5组匪比较对11个好人对手，共139项预声明比较。每项保存同种子配对差值、逐点区间及同时覆盖整个家族的95% Hoeffding区间。训练选择后的3项回应链只报告逐点区间。

敏感性使用种子33,000,000起的1,024局，只测试训练选出的基线/稳健好人和参考/训练最强匪。四个配置全部是4警4匪8民：标准规则、PK、四次遗言、反向发言。小配置不进入本轮。

## 条件分支

每格除终局胜负和夜数外，保存首夜死亡身份与首验结果，并分别报告首死警察、首死平民、首验中匪、首验好人的条件胜率。条件分母由同一策略格中的自然随机分支产生；不同策略可能改变首夜刀人，不能把跨策略条件胜率直接解释成随机干预的因果效果。它们用于定位总体差异集中在哪类开局，并指导下一轮受控分支实验。

## 解释与晋级标准

一个候选只有在新的独立留出集上保留收益，且面对同步扩充的匪方池仍有合理的最差表现，才进入下一轮。没有通过家族区间不等于无效果；方向在对手间反转时，不汇总成“普遍有效”。票型策略的失败只否定该具体评分和使用位置。

本轮不声称获得16人GTO、近似纳什均衡、完整最佳回应或教学迁移效果。所有原始0/1结果、条件标签、冻结源码、入口脚本和规范化配置一并归档；独立核验会重算统计并用归档源码重放每个实验单元的首尾种子。
