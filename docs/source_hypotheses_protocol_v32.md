# v32 冻结协议（2026-11-06）

研究问题：在不认证死亡、不使用授权字段判假的条件下，平民从声明内容与首个活来源的发言时点能排除什么来源解释？目前策略生成器是否足以支持可信的时点概率？另单独检验“已听到真警队友遗言后不再补跳”的收益，不预设它必优。

v31 旧比较存在方向性偏置：授权字段触发死/活冲突的活端点优先。训练/留出数字不能使该规则变合理。本轮固定 aligned 中性接收器及统一意图，不回滚旧优势。

## 字典与干预
- inherited：v31 aligned，保留首日防御补跳。
- restrained：只在警察自己的信息集中已听到警察队友首日遗言报告时，把自己的普通轮跳警报告改成 pass；不改变验人、私人反证、实际票和 PK 合法性。并非限制平民相信死者，也不压制“死者是匪”的真正警察回应。不修改 PK 发言。
- late / decoy：继承 safe_late / posterior_decoy 位置刀。
- old / copy / quiet：继承远位假查杀 / 复制死者金水再错误归票 / 首日不悍跳，后续沿用原计划。
- false_notice / false_grant：继承自刀假金水名单 / 再加授权；边界控制，非主策略。
- q=1/2 只继承适用分支的局部回应概率，不新增随机混合、不求均衡。
- 7/8 是十五个活人普通发言顺位的预先二分界，不是身份概率；early=1–7，late=8–15。
- no_live_at_end：完整普通发言结束仍无活来源报告；不能在前置位提前使用。
- hit / copy / other_clear：首个活来源报查杀 / 与死者同一金水 / 其他金水。

## 方法与冻结
16 个单元（2回应×8匪方案），每单元 train256、holdout2048；共36,864完整对局，2,304个不同 Nature 种子。配对同一首夜；不选择策略、不训练行动规则。另独立 smoke32局。train/holdout只用于预先设计诊断的复现，不作反复调优。

共同主要指标：终局好人胜率及首日出匪；8个回应配对×2指标=16重同时区间（原项目配对正负翻转 Clopper–Pearson + union bound）。主分析首死真警且验好人，裁判标签只做离线分层；全局和改变分支另描述，不新增显著性声称。控制策略复制不改、种子不换。

平民诊断：预先固定1号座位（代码0），仅其存活且是平民的对局；首死者有金水报告时取首个活报告刚出现的消息前缀；若无，则取发言结束。剔除票型，绝不取随后声明或未来出局。标签仅离线计算。列出7类公开事件在普通刀/自刀生成器中的出现次数。按事前自刀权重2%/10%/25%、普通六方案等分、自刀两方案等分展示事件条件敏感性；这是指定情景分布，非自然真实先验或均衡比例。若任一来源类在训练事件中零次，不将经验0/1作为可靠后验，标为未覆盖；留出只检验预先事件。

每单元按种子顺序取前8个合格平民前缀，穷举警察位置并组合计数其余匪位置，检验声明身份相容性。硬前提：平民不假跳、真警报告真实身份判断。软名单/授权/死活/发言顺位不认证身份。此处忽略共同验人目标约束、生成策略与刀法似然，是“身份逻辑必要约束的超集”，并不声称所有支持世界都能被当前策略产生。展示至少一组不同来源角色的见证；计数不是后验。

每单元3个预定种子直接重放；inherited另与原v31逐场样本对比。检查合法票、私人查杀优先、私人金水不误投；检查 restrained 首死真警遗言后无普通轮新警报告。逻辑检查授权删除不变、私人假查杀可排除来源、同内容/同时点仍允许不同身份。

不向行动器输入诊断概率，不加数值信用；不把复制/沉默固定方案称为学习后的最佳回应。不认证死者回收胜率，不以本批结果调规则。后续自刀+活匪配合、非补跳条件回应、票型/私人记忆/跨日委托、公开怀疑、遗言制度仍分开。
