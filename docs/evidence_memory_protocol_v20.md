# v20 预先冻结：私人记忆、无数值信用的信息采纳、单警局部混合

## 问题和对照字典

主配置4警4匪8民；警互认、共享每晚一次验人、只匪/非匪；死亡不翻身份，前三个死者遗言，一轮PK再平票平安日，允许弃票。位置验人gap、等权位置后验、二人非绑定内推继承v19。实际匪刀为最高评分合法刀的随机破同分；2%tremble仅在好人的位置似然假设里。不开平民假警或真警谎报，因而保留金水来源先于金水目标的关系约束；不以此声称放逐顺序全局最优。

共8行：
- credit_today：原0.5/0.75信用与0.6门槛；被假查杀的平民只在当天有优先反驳；可选回应概率1/2。
- credit_memory：同信用，跨日记住来自自己视角可确定的假警；同1/2。
- evidence_today：不用来源信用门槛，以来源声明、冲突、私人事实决定候选；私人假警反驳只读当日；同1/2。
- evidence_q50：同证据信息规则，保留跨日私人假警事实；回应概率1/2。
- evidence_q0、q25、q75、q100：同证据信息＋跨日记忆；可选回应概率分别为0、1/4、3/4、1。

后缀25/50/75/100只指单次“第一名真警是否立即公开”的概率百分比，不是信用分、胜率或平民身份概率。旧信用仅作对照，不修改或调优。双方都使用同一局部回应安排；不同于v19的可额外出第二警安排，因此绝对胜率不能跨版本归因。

4列：late_near、late_far、decoy_near、decoy_far。late是safe_late位置刀，decoy是posterior_decoy伪装刀；第一个匪在普通发言假跳，near查杀其后第一个尚未发言非匪，far查杀其后最后一个尚未发言非匪（没有后续非匪则相应从全序选）。匪只知匪队，不知目标是警还是民。这样同时检验把受害者留到更晚发言的简单反制，不根据训练结果再选目标。续局不新增假跳，匪继续追公开跳警者，依既定票法投票。

## 当事人与旁观者：记忆权限

民C看到A查杀自己，因知道自己非匪，记A为假警；memory版跨日保留，只影响C自己提名和投票。旁观D不会收到“C是平民”的裁判认证。警察知道所有队友、自己的共享验人，依“无平民假跳”排除警队外的跳警者；跨日保留这些事实。死亡不翻身份，不凭放逐结果奖励信用或认证身份。公共自查杀、同来源对同目标报相反验人，属于当前假设下的公开矛盾。

这里的remember只切换私人假警证据的跨日读取；过去的真实验人原本就保存，公开发言也始终可见。不是把“无记忆”玩家的全部历史删除。

## 信息规则不等于概率推断

evidence投票优先级：
1. 服从PK合法候选，排除自己；警察额外排除自己已知好人。私人确定的活匪/假警优先，公共观察者不得借用私人事实。
2. 保留金水A→B的来源先于目标保护；环不清空候选。
3. 排除自己能确定不是真警的来源；仅有一个未排除来源时，采用其合法当日改归/历史活查杀/当日内推（依次优先）。这是可被匪利用的“唯一来源协调协议”，不是其100%真警。
4. 多个来源建议一致时按共同建议；来源报告互不相容（例如A查杀跳警的B）时，将尚活着的冲突来源纳入比较，不用“越晚越可信”破同分。全部来源也可能都是匪，不假设必有真警。
5. 没有冲突时合并合法建议；没有建议时沿用冻结位置排序。选择冲突来源、合并建议内人选及位置同分，均使用原位置分与公开发言顺位，是策略，不是逻辑证明。

来源信用在evidence模式不用；目标位置怀疑仍是旧位置模型；谁可提出建议由声明来源和冲突关系决定；最终每人独立按合法候选投票。没有新增数值身份分。金水目标的完整代理归票权限本轮未重建，警察彼此共知不自动让平民认证他们。

## 单警回应与混合执行

预定首位活警在自己的普通发言轮次决定。首夜没死警、此前出现警队外假警、且假查杀没中警队时，以q报真实验人＋保留内推＋明确反驳，否则暂缓身份仍可普通提名。这个随机数由该玩家私下抽一次；其他警察不抽第二次，知道队伍里预定谁先发言即可，不需要秘密相关装置。q的动作只发生在这个单个节点，之后策略完全相同。

假查杀命中警队时，首位可安排的警察不作可选沉默，按真实验人回应。已有真警公开后不机械追加第二名；如果假跳发生时首位警察已说完，则当前单一发言轮次不给其再次反驳机会。不能把这种情况叫主动藏警。首夜死警另统计；不存在适用q的分支时不作q结论。多匪站队后的4v4对冲需新增团队声明，本轮不实现。

q=0并非所有局面都藏，q=1也非全队跳；只是上述窄条件的单警局部概率。预先固定q网格0/25/50/75/100%，不强求内部混合，可能最优为端点。

## 统计与冻结

训练160000000起2048/单元；新留出161000000起4096/单元。8×4训练、9×4留出（第9行是训练冻结的局部q），合计212992局。参数、代码、训练选择规则在读结果前冻结。相同列跨行保持发牌、验人、刀、假跳目标时点一致；掩码必须逐局相同。

八项主比较：4列各自的memory_evidence及routing在全部局面的胜率差；给Bonferroni八比较正常近似区间及保守Hoeffding区间。其他分层与终局外指标为解释性，给逐项配对区间，不能挑稀有漂亮分支做主结论。主条件仍另报首夜未死警有回应机会，以及首名真警前的假查杀中民/中警分层。报告每条件n、原胜率、胜负改变数、配对方差与未配对参照。记忆机会按“活着旧假警仍在合法候选、今天无该事实再出现”计投票次数，第一轮/PK可能分别计数；不得用次数当独立局数作显著性。

混合探索：只在训练的q0/q100两行×4列经验矩阵上求精确有理数受限均衡；q=训练q100权重。由于只一个可选节点，开局混合两端点可由首警在该节点的局部抽样实现，不需整队秘密信号。浮点PRNG实现q（机器精度），矩阵证书只对经验端点矩阵精确。读取留出前冻结q及双方混合；留出不重新选q、不再解最优值，直接模拟该局部q并核查冻结端点混合的留出上下界。总体收益不是精确已知；训练gap0不代表总体或完整游戏gap0。网格中间q不放入均衡求解，避免把模拟噪声当成非线性收益或“新策略”。

留出不能证明候选集外不可利用；匪只有4种固定回应，没有学习、没有自刀假跳、没有团队拉票对冲、没有自适应生存证据。后续不得按留出挑q继续宣布其为未看数据。跨日票型/公开怀疑/遗言制度继续分开保留。
