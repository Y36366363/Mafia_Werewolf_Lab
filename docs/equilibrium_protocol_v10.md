# v10 公共协调、专门反制与受限混合均衡协议

主配置固定为4警、4匪、8民，采用公开顺序投票。所有策略在正式训练前冻结。

## 非平民探测公共协调基线

`coord_deliberative_*`由全部好人角色执行。首日发言序前半段按公开座位规则提出候选，后半段按当时公开提名领先者收敛；投票时警察优先投已知查杀，其余好人按公开协调目标投票。该协议不要求知道谁是平民，也不以“平民先铺目标”为启动条件。

警察查杀释放分别设为立即、已有公开同目标后跟随、最后一名存活警察再跟随。三者用于识别公开协调收益与私人信息释放时点的交互。单目标强制锁票在正式实验前预检中表现过弱，未进入正式候选。

## 三个匪方回应家族

- 集中目标回应：按公开多数目标的支持者加权，权重2、4、8。
- 分散目标回应：按发起新目标的玩家加权，权重2、4、8。
- 警察跟随回应：按较晚重复既有目标的玩家加权，权重2、4、8。

每个家族只在指定好人目标策略的训练结果上选择一个经验最优回应。未被选中的权重仍保留在扩展矩阵中，防止均衡只覆盖三个获胜回应。

## 冻结扩展矩阵与受限均衡

训练矩阵为7种好人策略×13种匪策略，每格512个自然开局。用精确有理数单纯形求经验矩阵的零和均衡，并直接对所有纯策略重算上下界证书。回应选择和双方混合在读取留出前写入文件。

留出矩阵每格2,048个全新自然开局。训练混合保持不变，报告其面对每个留出匪策略的最小收益、每个留出好人策略面对冻结匪混合的最大收益和样本外间隙。另求留出矩阵的事后受限均衡，只诊断经验矩阵漂移，不参与策略晋级。

混合解假设阵营在局前共享同一个秘密策略索引；普通面杀规则未必提供这种相关装置。即便训练证书间隙为零，它也只是冻结有限候选与经验胜率矩阵的受限均衡，不是完整游戏GTO或CFR收敛结果。
