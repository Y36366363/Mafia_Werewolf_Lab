# 规则合同与首批实验 v0.1

2026-10-10，依据用户对规则问题的回复。核心规则已实现，剩余流程参数化。受限小模型已有精确证书；完整16人GTO没有认证。实现范围及最新实测见 [框架](framework_v01.md) 和 [报告](experiment_report_v02.md)。

## 1. 用户确认的规则

- 目标配置：4 警、4 匪、8 民。
- 匪方杀完所有警察获胜；不使用“杀光平民”或“匪人数达到好人数”作为替代胜利条件。
- 警队每晚共同验一人，结果为匪/好人。允许验己方警察；因结果已知，在不产生额外公开信号的基线中只作为无信息动作。
- 首夜被刀警察可以获得当夜验人结果。
- 死亡不翻真实身份；遗言和跳警均是玩家声明。
- 16人局前三次或前四次死亡有遗言，二者均纳入研究。
- 发言顺序与死者左/右侧有关。
- 允许匪自刀和平民假跳警。
- 内推、拉PK的选择需要作为策略讨论，不能固定为专家经验答案。

## 2. 明示的建模假设，不冒充用户确认

为能实现首个模型，暂设身份等概率分配、警匪各自互认且夜间共享队内记录；好人胜利条件为匪全灭。这些假设与“共同验人”兼容，但超出回复的逐字确认范围。

首夜以秘密同时选择刀/验目标建模，双方不读取对手当夜选择；随后给警队验人结果，处理死亡，再检查终局。最后一警死亡时匪胜，终局之后不再进行有战略效果的遗言或投票。以后夜晚也允许当夜被刀警察获得验人结果，列为可切换假设，用户仅明确确认了首夜。

所有角色暂可作虚假身份和验人声明，包括警察；是否限制警察的虚假声明另做动作空间变体。有限模板之外的暗号、连续时长、语音等不进入初始模型。

## 3. 遗言与顺序的变体

遗言基础定义：按全局实际出局次序计数，包含夜死与白天放逐；前 L 个死者可留一轮有限模板遗言，无后续交流。基线 `L=3`，对照 `L=4`。用户没有明确区分夜死和白天放逐，因此这个计数口径是实验假设。

方向机制分为三个不同游戏：

1. 固定向死者左侧相邻活人开始，沿该方向完成一轮。
2. 固定向右侧，规则同上。
3. 在有遗言且游戏未终局时由死者选择左/右；无遗言则采用预设方向。

跳过已死座位。无夜死或平票无人出局时需要另定发言锚点；首个基线可延用最近死者位置和预设方向。方向由谁决定在用户回复中未明确，因此第3种不是已确认规则。

固定左/右在没有其他左右偏置、且策略和座位一并镜像时是同构游戏；死者可选方向会扩大动作空间，不能当作同一个参数替换。

小配置不援引未经查证的“最常见玩法”。采用与目标模型一致的 `L=min(3,N)` 基线，加 `L=min(4,N)` 对照；当它允许所有关键死亡留遗言时，再用 `L=1` 做机制消融。每个结果明确报告 L，不能自动迁移至16人。

## 4. 内推和PK：规则给机会，策略选对象

“谁可提名、怎么进入PK、怎么投票”是裁判机制；“推谁、是否上PK、报谁好人、拉谁对比”是策略。

先定义两个受限协议，不声称它们就是用户实战中的完整PK规则：

- P0，开放放逐：一轮有限模板发言后，存活者同时秘密投任意其他存活者或弃票；票型在全部提交后公开。唯一最高票者出局；最高票并列则当日无人出局、进入夜晚。
- P1，两阶段PK：第一轮投票与P0相同；唯一最高票者出局。最高票并列者进入一轮PK发言，再由所有存活者同时投PK中除自己以外的候选或弃票；仍并列则无人出局。

两协议中均允许发言时提出一个内推对象或两个PK建议对象；这些建议是可被接受或拒绝的公共消息，不能自动夺走其他人的投票权。P1中的法定PK名单由票型产生，和口头建议区分。

如要研究“提名直接锁定两人PK”，另建P2并明定所有提名如何聚合，不能在P1中偷偷引入。最高票制与绝对多数制也必须分别版本化。

先研究P0，再引入P1并重求；不用在第一个模型里同时放进所有投票变体。

## 5. 新规则改变的首夜推论

### 5.1 不翻身份且允许自刀：首死非警不等于首死平民

警队知道自己的成员。若首死属于己方，他们知道死了警察；若首死不是己方，只能先判定为“平民或自刀匪”，除非已经验过此人或另有合法信息。

匪队知道自己有没有自刀，但普通刀中一个非匪后，仍不能直接知道是警还是民。平民不知道任何陌生死者的真实身份。

因此初稿的 `4/11` 和 `3/11` 是已知特定角色后的组合基线，不能不加条件地作为现实玩家后验。

### 5.2 自刀的条件概率解析控制

先定义固定策略实验：匪队以概率 q 自刀，并在4匪中均匀选择；以概率 1−q 在12名非匪中均匀刀人。不读发言或警队私有信息。身份均匀分配，警队暂不条件化于验人结果。

首死实际角色的概率：

`P(死警)=(1−q)/3`，`P(死民)=2(1−q)/3`，`P(死匪)=q`。

警队观察到首死不是队友后：

`P(死者是匪 | 非警死亡)=3q/(2+q)`。

在相同对称基线下，任意一名活着的未知非警是匪的概率为：

`[4−3q/(2+q)]/11 = (8+q)/[11(2+q)]`。

| q | 非警死者是匪 | 活未知位是匪 |
| --- | --- | --- |
| 0 | 0 | 4/11 |
| 1/4 | 1/3 | 1/3 |
| 1/2 | 3/5 | 17/55 |
| 1 | 1 | 3/11 |

这些是已知固定策略下的后验，不是均衡自刀频率。遗言、验人、座位依赖选刀、公开行动历史以及对q的未知都会改变后验。

### 5.3 首死警报告真结果的收益结构

死亡警察不会再承受“自己跳警以后被刀”的存活成本。警队已经共享验人时，遗言的主要价值是对外传递，而不是让队友重复获取信息。

匪方可自刀并模仿死警声明，所以死者跳警不构成自动认证。真实查杀可能有高协调价值，但必须同时考虑对跳、验人目标也死亡、提名限制、误信假声明和终局结算。

首死警验好人时，报结果可帮助形成公共投票锚点，也可能给匪方后续攻击提供线索；不报则失去公共协调机会。报告某人的非匪身份不必然泄露其他警察，需分别建模具体消息。

### 5.4 剩余警察数量本身有战略价值

匪胜只依赖警察全灭，因此不能用存活好人的总数替代残局状态。例如同样两名匪、六名好人，1警5民与3警3民的终局风险、后续验人和暴露成本不同。

自刀牺牲的除了票数，还有可存活执行夜刀的匪成员；自刀最后一匪在暂定好人胜条件下立即输。任何信息收益必须覆盖这些损失。

## 6. 下一批实验

1. 精确验证上述固定q后验，并核对观察权限。此项是解析控制。
2. 用2警1匪3民做第一个完整小模型：它能表达死一警后另一警继续行动。1警模型留作终局控制，不能承担首死警遗言的核心研究，因为唯一警死亡已经结束游戏。
3. 用2警2匪4民扩展自刀与假死警信号；一个匪的模型中自刀立即匪全灭，无法检验常规自刀战术。
4. 先用P0和固定左向发言、L=3；分别加入P1、死者选择方向、L=4，比较影响。每次重新求解，不借用旧模型证书。
5. 在4/4/8配置保留真实座位，开展冻结对手策略的首日实验，再进入双方策略池扩展。不得用小配置胜率代替16人结果。

当前已完成裁判、合法观察、P0/P1、左右固定方向、3/4遗言、有限模板策略、完整终局模拟、小模型精确受限求解和16人反制评估。死者主动选方向、两个候选的正式提案和狼人杀技能尚未实现。没有声称任何跳警、查杀、自刀、内推或PK策略已在完整16人游戏中最优。
