# v28 冻结方案：首夜死警金水、后续依据与改归权限

2026-11-02；正式实验前冻结，先完成旧种子只读审计。对象是4警4匪8民。

## 策略/参数字典

- `reference`：保留v27 local活警金水接力（第2日起）；首日死者只按原规则报真实验人，不新增内推/委托/最终接力。
- `notice`：首夜死警验好人并真实报金水时，在同一遗言中补原位置后验排序的二人内推、委托该金水；不执行新的金水最终归票。对照额外警察信息/公开授权本身的作用。
- `list`：同notice；金水在普通发言全部结束、投票开始前获得一个最终归票槽，按自身此时信息在原名单中选。若自己已知的活匪全在名单外，可拒绝，不能被权限强迫错投。
- `evidence`：和list拥有完全相同的最终槽；若有下面列明的公开依据，可改归名单外；否则仍在名单内选。不是任意改票、不是给金水警队私有信息。
- `q0/q50/q100`：保留既有首日可选跳藏窗口0%/50%/100%。首夜死警时这个可选节点不出现，因此主死警分支三个q理论上执行相同；检查逐局过程相等，不把它们充当三组独立证据。总体其他分支仍保留q。
- 原8匪列不变：late/decoy为原safe_late/posterior_decoy刀；near/far为早悍跳假查杀对象的后续发言近/远位；restate为原人重申、死后同伴不接续，claim为死后活同伴接续。全部原team票，无新训练回应。
- `dead_clear`：裁判统计用首死为警且首验非匪。只用于分层评价，不给玩家该真假标签。

## 新增动作与信息合法性

主干规则：死亡不翻身份，前三死亡有遗言；透明顺序投票，单轮PK复投后仍平则平安日，允许弃票。信用分与票型学习冻结；验人、刀法和续局策略保持原样。

遗言仍只有一次。新增结构化内容为 report → shortlist → delegate 三字段，只有紧邻同一report的合法字段才可附加，不能等别人说完再补遗言。引擎不鉴真，任意角色可说同类假声明；本轮实际匪候选没有自刀/假金水授权，所以不能把真警来源的结果外推至完整悍跳博弈。

名单用死警自己的警队座位、首验和继承的位置后验排序产生，排除队友及验好者；金水只收到公开名单，不能访问其形成过程的私有数据。notice/list/evidence三者在相同局面的遗言内容相同。reference对notice若有收益，只能称额外信息/授权组合效应，不能归因于金水接力。

最终归票槽是**新增公开协议资源**：普通发言完后受托者可有一条relay。它不同于原桌游仅按座位一次发言规则，不能暗称免费真实桌游规则。list与evidence槽数/时点相同；本轮不比较自己回合发言与最终槽，时点收益不能单独识别。所有玩家均经过同一hook，由自身观察判断是否有授权，不由裁判给全场点名真金水。

公众仅把有效relay解释为死者授权建议的更新，不新增一个独立警察来源，不认证死者/金水身份。若从自己视角能反证来源则拒绝；其他冲突来源仍保留。新权限不强制覆盖私人活匪/私有好人/PK候选合法性。遗言委托当天有效，跨日不自动续成指令；原v27次日起活警接力继续保留。

## 名单外依据（不用信用数值）

1. 某活来源自查自己是匪；
2. 同一来源对同一对象前后报相反结果；
3. **条件性**共享验人冲突：死者A首夜报B好，另一活来源F当天报不同首夜结果。在“警队共同一验、真警报真实结果、不报队友假验”的候选假设下，**若A真则F不能真**。不是直接证明F是匪，也不证明A真。授权建议可以选择F，但来源对跳仍需按观察者原协议处理。

只有实际归票前已出现的报告可作依据；校验relay时截断到relay之前，禁止用后来声明追认。前两种不依赖A真实性，优先于第3种；同类多个目标用原排序破同分。此离散顺序是预设策略，不是最优性定理或身份概率。

## 样本、配对和比较

12好人行×8匪列=96单元。开发185000000起128个seed；新验收186000000起2048个seed；调试187000000起。正式208896次运行，2176个基础seed跨策略配对；不是208896次独立发牌。所有候选在看开发结果前固定，不挑q、不开新匪列、不再搜索seed。

预定三个相邻对照：reference→notice（新增遗言信息/委托）、notice→list（新增最终接力）、list→evidence（同槽下增加有证据的改归权限）。q50×8匪列×3对照×2评价范围（总体/固定首死警验好人分支）=48项主要比较族；用配对正负翻转的Clopper–Pearson边际区间及union bound，同时95%。其他q为敏感性，不选最佳概率。死警分支为前干预条件，所有政策配对mask必须相同。

输出终局胜率之外，首日出匪/出警/PK/平安日、授权与接力覆盖、名单外改归、采纳及改票次数；对每局保存包含所有公开出人/投票/终局以及私有夜验/刀的过程哈希。按对照统计“终局相同但过程不同”，不能用胜率相同代替过程等价。不同存活轨迹的累计次数只作描述，不能混作共同分母因果机制。

新增组件只作用于dead_clear分支，分支外的过程须保持相同（注意report确真是本候选池限制）。检验q在死警分支的过程一致。

## 核验与预设案例

完整适当测试、冻结资产哈希、所有96×2记录/统计检查、各单元首/中/末无包装器重放、reference对v27控制兼容。不是全部正式模拟二次独立重跑。

验收q50每个相邻对照、每种刀×接续模式，各取首个“负转胜”“胜转负”“终局不变但过程不同”案例（seed优先、匪列名字破同分），相同条件案例去重。完整四版本逐步审计，包含死者信息、授权名单、金水所见、最终目标/依据、首日票型和夜验刀。不新增验证样本。

必要负结果照报：如果只改善人为加入名单带来的损失、或仅有局部过程变化而无终局确认，不能宣称超过原基线。保留金水接力机制，不因本轮无增益删去；假金水授权、首日自刀、金水假跳挡刀、全员遗言仍分开待办。
