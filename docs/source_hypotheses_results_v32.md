# v32：死／活来源解释、回应时点与克制补跳（2026-11-06）

本轮先承认：v31 旧接收器的真死警优势含有**方向性偏置**。授权字段触发“优先处理活来源”，并没有证明死者更可信。取消偏置导致旧胜率下降，不构成恢复身份认证的理由。v32 固定修复后的 aligned 接收器，不加入信用权重，不把下列诊断概率用于实际投票。

## 1. 先读策略／参数字典

- **inherited（原防御回应）**：沿用 v31 aligned。首夜死警已报验人后，第一位活警仍可能因警队成员被假查杀而补跳。不是规则强迫，而是原行动生成器的选择。
- **restrained（不重复补跳）**：在警察自己的视角，已听到真实警队队友首日遗言报告时，普通轮的额外跳警改为过。保留验人、私人反证、投票优先级和 PK 限制；不修改 PK 发言。对平民没有注入“死者是真警”。如果死者实际是匪，真警没有这个私人队友条件，仍按原规则行动。不是一般性“遇到悍跳永远隐藏”。
- **late**：safe_late 位置刀；**decoy**：posterior_decoy 位置伪装刀，完整参数继承冻结 v31。
- **old**：首日远位假查杀，之后保留重申、接续；**copy**：符合触发条件时复制死者金水，再正式归一个错误目标；**quiet**：匪方首日不悍跳，仍正常投票和续局。三者都是完整固定行动计划，不能仅凭名字理解为整局只有一句话。
- **false_notice / false_grant**：首夜自刀，假报金水和名单；后者再给授权。当前此两方案首日活匪不悍跳。继承实现还会影响同日被放逐匪的遗言，不是纯粹“只改首死一句话”。保留边界控制，不升为主策略。
- **q=1/2**：原适用分支中的局部跳／藏抽样，概率50%；不是全警队每个人各掷一次，也不控制本轮被抑制的首死真警防御补跳。q0/50/100以后仍可研究，本轮没有重新找最佳q。
- **early / late**：首个活来源的普通发言顺位1–7／8–15；只是固定分箱，不是可信度。**hit / copy / other_clear**：报查杀／报与死者相同金水／报不同金水。**no_live_at_end**：整轮讲完仍无活来源报告，只能在发言结束后使用。
- **2% / 10% / 25%**：人为指定的开局自刀方案总权重；普通六方案等分余下权重，自刀两方案等分。不是从玩家数据估出的真实频率，也不是均衡概率。
- **P/M 等支持标记**：前者是首死报告者、后者是首个活报告者的身份；P警、M匪。它们是身份解释，不是信用分或投票资格。

## 2. 本轮方法与冻结边界

固定4警4匪8民、前三名死亡有遗言、不翻身份、允许自刀、一轮PK后再平票平安日。每单元训练诊断256局、独立验收2048局，共16单元，实际运行 **36,864局**（耗时167.1秒），2,304个不同Nature种子跨条件配对；不能把36,864当成独立发牌数。另32局独立smoke。
训练和验收种子分别从197000000、198000000开始；smoke从199000000开始。事先冻结源代码、配置和协议，未根据训练筛策略、未用验收调规则。训练表只是预设公开事件的频率诊断，没有训练行动器。
主比较在“首夜死真警且首验好人”条件中，比较是否抑制重复补跳；该条件由裁判离线分层，平民不可见。8个条件×终局、首日出匪两指标，以配对胜负翻转的Clopper–Pearson边界加联合界构造16项同时95%区间。自刀列不满足该主条件，明确记为空；全局数字描述，不追加显著性筛选。
平民信息审计预先固定1号座位，仅当其存活且为平民时取样。首死者报金水后，在首个活报告刚出现时截断消息；无活报告则在发言结束取样。丢弃票型，不使用后来发言、夜刀、未来身份。每单元前8个合格前缀另做身份支持枚举。
枚举使用“平民不假跳、真警身份判断真实”两个前提，允许匪任意说谎；不把授权、名单、死亡和位置当真伪认证。枚举忽略共同验人选择与生成行为的概率，是**身份必要约束的超集**，不是当前策略完整生成模型，更不是按世界数量计算贝叶斯后验。另有人工双世界测试同时满足共同首验与同一消息观察，证明至少关键复制金水情形确有不可区分性。

## 5. 为什么还需要策略生成模型？

设H是死者真实身份解释，E是当前已听到的声明与顺位。概率更新需要 P(H|E) ∝ P(E|H,双方策略)P(H)。Nature只给均匀身份发牌；普通刀／自刀选择概率、真警愿不愿补跳、匪何时复制金水，决定事件的似然。知道Nature均匀，仍不足以得到这些似然。

## 6. 哪些依据能用，哪些不能？

- 平民知道自己的身份。有人查杀自己，在“不允许真警假报”的前提下，自己可直接排除该来源是真警；其他平民没有这项私人证据，不能直接复制结论。
- 两个来源对同一人给出相反判断，至少一个不是真实报告。它没有指定谁假，死亡也不能替代证明。
- 两人复制同一个金水，可能双方真、真＋假或双方假。若无“至少一个是真警”的额外保证，多人重复不能自动认证金水。
- 发言顺位、前面是否已经有警察声明、是否遭查杀、后面还有多少发言槽，都是合法可见特征；后面还有多少**真警**未发言不是平民可见事实。
- “真警此时通常不该再跳”可以成为策略似然依据，但要先明确警方确实使用哪种条件规则，并容许匪针对它模仿。不应把用户的战略直觉直接写成零概率。
- 投票站队可作为后续来源条件证据；不翻牌下，裁判知道被放逐者是好人，平民却未必知道，不能让票型更新读取该隐藏标签。

## 7. 可复查的同观察双解释

人工例：1号死者报9号金水；5号活来源也报9号金水；16号是观察平民。可以构造两副合法4警4匪8民身份牌，双方都共同验9号、观察者听到完全相同的声明和顺位：第一副1号警、5号匪（普通刀）；第二副1号匪、5号警（自刀）。因此仅靠这段相同信息不可能保证判对。这个见证证明信息不可识别，不声称两副牌在当前固定策略下同样常见。
真实生成前缀检查256个，其中256个在上述必要身份约束中仍支持两种死者身份；这是固定前缀的逻辑审计，不是胜率抽样估计。详见 `results/v32_diagnostics.json` 的观察和身份见证。

两个实际过程例子详见 [逐局阅读版](source_hypotheses_cases_v32.md)。后置刀例中，补跳后金水误归到真警；不补跳后改出内推中的匪，最终翻为好人胜。伪装刀例恰好相反：补跳使金水归到悍跳匪；不补跳时金水跟到被假查杀的真警，首日错出警。它们展示当前接收器与声明结构的相互作用，不能把成败全归因于未来暴露成本。
