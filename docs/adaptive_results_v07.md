# v07：实时票差、公开平民首发与训练生成条件表

本轮在4警、4匪、8民上执行156,672局完整对局。其中46,080局用于训练九单元条件概率表，24,576局使用独立种子评估4×6策略矩阵，86,016局在4,096个固定首验中匪状态上比较警察早释放、静默和五种平民首发规则。所有对局采用新增的公开顺序投票规则。

## 阶段结论

**实时票差约束消除了固定散票的大部分协调损失，但没有形成稳定匪方收益。**固定3+1在四种好人策略下使好人胜率增加0.39至1.66pp。`combined_live_margin`把匪方多票回合的散票率从固定3+1的99.9%–100%压至16.9%–26.1%，但相对`combined`的好人胜率差仍为-0.10至+1.07pp；四项逐点95%区间均跨0。只在全场最后一票安全时装饰的`combined_live_final`散票率为3.0%–5.7%，胜率也与协调基线接近。当前结论是“票差门控避免明显送票”，不是“装饰票已证明能提高匪方胜率”。

**公开顺序投票揭示了原`coordinate`并不总是同票。**综合评分基线仍有44.8%–64.3%的匪方多票回合出现不同目标，因为同分时各行动者使用独立本地随机数。`live_margin`同时改变了同分破局和装饰条件，因此这里的胜率比较是完整投票策略比较，不能把差值只归因于最后一张装饰票。下一版应先规定一个所有匪可由公开信息和队友身份共同计算的确定性主目标。

**训练生成表在训练集改善、留出集失败。**初始表的训练最差胜率为29.69%，两轮坐标回应后升至35.94%；冻结表在全新留出集的最差胜率却只有24.90%。人工`confirm_mix`达到27.34%，继续保持纯候选第一。这说明128个训练种子上逐单元反复优化产生明显选择偏差，冻结与留出机制成功拦截了错误晋级。

**平民首发的无条件收益很小，警察早释放明显更强。**五种规则只有在首位发言者为平民时启动，启动率47.95%；在全部4,096个首验中匪状态中，偶然对齐率仅2.93%–3.61%。相对静默，规则的好人胜率增益为0.15–0.54pp，而警察早释放为2.54–2.98pp。平民规则的逐点正态区间多为正，但按18项比较计算的家族Hoeffding半宽为5.67pp，所有规则差值均不能排除0，因此不晋级为首日默认动作。

## 方法边界与下一步

本轮公开顺序投票是新规则变体，不能直接与v06同时投票胜率比较。`live_margin`保证的只是行动瞬间主目标仍唯一领先，后续票仍可能改变结果；`live_final`才提供最终票表保证。训练表是有限网格坐标回应，不是CFR遗憾收敛。所有胜率均为冻结启发式续局的策略评估，并非完整游戏GTO。

下一阶段应先修复匪方主目标的公共确定性破同分规则，再把训练拆为互不复用的坐标子批次或使用交叉拟合，减少逐单元重用128个种子造成的过拟合。平民首发若继续研究，应优化“覆盖率×对齐收益”的组合，而不是继续报告稀有对齐分支。

独立核验重算360个训练候选单元的选择路径、24个留出单元、21个首发单元和4,096个开局，并重放63局；全部通过。
