# v49 公开反推反制与有旧票依据的归票

主板4警4匪8民，继承v47的条件板子、第二夜保留两名原对跳者、预备编报和续局。放弃新座位优先，`neutral`为新比较基线，`challenge`增加v48的首日反推记录。共同查杀、q=1/2、信用、私人反证、金水保护、PK与继承的票规则保留。假报告还是50%查杀、其余金水，不研究重报混合。

首日反制只允许被普通活来源直接查杀、报告在自己普通发言前已见、且不是己方首个发言者的匪在自己的提名位置反推。该公开提名替换继承的提名，首轮实际票跟自己的反推，PK继承。不能读取尚未报出的查杀，也不能改变已经结束的发言。好人的反推能力不改。逐个筛查原策略与反制策略可否让同一对原来源活到首日结束。主比较只使用两边都入组且原来源相同的种子，两边独有入组以及原来源不同的数量单列。角色不进入筛选。此设计衡量在同一类可续报开局中反推规则的增量，不估计不同首日幸存面的总策略收益。

条件局各运五组。无／有首日反制各比较`neutral`与`challenge`，形成两项独立接收器差。每个接收器对照必须在第二天首轮投票前完整相同。固定有首日反制与`neutral`，再比较普通预备归票和`backed`归票。仅假报告是金水、且在第二夜已有公开旧票证据时，`backed`把正式归票从对跳者换成另一名尚活非同伙，假报告原样保留。候选排除原对跳双方、拟刀座位、这次金水和历史金水保护的座位。至少两张昨天已结算的首轮票来自仍存活的非同伙、非对跳者，且人数严格多于对跳者。若有多个候选，先按支持人数、再按当时顺序取第一个。这个条件不是分数或概率，未拟合。匪队第二天仍按正式归票投票，PK非法则回退。支持可因跨日变化而消失，报告实际跟票及出人。

正式筛240000000起连续8192个新种子，预检241000000起96个独立种子。三个预设全体条件局的终局配对差以同时95%区间呈现。另报告反推记录覆盖、指向来源、改票、次日出局、两边都输但过程变动，以及有备选机会的条件结果。备选机会预先由共用第二夜前缀确定。所有例子按首次变化、最早增胜和最早失胜选取。先看冻结种子结果，不根据其增加条件或阈值。
