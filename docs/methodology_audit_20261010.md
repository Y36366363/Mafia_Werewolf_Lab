# 方法审计与结果解释边界

日期：2026-10-10。适用于首个可运行框架；本文件区分必须满足的有效性条件、首批实现范围和后续研究。数值结果与执行状态以实验产物及报告为准。

## 1. 三类实验回答不同的问题

| 实验 | 估计或求解对象 | 可以支持的结论 | 不能据此声称 |
| --- | --- | --- | --- |
| 1警1匪2民完整受限小博弈 | 声明规则、有限策略集合下，由开局到终局的期望收益矩阵 | 该矩阵的 maxmin 值、最优混合及可独立复算的矩阵残差 | 原始4人游戏全部合法策略的均衡、16人 GTO |
| 4警4匪8民首日分支 | 在同一开局分支中改变一个声明或决策，随后运行冻结策略到终局 | 固定后续策略下的条件胜率差及蒙特卡洛误差 | 不受后续策略影响的最优动作、把分支赢家拼接后的均衡 |
| 双方策略池扩展 | 枚举候选团队方案的对局矩阵，加入已发现的有效回应 | 受限策略池的混合，以及评估集合内的回应收益 | 完整最佳回应、完整游戏 exploitability 上界、已认证 ε-GTO |

1警模型中唯一警察死亡立即结束，无法回答死警遗言问题；1匪模型中自刀立即结束，无法回答自刀的信号收益。2警1匪3民和2警2匪4民是机制桥梁，分别检查死警报告和自刀交互；16人实验仍须单独执行。

## 2. 纯团队计划合法，不等于混合团队计划可实施

每个纯计划可以由一组局部函数组成：警察只读取警队观察，平民只读取自己的观察，杀手只读取匪队观察。这样的计划无需向平民泄露私有验人结果。但在多个完整团队计划上随机抽取一个共同索引，再让警察和平民都使用这个索引，会引入额外的相关装置。

- 若索引向所有人公开，对手可依据实际抽中的计划回应，普通隐藏混合的矩阵值不再直接适用。
- 若索引只对整个好人阵营公开，需要一个能识别好人、秘密通知好人而不通知杀手的装置；用户的基本游戏规则没有提供它。
- 若每名玩家独立抽取自己的策略，得到的是乘积分布，通常不等于矩阵求出的任意团队联合分布。

因此，首批矩阵求解应明确命名为**允许阵营内部事前秘密相关的受限团队计划基准**。抽取发生在身份分配之前或独立于身份；计划中的角色条件函数仍需服从观察权限。此基准能校验收益枚举和数值求解，但协调能力属于额外假设。它也不是完整实战游戏价值的无条件上界：扩大好人协调能力与限制双方策略集合是不同的改动，不能混为一个单向界。

把相关分布拆成独立局部策略后必须重新评价，不能继承原证书。团队相关和独立行动的差异有原始研究支持：[Zhang 与 An，2020](https://ojs.aaai.org/index.php/AAAI/article/view/5610)。

## 3. 信息权限是首要正确性条件

裁判保存全体真实身份、夜间目标和真实胜负。策略函数只能接收经过裁剪的观察。类型注释、约定“不要读取”或把完整裁判对象放入策略再手工过滤，都不足以构成权限边界。

必须检查以下情形：

1. 构造两个身份不同、但目标玩家自身身份、队友、合法验人、公共历史相同的世界，观察应相同；固定随机流下行为也应相同。
2. 平民看不到警队名单、真实验人或首死真实身份。警察知道非队友死亡，不自动知道是平民还是自刀匪。杀手普通刀中非匪，不自动知道是警察还是平民。
3. 杀手先提交目标、警队后提交目标只是软件调用顺序；第二个策略不能看到第一个当夜选择。投票同理：从同一投票前历史收齐全体选择后才公开票型。
4. 声明“我是警察”“某人是匪”只产生公开消息，不能调用裁判真值直接认证。
5. 夜间验人结果先进入合法警队记录，再执行死亡和终局检查；最后一警死亡后不得凭遗言再翻盘。死者不能继续投票或参加之后的队内行动。
6. 用于配对的公共样本编号、随机种子、分支名称不得变成玩家可反推身份的输入；种子仅属于模拟器。

拥有完整身份信息的策略只可用于单独标注的上界或泄露阳性对照，不能进入正常比赛及测评标签。

## 4. 条件分支的抽样与配对

报告的分支应由裁判在开局夜晚结束时分类，例如 `dead_civilian`、`dead_police_checked_good`、`dead_police_checked_killer`。分类只决定评价样本，不进入任何玩家观察。

先按共同的开局策略完整抽取角色分配、刀人和验人，再筛选符合分支的样本；保存完整合法观察后，为每个待比较动作复制同一状态。其余策略参数和后续随机机制保持一致，运行到真实终局。不要先按真实身份挑选刀人目标，再将结果称为原开局策略产生的条件分支。

如果干预改变的是首夜刀人、首验或自刀，死亡分支本身就可能改变。此时主要比较应是**开局总胜率**，同时报告各分支发生率和条件胜率。不同治疗组各自筛出的“首死警”不是同一组开局；把两者差值解释成同一分支内的干预效应，会引入选择偏差。刻意强制首死某角色也可以研究，但须称为指定状态/干预分布，另存取样合同。

匹配随机数优先按 `样本、天数、阶段、行动者、用途、调用序号` 分域，避免新增一次随机声明后使所有后续随机抽样错位。不同状态中候选集合不同不妨碍合法配对，但每条路径的边际抽样仍须正确。不得重用一个随机量来制造未声明的团队秘密相关。

## 5. 胜率、误差与样本独立性

令每个独立开局编号的结果为 `Y_A,Y_B∈{0,1}`（好人获胜），配对差为 `D=Y_A−Y_B`。估计差值为 `mean(D)`，标准误为 `sd(D,ddof=1)/sqrt(n)`。样本充分时可报告 `mean(D) ± 1.96 SE` 的近似95%区间，并明确方法；胜率本身可用 Wilson 区间。两组独立胜率区间的上下界相减，不能替代配对差值区间。

如果同一个角色布局被多次重复、或者同一个原始开局同时生成多种观察分支，应以原始独立抽样单位进行聚类汇总或 bootstrap。一个开局中的16名玩家、许多投票和多个阶段，不是额外的独立样本。

首批比较属于探索性研究，须保存所有预先选定对照与失败结果。多个方向、遗言数、策略参数中挑出的最大正差会有筛选偏差；对选出的方案使用独立种子重测。若结果极端导致样本差值全为零，普通正态区间退化不证明真实误差为零，可增加样本或使用保守有界区间；精确全空间枚举则没有蒙特卡洛误差。

各结果须报告实际分支样本数及开局接受率；不要把抽样前总局数用作稀有分支的置信区间分母。没有足够精度时写“区间尚无法区分”，不能以未显著优于零证明策略等价。

## 6. 最小有效控制集

| 控制 | 预期 | 识别的错误 |
| --- | --- | --- |
| 随机首验与普通首刀 | 4/4/8下验匪和刀警均为1/3 | 角色分配、目标排除、计数错误 |
| 固定q均匀自刀 | `P(死匪\|非警死亡)=3q/(2+q)` | 偷看死者身份、错误后验、采样偏差 |
| 相同策略与相同随机流对比 | 配对差逐局为0 | 干预遗漏、随机流不稳定、状态污染 |
| 非终局死警报告已知真结果 | 消息公开，但平民只取得声明 | 声明自动认证或真值泄露 |
| 最后一警夜死、最后一匪自刀 | 分别立即匪胜、好人胜 | 终局判定时序错误 |
| 候选剩一人、全弃票、同票 | 按规则合法结束或进入PK/夜晚 | 非法自投、无限循环、零票误放逐 |
| 座位循环重命名 | 对等变策略和变换后随机流结果一致 | 座位编号意外变成信息 |
| 左右镜像 | 规则、策略、目标和方向同时镜像后等价 | 固定方向实现错误 |
| 一个已知可改善的固定对手回应 | 评价器应检测到预期改善 | 策略实际未被调用、差值符号颠倒 |

位置比较有两个不同命题：均匀身份先验下未知位置的身份边际相同；带发言顺序的完整游戏价值可能不同。验证第一个命题不能替代第二个。若策略有“最小座位号领警”等人为锚点，必须同时变换或明确其破坏了哪种对称性，不能只翻转方向就要求逐局相同。

## 7. 反制策略池的审计

首批可从少量可解释策略开始：隐藏/报告真验人、随机水包/报民过、单名内推/双名PK建议、真查杀优先响应、真假警信用权重、随机刀/追刀已跳警、匪假查杀/报假好人、自刀后假死警。这些是用于发现机制的行为模型，其信用权重并非已求得的贝叶斯最优更新。

先固定规则评估策略，再扩大策略集合。新增PK、遗言次数或死者选方向是在改变游戏规则；每个规则变体须有独立矩阵与报告，不能当成同一零和矩阵里由一方单独选择的策略。

收益矩阵训练样本与最终评价样本分开；混合权重只能依训练数据决定。可以在预先保留的候选集合中找最有利回应，但报告“候选中已发现的回应收益”；候选枚举不等于遍历所有合法策略。若矩阵来自模拟，LP残差只说明对该估计矩阵的数值求解精度，不能吸收收益估计误差。

对好人收益矩阵 `A`、行混合 `x`、列混合 `y`，可独立检查 `lower=min(Aᵀx)`、`upper=max(Ay)` 和 `upper−lower`。差值是当前矩阵允许联合计划偏离下的鞍点间隙；须另查概率归一化、非负、目标值一致性。求解器的成功状态不足以替代这些检查。

自刀应比较至少“不自刀”“自刀但不配套信号”“自刀加假死警”“同一假声明不自刀”。否则无法分辨牺牲票数、可信度和交互的贡献。当前对手池下收益差不大，不构成永久删除该动作的依据。

CFR 与策略池扩展是不同层次：前者在给定信息集/动作树中更新局部策略，后者加入完整策略候选。相关的算法适用条件应单独满足；不能因双方阵营收益相反就直接援引普通两人零和结论。[CFR 原始论文](https://papers.nips.cc/paper_files/paper/2007/hash/08d98638c6fcd194a4b1e6992063e944-Abstract.html)

## 8. 进入教学题库前的条件

每题绑定规则版本、观察而非裁判全局、候选动作、固定后续策略或明确求解目标、数值来源与误差。受限均衡题和固定对手利用题应分别标注。没有稳定策略排序的题可以用于讨论不确定性，不宜作为唯一标准答案的评分题。

训练集与测评集按完整信息结构和角色/位置等价族隔离，仅换座位号不能保证是新题。评价撤掉AI后的未见题表现、置信度校准、延迟保持；德州扑克迁移使用另行验证的扑克任务。框架通过测试只说明工程和局部数值证据可用，不表示教学方法有效。

## 9. 执行状态记录

本文件首先提供独立方法审计；不因检查已列在这里而视为已经通过。首批实现审阅已确认：策略函数的输入为观察对象；当夜两方决策读取同一夜前状态；投票先收集后公开；死警取得当夜验人而不取得以后夜晚信息；首日遗言干预只作用于首夜死者。裁判核心主要验证原子操作，完整阶段调度由 `simulation.py` 承担，不能把裁判对象单独称为已经封锁所有非法调用序列的状态机。

已将独立精确矩阵核对保存为 `tests/test_cross_model.py`：把小模型的216个机会情景、18个好人方案、8个杀手方案共31,104条首日路径，通过通用裁判的 `from_roles → resolve_night → observe → add_message → resolve_votes` 重新运行；小模型观察由通用裁判观察投影构造，再通过通用裁判独立递归枚举冻结的后续策略直到终局。144个有理数收益与小模型枚举矩阵逐项完全一致，2项交叉模型测试通过。此核对使用不同的裁判与投票结算，但复用小模型策略函数，因此不夸大为策略逻辑的完全独立实现。

当前矩阵给出纯鞍点 `8/27`，好人采用“真报告、平民过、公共声明不影响投票”，杀手采用“指控第一名其他存活者”。因为输出恰为纯策略，本次具体解不需要秘密相关装置；任意团队混合的整体求解能力仍受第2节限制。这个值只针对声明的18×8策略池：首夜验/刀固定均匀；杀手首日投票固定第一名其他存活者；死民遗言固定过；后续策略冻结。可执行到终局与枚举全部合法策略是两个不同要求。

发言代表采用“本队中按公共发言顺序最先发言的存活者”，随座位和方向一同变换；不额外使用最小座位号作为代表。左右方向对比仍是冻结启发式策略的比较，不能代替新规则下重新优化。声明信任采用预设权重，尚未求解信息历史下的均衡信念。

对首日实验另作64个开局的调用插桩：产生256条后续路径，所有对照、干预及两个对手都复用各自开局的同一不可变裁判状态和种子；原状态无消息污染；传入策略的干预参数仅为动作，未传入分支标签。该批抽样得到首死民37局、死警验好人18局、死警验匪9局，报告分母与各分支实际样本数一致。源码指纹和配置指纹均与当时文件及保存配置匹配。

源文件必须在正式运行前冻结；运行中改代码可能导致各报告的源码指纹不同。验收时应核对每份模拟报告的 `source_sha256` 与运行清单一致，并核对清单中的各产物哈希。当前大配置策略池执行训练样本内选择纯回应、独立评估样本检验，尚不进行混合均衡认证。配对结果另保存适用于独立有界差值的 Hoeffding 区间，避免把零样本方差误读为确定等价。

## 10. v01结果审查与需要修正的启发式

`results/v01` 的清单产物哈希以及各模拟报告的源码指纹经独立核对一致。首批留出样本中，`hit_trust` 对 `quiet_random` 的好人胜率为53.32%，面对 `fake_hunt` 为0%；训练集选出的 `dead_only` 对同一对手为4.10%。这些数字揭示现有启发式容易被利用，不能解释成规则本身决定的阵营优劣。

首日分支的安静对手比较中，水包、死警报好人和死警报匪的配对近似95%区间均包含零；对悍跳追刀对手，许多条件胜率接近零，无法可靠区分单一遗言动作。机制实验也出现大量0/768获胜的组合。全零观测不等于这些机制无效；应保存原始结果，再在预先选定且尚有胜负变化的冻结策略上补充实验。

对种子5100000的逐步回放发现一个应修正的策略解释问题：在 `trust=all` 时，警察会给已知不属于警队的发言者所称“验人结果”加分。例如首日匪7假查杀民4，真警0、8、10在没有私有查杀时也跟投民4。裁判没有泄露身份或把谎言认证为真；问题在于启发式没有利用警队已经互认这一信息。死者信任模式也应同样区分已知警队成员和外部声明者。

v01保留为**天真信任策略的压力测试**。后续版本须让警察不把已知队外成员的声明当作私有验人来源；平民因不知道警队名单，仍可在同一信任模式下响应这些声明。这个修正应改变策略源码版本并重新运行，不能覆盖v01数字。公开提名、行动和推断仍可具有战略意义，不因声明者不是警察而全部删除。

近零胜率还存在无需程序错误就能解释的机制：真警频繁公开身份后成为夜刀目标；匪方通过共同假声明集中4张票，而缺少公开协调的好人票分散。v01策略池尚缺少不直接跳警的警察提名、较强的平民协调及充分条件化的信任回应，故“当前池最稳健纯策略”远不足以代表游戏最优防守。

## 11. v02策略修正审查

v02已让警察忽略已知队外成员声称的验人结果，并保留平民在相同信任参数下对这些公开声明的响应。`tests/test_police_claim_consistency.py` 的两项测试已通过：在配对随机流下，加入外部虚假验人不会改变警察投票；同一声明能改变不知道警队名单的平民投票。v01源码、配置与结果另存档，修正结果应重新运行。

新增警察共同提名使用警队共享验人、互认名单以及公共发言顺序选目标；各成员可以独立算出同一结果，没有向平民额外传递秘密状态。新增杀手共同提名同样只使用匪队名单及公开历史。提名是公开行动，其出现模式会产生身份线索：当固定策略规定警察都提名、平民都过时，对手可能据此追刀提名者。针对只追刀跳警者的优势不能解释成提名确实隐藏了警察身份；策略池应加入读取这种新公开信号的反制，或者明确尚未覆盖该反制。

## 12. 最终产物复核与v03信号反制

最终审计只读取现有数值产物，没有重跑模拟或修改策略。`results/v01`、`results/v02` 中各6个清单产物的 SHA-256 均一致；各自 `source/mafia_lab` 归档代码重新计算的指纹与清单一致；归档配置内容也与清单匹配。v03结果保存在 `results/signal_counter_v03.json`：当前包源码、`scripts/run_signal_counter.py`、配置文件原字节及排序后配置内容的指纹均与报告一致。

v03固定3个好人方案、4个匪方案，每格1,024局，共12,288局；12格共用同一组开局种子用于配对，不是12,288个彼此独立的开局。独立复算确认：每格原始二元胜负长度、胜场、胜率、首死计数及夜数/死亡数边界正确；矩阵与原始记录一致；6组配对差值、改善/恶化计数、正态区间和 Hoeffding 区间均逐项一致。相同种子产生的首夜摘要也全部一致（首死民683局、警341局，首验匪338局）。这些是产物完整性及统计复算证据，没有将其扩大为独立实现全部16人游戏的证明。

保持好人提名方案、匪声明方式和自刀率不变，仅将夜刀规则由“追刀跳警者”扩大为“追刀跳警者或提名者”，得到：

| 匪方声明方式 | 只追刀跳警者时好人胜率 | 同时追刀提名者时好人胜率 | 配对差值及近似95%区间 |
| --- | ---: | ---: | --- |
| 每日假查杀 | 961/1024 = 93.85% | 33/1024 = 3.22% | −90.63个百分点，区间[−92.43, −88.82] |
| 匪队模仿共同提名 | 265/1024 = 25.88% | 5/1024 = 0.49% | −25.39个百分点，区间[−28.06, −22.72] |

第一组有929局由好人胜变败、1局由败变胜，第二组分别为260局、0局。两个保守 Hoeffding 区间也均位于零以下。这里的差值方向为好人胜率“信号追刀减跳警追刀”，负值表示匪方新回应有效。对照与干预必须使用同一声明方式；不能拿不同列同时改变假查杀、提名和夜刀后只归因于信号利用。

其余两个不发提名的好人方案产生4组逐局完全相同的配对结果，符合代码中的阴性对照：杀手先排除匪队成员，匪方自己的提名不会新增合法攻击目标；好人也没有发出新的提名信号。样本区间退化不是普遍策略等价的统计证明，但当前冻结策略的行动规则解释了为何这一扩展没有可用的新目标。

本阶段支持的具体发现是：**共同提名在原有对手池中的高收益会被利用提名者身份线索的合法回应大幅削弱**。它没有证明所有提名策略都差，也没有求得最优提名频率、平民掩护比例或16人均衡。下一轮应保留原策略与反制，再研究平民也提名、警察选择性提名及双方重新适应；不能只训练对抗没有读取新信号的对手。

审计独立性分三层：小模型使用独立裁判路径并复用策略函数；首日开局通过调用插桩检查信息及配对；最终数据从原始记录重新核算统计量和指纹。16人策略、采样器与游戏终局尚没有第二套完全独立实现，且胜率区间仍属探索性逐点区间，不能替代完整游戏或教学效果认证。
