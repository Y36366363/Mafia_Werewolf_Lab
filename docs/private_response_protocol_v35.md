# v35：私人来源条件下的跳藏概率，冻结协议（2026-11-09）

## 问题及研究优先级
上一轮first_live的收益随局面变号，不设为默认；本轮只保留一个小型对照。conditional_gold保留实现及历史报告，但上轮终局逐局与原接收器一致，暂不继续扩展。本轮主接收器original，信用冻结。优先研究警察**私下知道首死跳警者不是警队队友**时的回应，避免把真死警额外暴露成本一起改变。

## 策略及参数字典
- legacy：v34 self警方规则、original平民接收器，含旧局部q50，原样基线。
- dead_q0 / dead_q50 / dead_q100：只修改如下私人条件：首日、首死者已遗言跳警或报验人、该死者不在自己警队。警察在自己普通轮发言时，检查是否已有活警队友公开；若无，最早仍有普通轮机会的警察做一次局部随机选择，分别0%／50%／100%报告真实首验，保留原内推和归票。此处并不要求此前活匪再次悍跳：死者的假警声明本身就是回应依据。
- q是这一次动作的概率，单位为[0,1]，非信用分、非身份后验。用既有该玩家该轮的独立随机流抽样，无秘密相关装置；其他警察根据自己已知队友的公开普通轮发言知道机会已经过去，不能重复抽样。若抽样后隐藏，后面仍可能有本人被假查杀的防御，但不重新抽q。
- 本人此前被外部来源查杀时优先真实回应；已有活警公开则不再新增普通轮警察。故q0不等于所有警察必定整日隐藏；q100也不保证每局最终有机会回应，若没有该私人条件则不适用。
- 若首死者确为警队队友，或未遗言跳警，则完全继承v34 self；不改变PK发言、后续日发言和信息接收。真假判断来自警察自己的队友名单，不给平民传角色标签。真警真实报验、平民不假跳前提继续保留。
- dead_q50_balance：相同新q50警方规则，只将平民接收换成v34 first_live首日风险控制；次日起恢复original。只一个局部对照，不学习平衡概率、不继续扩大平衡规则。
- 七匪条件继承v34：late_old/copy/quiet普通safe_late刀；self_quiet、self_copy_early、self_copy_team_pass/relay自刀静默、复制非匪金水、两匪保第三匪不接力／接力。假金水可同窗发假归票，不重训匪最佳回应；列数不代表自刀权重。

## 实验与统计
5好人方案×7匪计划=35单元；训练诊断128、独立留出2048／单元，共76,160次完整终局模拟；2,176个Nature种子跨方案配对。另70局smoke。先过单元／smoke再冻结源码、配置和协议；不根据训练筛选策略、留出后不调q或换种子。

主要比较：每匪条件 legacy→dead_q50、dead_q0→dead_q50、dead_q50→dead_q100、dead_q50→dead_q50_balance，共28比较，终局好人胜率与首日出匪两指标=56项同时95%区间，沿用配对翻转Clopper–Pearson及联合界。主比较全发牌，另报私人条件适用局数、实际抽样局数、真实回应覆盖和合格假金水数量，不能把稀有分支代替总体。

首夜相同逐局核验。所有普通刀首死非匪，不触发新私人条件；前四方案对普通刀应与legacy完整轨迹一致（平衡行除外）。自刀但真警尚未见假声明不允许提前使用分支；局部动作仅读Observation。

完整终局、首日出匪／死警、首日公开警数、次夜死警均记录；不以短期指标择策略。假金水资格按v34公开门离线评估：所有报验是否同指B、来源是否反驳；不启用conditional_gold优先。不同q使公共历史不同，不能把资格改变当作在相同信息上校准概率。

每单元每阶段3预定种子完整重放；legacy与v34直接对照。检查一次局部抽样、公开后不补第二警、私人反证／PK／次日起正常接收；样本首死真警不进入私人分支。固定1号合格平民前缀每单元首例保留身份必要约束检查；计数不是后验。事后首例过程案例只作说明，不作为额外独立验证。

## 解释界限
这里没有拟合完整策略生成似然、没有校准来源后验，也没有让民方根据警方新q重新学习信任。q50若有收益不等于最优混合；需证明双方反制下的相互无差异才可讨论均衡概率。本轮保留双方固定计划、所有种子和旧对照，不以更好数字扩池。

如果明知死者假跳时积极回应提高胜率，而真死警分支保持相同，就支持分开条件策略；若收益为零或下降，需检查当前平民采纳／续局，不能直接声称隐藏必优。自刀相对普通刀的盈利性与来源混淆价值仍分开。信用、复杂票型、跨日委托、公开怀疑及遗言制度另待讨论。
