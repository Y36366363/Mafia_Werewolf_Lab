# v09：多区块复验、自然开局与公开反制

本轮在4警、4匪、8民上执行209,664局完整对局：98,304局复验冻结v08条件表，49,920局完成三折探测选择和独立验证，61,440局用于最终自然开局留出。

## 阶段结论

**v08交叉拟合表的候选池稳健性得到复验，但不是逐对手支配。**它在4个独立外层区块中赢得3个区块的纯策略最差胜率；合并3,072局/格后最差胜率为27.41%，高于`position_mix`的24.54%和`confirm_mix`的21.29%。它面对`origin`和公开跟随诱饵时低于`position_mix`，但在综合评分族上补回更多，因此只支持“扩展候选池中的稳健折中”，不支持逐列优势。

**新增公开反制改变了弱策略的最差对手，却没有击穿冻结表。**`echo_mimic_det`根据公开历史追踪重复提名者，并跟随最近合法目标制造伪对齐；它把`confirm_mix`的合并最差胜率压至21.29%。交叉拟合表的最差对手仍是`combined_det`，说明表的主要风险仍来自普通协调匪票，而不是这次新增的公开诱饵。四种不装饰的确定性匪策略在全部复验中非预期散票仍为0。

**8位分散探测在自然开局与新反制下通过三折选择、独立验证和最终留出。**最终2,048局/格中，其最差胜率为17.14%，警察早释放为5.18%，静默为4.05%。相对早释放，五种对手下的配对增益为6.25–29.93pp；每项保守Hoeffding区间下界均高于0。该策略在当前冻结续局模型中可以晋级为下一轮默认候选。

**核心机制更接近公开搜索与协调，而不只是查杀对齐。**8位分散探测的全局查杀对齐率只有9.33%；相对静默，它在首验中匪分支提高2.03%–15.94%，在首验好人分支提高8.39%–27.25%。后者同样显著且通常更大，因此v08的“覆盖×对齐”解释需要扩展为“公开目标覆盖×协调收益＋私人信息对齐收益”。

**目标集中带来更高平均收益，也带来更差的对手下界。**三种8位策略平均提名数完全相同。单锚点平均覆盖1.49个目标，平均胜率37.17%、最差胜率12.89%；分散策略覆盖3.76个目标，平均胜率28.47%、最差胜率17.14%。集中策略更擅长统一票型，分散策略对`origin`反制更稳健。

## 评价边界与下一步

本轮仍使用冻结启发式投票与续局。公开探测在该模型中修复了大量好人协调失败，所以绝对增益可能对好人基础策略过弱高度敏感。下一阶段应让好人获得不依赖探测的公共协调基线，并让匪方学习针对固定锚点、目标分散和警察跟随时点的独立回应；之后再求扩展矩阵的受限混合均衡。当前结果是策略评估与候选池反制，不是完整游戏GTO。

独立核验重算128个复验单元、90个拟合单元、15个验证单元和30个留出单元，核验9个互不重叠种子区块并重放263局；全部通过。
