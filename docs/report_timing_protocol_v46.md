# v46 首次公开、跨日新报告与接续风险

冻结两个相互独立的问题，主板4警4匪8民。固定v44的q=1/2、共同查杀、信用、验刀、遗言和PK流程。比较前缀时使用同种子，保留完整终局和原始过程数据。

1. `greedy` 等价于v44 `copy_both`。`lookahead` 仅在第二天预计多一票时检查，从原归票已验匪换成首日跳警并假查杀的已知匪，会留下有两名本队公开报告支持的真查杀，同时旧假查杀对象仍活且并非警方已知匪。如果两种风险同时存在，保持原归。仅用警方当时已有的验人、队友和公开前缀。这是一个针对v45的布尔预警，没有预测后续具体匪、夜刀结果或胜负，不惩罚两票及以上增益。两票门槛不是训练结果。
2. 在来源时点实验四组里，已有公开报告槽的活警第二天起报当晚实际验人，原悍跳者可以在原普通发言槽补报告，接续匪沿用同一槽，旧正式归票照常生成。`echo` 允许在自己发言前可见时复制当日活来源，否则复制可用遗言，最后重申旧假查杀。`distinct` 优先报当前顺序上第一个尚未被公开报告过的非匪，假称查杀，找不到时回到`echo`。匪只知道自己人及当前公开前缀。四组都继续使用继承的当日归票预测，预测器未针对新接收器训练。
3. 来源比较只改第二天起平民首轮投票。恰好两名合资格的活归票者给出不同合法目标时，若候选合并或冲突仍未决，允许以下两种有限优先。先检查两人当天报告完全相同，此内容若在最早报告前已出现于公开发言或遗言，则不因活来源之间的顺序给优势；否则优先采纳首先公开该说法的归票。然后检查两人此前都在普通发言跳过警，若仅一人报告此前未被任何人公开报告过的座位，则优先采纳该归票。未报告或重复旧座位在这个窄条件下不能取得新信息优先。私人反证、合法候选、原金水保护和共同查杀优先先行。PK票继续用v44。这里的优先是可被反制的动作规则，不是可信概率或强制放逐后报者。

历史六局仅检查 `greedy` 哈希和 `lookahead` 触发机制；正式固定231000000起连续2048个此前未用种子，6组各2048场。预检8个不同种子。按三个预设配对分别报告增失、同时95%区间、首日一致性、第二天出匪和第三天接续；来源规则另报覆盖、改票、被优先来源赛后角色、活人重复和不同目标。对比只涉及固定整局策略，来源四组与风险两组的报告协议不同，不跨区块估计单因素差。

固定同种子机制案例按首个改变票的种子、历史六局以及当前反例筛选。机制案例不另估计胜率。若触发稀少，完整报告原分母；不追加种子追逐效果。后续正式推广依赖新实验证据，完整游戏均衡另论。
