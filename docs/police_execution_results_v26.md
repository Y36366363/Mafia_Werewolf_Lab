# v26：验人信息与执行归票分开；来源条件票型先作小试验

2026-10-31。先验证警方执行归票，再单独比较票型；不把二者揉成一个增益。本轮未调用LLM API，也未按训练或留出数字选新策略/q。

**共同规则：** 主配置4警4匪8民、警互认共享验人、真警只报实际验人、死亡不翻身份、前三死亡有遗言、可弃票、一轮PK再平票平安日。普通投票是继承的公开顺序投票，各票不可撤回；全轮完成后才进入新的票型计数。不是同时投票。规则允许自刀，但本池无自刀；无平民假跳。gap验人、等权位置似然、二人内推不变，2%仅在好人位置似然假设，未加到实际匪刀。

**q窗口：** 首夜未死警、预定首警仍有自己的发言机会、假警已发言且假查杀没中警队时，才由这一个警察抽样；首日被打中警队的既定必答及后续策略不变。执行归票从第二天才开始，不借机制比较改首日q。

来源信用继续冻结。source_credit=True是兼容字段，routing=evidence没有调用数值信用；remember=True保留跨日私人证据，history=False仅停用旧票型加分模块，和本轮独立vote_history开关不同。

## 本轮结果先看这三件事

- 明确执行归票：八个预定q50比较中，4项同时95%区间全在零上，0项全在零下，其余未分辨方向。不能只因动作更一致就宣称终局改善。
- 票型小试验：四项中，2项区间支持提高、0项支持降低；是否覆盖到可决策局面另表报告，不由胜率零差直接推无用。
- 死亡仍不认证身份。公开报验人与今天执行目标可以不同；当前验人不是唯一已知匪时，报5、明确归3、实际投3是合理的一致行动。

主要提升集中在固定的接续跳警条件，而原人重申条件增量很小。对手可以选择不接续，不能把19%—27%的条件胜率写成总体稳健胜率；q50八个原条件的经验最差列仍约5.76%。本轮未测试匪不悍跳或重新选择发言时点的最强回应。

## 执行归票具体改了什么

警察视角包含队友与共享验人，平民没有这些秘密。旧规则可能报“5是匪”，警队却按所有私知匪排序去投3，平民只读到5的验人。现在同一个原有发言者保留真实report和shortlist，再明确说“今天出3”。公开建议路由优先读这个当日accuse；警方也跟首个真实队友的合法私知匪执行目标。不是让平民知道警队名单。原内推仍是怀疑名单；明确出人可指向名单外、警队已有私人反证的目标，不再把“名单里选谁”与“今天必须出谁”混成一件事。

没有额外发言轮次或新增警察跳出，但确实增加一条声明内容，所以这是**公开协调协议干预**，不能说成完全同语义预算、纯改投票的一致性修复。匪也能使用同一合法accuse模板；固定反制仍可重申、接续、冲票，本轮未学习最强回应。公布执行目标与警队跟随是在同一协议中一起改变，尚未做二者独立贡献的分解，不能把全部增量归因于某一行投票条件。

调用只在原警察自己的普通发言位置，前后位由既有座位/死者决定，没有强行把警察移动到前置位；因此本轮不能声称已检验“前置位一定最佳”。金水接力归票未加入，需独立规定委托与可疑来源，不把单方金水当裁判认证。

## 新种子与配对方法

主比较6行×8旧匪条件48格；票型小试验增加6格，54实际单元，非完整7×10矩阵。训练179000000起每格512局，新验收180000000起每格2048局，共138,240次正式模拟。没有按训练选择q/策略；全部预定小试验也照常运行，不以主实验数字决定是否加入。

同q的legacy/aligned第一天和第二天普通发言前前缀逐局相同；aligned/history直到第二天第一次投票前逐局相同。后续不同死亡会改变验人、发言与刀，不强行保持不可能相同的续局。

八个alignment q50是一个同时95%比较族；四个history是另一族。分别给CP正负翻转概率组合区间、正常近似、Hoeffding；两族不能合称12项整体95%。CP在正式训练前规定，需每比较跨seed iid模拟假设，列间共享seed不需独立；不是收益无误差或有理数均衡证书。

## 来源条件票型：到底如何加减

这不是重新启用信用。对已完成投票，依据观察者当时的合法信息，每名投票者每天最多一个计数：

|行为|计数|解释|
|---|---:|---|
|投私人已知匪|−1|降低对该投票者的怀疑排序；倒钩也可获得它|
|否则投私人已知好人|+1|可能跟错票，不能直接判匪|
|否则跟已被自己合法反证的来源，且无未反证声明源也推同目标|+1|来源条件关联，仍非身份铁证|
|其他/弃票|0|不因弃票或改口本身惩罚|

+1/−1是人工等权的“日证据计数”，无校准，不是概率。累计在[-完成天数,+完成天数]，同日PK最新完整结果覆盖首轮，避免一日重复计分；目前不把后来验人回填成历史时点已知。旧日死亡也不提供阵营标签。公开金水保持来源关系，没有直接变私人确证。

仅当原路由给出至少两个未解决候选时，先按怀疑计数较高者投；同分沿用旧位置排序。不得越过金水保护、私人已知匪或唯一明确建议。前置/后置改变归票及PK新增信息不会因为“声明与票不同”自动受罚。部分平民没有可用确证，计数覆盖低是应报告的结果。观察者知道某源是假，不代表其他投票者当时也知道，所以+1仍可能误伤合理跟票。当前只处理轮次、历史前缀和候选合法性，尚未完整建模每个投票者的替代选择或改归理由，不能称完整票型推理。

保结果倒钩只在“当前目标票数>其他最高票+全部尚未投票人数”时触发，最后活匪可投非自己的队友；无论自己和后续怎么投，队友本来就会出局。它说明投已知匪可以被伪装，不表示主动卖队友从无收益。这里只在两组预定条件运行，不能称全反制池。

本批伪装刀条件的票型增量约1.27个百分点（同时区间+0.41至+2.11），值得继续；后置刀约0.29个百分点（−0.21至+0.80），尚未分辨。两种投票模式的相同终局统计不是四份互相独立复现，同一seed配对相关。

事后追加、复用已选案例180000002可看到具体伪装：13号平民私下知道首日查杀自己的1号是假警，首日12号匪曾投自己，因此在内推10/12中由10号民改投12号匪。保结果倒钩模式下，12号已跟票必出的1号，其日计数从+1变−1，13号不再通过该计数优先投12，回到10号。两侧最后仍输，说明终局零差也能掩盖局部信号被洗掉。该追加例保存在results/v26_bus_signal_example.json，不作新确认数据。

计数启发式若没有稳定终局证据，不晋升默认策略。零差要结合改票覆盖及bus是否触发，不把“少数改票而未改变结果”写成所有票型推理都无用。更强分票、主动卖队友、诱饵与来源条件更新仍待单独设计。

对旧174000033开发例的legacy/aligned重放单独保存，不算新确认；旧例中第二天10号警仍报5号真查杀，但明确归3号；三名活警都投3号，最终放逐由旧5号匪变为3号匪。验人信息与执行目标不同可以保留，真正要消除的是未表达的执行意图和未跟随合法执行目标。

## 什么时候接入LLM API

目前还不用把LLM放入主模拟。此次问题可用可复查的结构化规则定位；LLM不会自动解决来源、时间或权限错误，也不能把其解释当真实身份或均衡证据。本轮没有API请求或外部调用费用。

更合适的切入点是：明警/金水的建议权限、执行目标、跨日信息和票型前缀已经稳定可重放；接下来真正需要研究的是语言歧义、临时改归理由、诱导或说服。不必等完整GTO；只要核心信息权限和对应任务的动作接口可复查，就可先设计小批冻结案例的“影子解释/动作建议”，不改变正式策略，并让用户先判断几例再比较模型建议。

影子输入只给该玩家Observation：自己的身份/合法队友与验人、截至发言时的公开历史；删除赛后roles_evaluation_only、未来票和未来验人。输出限制为合法声明/提名/投票并附引用来源。记录模型/提示词版本、随机设置、成本、失败与权限违规，再用新留出比较。若切入自然语言，双方需相同信息与动作/发言资源，分开比较语言解析质量和整局胜率；不要把更长发言、额外思考或裁判真相混作策略收益。

LLM可以辅助检验人类可理解性、解析自然语言、提出候选策略；裁判、信息投影、收益统计和精确证书继续由程序检查。开始这些有费用的API实验前，需另定预算和模型，不在今天自动接入。
