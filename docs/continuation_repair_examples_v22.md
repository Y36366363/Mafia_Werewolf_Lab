# v22 修复怎么理解：三个小例子

这些是规则解释；实际收益以冻结新种子结果为准。

1. **A死了，B不是自动下一位。** A、B都曾跳警，声明互不相容。A被放逐并不证明A是假警，也不证明B是真警；历史疑点保留，但不能仅因A死了，就给B生成“今天必须出”的指令。若活着的C又和B形成当前对跳，B仍可进入正常比较。

2. **旧查杀没有被删除，但行动资格不能永续。** A第一天查杀民C，第二天A已死且没有新信息，不能单凭第一天这句话自动把C当成第二天归票。C自己的私人反驳继续保留，旁观者不会自动知道C是民。若有新的相关声明或证据，需要按新信息处理。

3. **今日遗言没有被禁言。** 真警A第二夜被刀且仍有遗言资格，拿到当晚验人后报活匪D。这个第二天的新报告仍可作为今天的未认证建议。新规则不是“死者说话都不算”，也不是把所有新声明认证为真。

本轮两项修复从第二天才启用，因此所有方案第一天及第二夜刀验完全相同。信用分冻结，回应概率保持50%，不额外改变验人、刀法、PK或遗言制度。
