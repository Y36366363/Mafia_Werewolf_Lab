# 警匪游戏研究设计 v0.1

日期：2026-10-10。本文保留初始研究设计。已有实现及测试见 [框架](framework_v01.md) 和 [首轮报告](experiment_report_v02.md)；核心规则见 [规则合同](rules_and_first_experiments_20261010.md)，完整16人游戏尚未求解。

## 1. 研究问题与边界

目标配置为 4 警、4 匪、8 平民。去掉语气、表情、熟人印象等面杀因素，保留规则产生的信息：身份、夜间行动、公开声明、发言顺序、提名、PK、投票及死亡。

“形式判断”仍包含信号博弈：玩家为何声明某种身份、别人为何相信、杀手如何模仿，以及声明如何改变之后的刀人和投票。不能把谎言全部删除后，继续声称解决了悍跳问题。

所求最优策略通常是完整的条件计划：在某个角色可观察的信息历史下，以什么概率采取每个合法动作。它不是知道全场身份后的上帝视角答案，也未必是唯一策略。

有限游戏在通常条件下存在混合策略 Nash 均衡，但这不等于易于计算，也不意味着任何多人学习算法都收敛到该均衡。两阵营收益相反，不足以把分散信息的多人游戏当作普通两人零和游戏。

## 2. 必须先冻结的规则

下表保留初始规则审计清单；用户后续确认的取值及剩余研究变体以规则合同为准，不能依“常见玩法”自动填入生产配置。

| 项目 | 需要确认 | 会影响的问题 |
| --- | --- | --- |
| 胜负 | 匪全灭则好人胜？匪胜是警全灭、民全灭、两者任一，还是人数优势？何时结算？ | 警察暴露、自刀、所有残局价值 |
| 队内信息 | 警察互认？杀手互认？夜晚能共同商议并共享历史吗？ | 合法信息集与团队协调 |
| 验人 | 全警每晚共同验一人还是各验一人？返回匪/非匪还是具体角色？能验谁？ | 信息获取速度、验人价值 |
| 夜晚时序 | 刀人与验人是否同时？被刀警察是否拿到当夜结果？最后一警死亡是否先结算？ | 首死警察能否报告验人 |
| 死亡信息 | 是否翻身份？首夜、以后夜死、白天出局各有无遗言？ | 声明可信度与信息传递 |
| 发言顺序 | 起点由首死者、邻座、随机或固定号码决定？正向/反向？每人几轮？ | 座位的战略价值 |
| 内推/PK | 谁能提名？人数上限？上PK后怎么发言和投票？平票如何处理？ | 候选范围与票型协调 |
| 投票 | 同时或顺序？是否公开？能否弃票、投自己？多轮如何处理？ | 信息泄露、平票与协调 |
| 特殊动作 | 杀手可自刀？平民可假跳警？死者能否继续交流？ | 信号混合与合法策略空间 |
| 初始分配 | 身份是否在座位间等概率分配？有无先验偏差？ | 座位对称性与概率基线 |

“扔水包”“内推”“拉PK”须定义成动作与规则效果，不能只存文字标签。

## 3. 不能泄露给策略的信息

裁判状态保存全部身份；玩家观察分别生成。

- 警察：本人身份、规则允许的警队名单/共享记录、验人结果、公开历史。
- 杀手：本人身份、规则允许的匪队名单/共享记录、己方夜行动、公开历史。
- 平民：本人身份及公开历史；不能看到警队名单或私有验人结果。
- 所有玩家：座位、存活、合法可见的票型、发言及身份揭示。

同一玩家无法区分的隐藏世界必须给出同一个行动分布。已知“首死实际是平民”的裁判分支，并不表示场上所有人都知道他是平民。

警队共享信息可以在允许的阶段形成联合决策；这不允许平民在白天无条件使用警队信息。若研究团队联合最优，必须声明其可用的是事前约定、公共随机化、队内私聊，还是其他协调机制。

## 4. 第一批无需模拟即可验证的基线

下面只是组合概率，不是整局胜率或 GTO。假设身份均匀分配、警/匪互认；警队共同验一名非警，匪队共同刀一名非匪，首夜无额外信号且不自刀。

### 4.1 首夜验人和刀人的命中率

警察知道 4 个警察位置，剩下 12 个位置中有 4 匪、8 民。任何单个未排除位置：

`P(验到匪) = 4/12 = 1/3`。

杀手知道 4 个匪徒位置，剩下 12 个位置中有 4 警、8 民：

`P(刀到警) = 4/12 = 1/3`。

即使己方座位相邻、分散或扎堆，在这个均匀先验下，任何单个未知位置的角色边际概率仍相同。但目标位置与己方座位的关系可能影响之后的发言、传信和投票，因此相同命中率不证明相同整局价值。

如果整个规则与信息历史在交换两个未知座位时都不变，它们才是策略等价目标。存在座位顺序机制时，需要重新求解，不能以命中率相同消掉位置变量。

### 4.2 已知首死平民后

如果警队通过合法信息确定死者是平民，且尚无其他排除信息，在 11 名活着的非警中有 4 匪、7 民：`P(验到匪) = 4/11`。

如果匪队确定首刀是平民，且尚无其他信号，11 名活着的非匪中有 4 警、7 民：`P(下一刀命中警) = 4/11`。

这里的警察数字适用于死亡已知后的新验人决策或重新条件化，不是首夜事前验人概率。现实行动史有选择效应；此前的声明、验人和投票会改变后验。

### 4.3 已知首死警察后

若匪队依法获知首刀是警察，且尚无额外信号，11 名活着的非匪中有 3 警、8 民：`P(下一刀命中警) = 3/11`。

如果不翻身份，杀手不能因裁判记录“首死警察”就直接得到这个后验。

### 4.4 没有额外信息的平民水包

在对称局面、没有私有线索且尚无信息性行动史时，平民随机点名不会提高识别匪徒的能力。但它可能作为公共随机选人机制、协调投票、诱发回应或占用PK名额影响胜率。

因此可以证明“无额外角色识别信息”，不能直接证明“扔水包严格劣于报民过”。如果报民可被匪模仿，报民也不自动成为可信身份信号。

## 5. 把用户的问题改成可检验的策略比较

| 问题 | 首批候选动作 | 比较时必须一起建模 |
| --- | --- | --- |
| 首夜如何按位置验人 | 随机未知位；近/远己方；早/晚发言位 | 警队自身座位、目标的后续发言价值、结果传递和存活 |
| 首夜如何按位置刀人 | 随机非匪；邻接/远离匪队；改变发言起点 | 夜晚时序、遗言、发言和投票顺序 |
| 首死民，遗言怎么说 | 报民过；随机水包；预先约定的公共提名 | 谁知道死者身份、提名规则、他人回应策略 |
| 首死警，验到非匪 | 不跳；跳警不报结果；跳警报真结果 | 同伴是否已持有结果、可信度、身份暴露、被验好人的协调价值 |
| 首死警，验到匪 | 真查杀；暂不报；给候选范围 | 查杀能否促成放逐、PK机会成本、匪队反制、终局时序 |
| 内推与拉PK | 单候选；双候选；查杀对照候选 | 候选是否合法、投票机制、真假警竞争和信息暴露 |
| 警察没死，匪是否悍跳 | 不跳；报假非匪；报假查杀；对跳 | 真警的响应、平民如何更新信念、匪队队内协调 |
| 匪自刀是否入混合 | 不自刀；自刀指定匪并给预设遗言 | 自刀是否制造可信警身份、后续票数、死亡信息和立即终局 |

“验到非匪”与“可信地让所有人知道他是非匪”不同。信息传递不可信时，真实查杀也可能无法转化为放逐；胜率必须算到终局。

首死警的死亡是否暴露其他警察，取决于规则和他说的话：单独报本人身份不必然暴露同伴，公布队友或特定协调行为才可能泄露。

## 6. 由简到繁的研究顺序

### S0：规则合同与解析控制

固定规则后实现角色分配、夜行动、结算、遗言、PK和投票；先核对首夜概率、座位重命名对称性和观察权限。不允许控制器偷看身份。

### S1：小配置完整博弈

从 1 警、1 匪、2 民的模型开始；如果目标胜负规则使它过早终局、无法表达要研究的机制，改用 1 警、1 匪、3 民或 2 警、1 匪、3 民。必须沿用声明的规则，不为数值好看临时改变胜负。

动作先限为有限模板：报民/报警、报一条验人声明、提名一人、合法投票。枚举合法的角色条件策略与最佳回应，获得能独立核对的小基准。模板游戏的均衡仅针对该模板游戏。

### S2：16 人首日受限实验

保留 4/4/8 配置，分别研究首死民、首死警验非匪、首死警验匪的分支。先冻结后续策略，比较行动导致的整局胜率。

这一阶段是固定策略评估，不是完整 GTO。若只模拟首日，必须有明确终局收益，或标为有误差的 continuation-value 模型；不能把首日投中匪的概率冒充整局获胜概率。

三个分支的发生率受双方首夜策略影响。条件分支的最佳行动不能独立拼起来，就宣布得到完整游戏均衡；扩展博弈还须回到根节点重新求解。

### S3：受限策略空间的相互适应

把已定义的候选策略放入 restricted game，加入双方合法最佳回应，重新求解和独立评价。对手固定时的优势单独报告。

“求受限均衡 → 搜索能利用它的回应 → 加入 → 重求”的想法更接近 double oracle / 策略池扩展；CFR 则是在给定动作树中按反事实遗憾更新各信息集的策略。两者可以结合，但不是同一个操作。

多人分散信息模型不能直接套两人 CFR 收敛证明。小规模可先枚举可执行的完整团队计划，用零和矩阵求解；其团队计划必须服从各角色观察权限，且只使用声明允许的协调。否则只标为全信息协调上界。实际采用 Nash、团队 maxmin 或允许事前相关的团队均衡，需要另立合同和评价器。

### S4：增加欺骗和位置机制

逐一加入悍跳、假查杀、PK竞争、自刀以及发言起点，做单机制和关键交互对照；每次增加动作都产生新模型版本。最后才扩展到更丰富的模板语言与狼人杀角色技能。

## 7. 为什么不能“单项没收益就永远淘汰”

某策略可能只有和另一策略配合才有价值。例如自刀若没有遗言和悍跳信号可能只损失一票；允许可信声明后却可能产生协调收益。这是待检验的交互假设，不是已有结论。

当前对手下不赚钱也不代表没有防守价值：某动作可能用于阻止对手偏离。只看已有对手池可能漏掉新的反制。

保留候选、失败结果和适用条件。只有有严格支配证明、合法动作等价证明，或明确标注“在当前受限模型中筛掉”的证据，才删除动作；后者不构成对完整游戏的淘汰证明。计算成本导致的裁剪另列为抽象误差。

## 8. 数值证据和独立验证

每个结果保存：规则/动作树/信息集版本与哈希、收益单位、求解目标、策略、随机种子、计算预算、完整条件概率、行动价值、独立评价器与适用范围。

小模型优先精确枚举/矩阵/适用的序列形式；只有满足算法前提时才使用 CFR/DCFR/MCCFR。团队协调路线若采用转换，先审计转换的策略可实现性和信息权限。

收益首先定义为阵营终局获胜指示值，行动价值为条件胜率。固定对手下的行动损失可以用“最佳合法行动胜率 − 当前行动胜率”，以百分点报告。它不等于均衡 exploitability。

对多人模型分别报告单个玩家最佳偏离和允许的团队联合偏离；只有在有效的两人常和表示中才使用 `exploitability = NashConv / 2`，且注明收益约定。算不出精确最佳回应时，只能报告已发现的偏离收益作为下界，不能宣称已认证 ε-GTO。

模拟胜率保存独立评估样本与置信区间。比较时使用匹配角色分配和随机流以减少方差；动作空间、预算和阈值在评估前冻结。自我对战胜率接近 50% 不证明均衡。

独立评价必须重新核对终局时序与收益，不能只复用训练器的同一函数。PokerCapabilityLab 的 2026-10-10 flop 审计发现终局收益错误会制造虚假的 exploitability 差距，这一教训尤其适用于“最后一警被刀后能否遗言”等边界。

证据分级：`analytic_probability`、`fixed_policy_value`、`restricted_equilibrium`、`certified_declared_game`。当前只具备第一级的条件公式，其他级别待实现与验证。

## 9. 教学实验如何服务德州扑克

数值求解成功与人类学习成功分开记录。最先可测试的机制是组合计数、行动引起的后验更新、信息公开的收益/成本、顺序规划，以及混合策略执行。

对照可包括：直接给答案、例题讲解、反事实配对训练、主动预测后给反馈。冻结训练时长、题目难度与无辅助评估；以玩家为随机分组单位，按参与者和题族处理重复观测，不把同一人的多道题当独立样本。

评价包括无辅助前后测、未见题族迁移、延迟保持、置信度校准。混合策略用重复决策的分布与战略损失评价，不能要求每次都选最大概率动作。延迟间隔、主要指标与样本量在正式试验前预注册。

迁移德州扑克须另做直接检验，例如：警匪训练 vs 相同时间扑克训练 vs 主动对照，比较未见、已验证的扑克任务中的无辅助表现。警匪得分提升不自动支持扑克能力提升；初期可能仅支持共享推理子技能的迁移。

只有独立通过局部标签和模型范围审计的题目进入正式测评。LLM 可以起草解释与追问，不能自行填写数值答案或认证等级。
