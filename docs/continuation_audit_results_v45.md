# v45：警队协调后丢失的六局，究竟输在哪里？

日期：2026-11-19。主板子仍为4警4匪8民。本轮只审计，不改变实际策略。

## 先读策略与参数

座位均从1开始；原始JSON从0开始。

| 名称 | 实际动作及用途 |
|---|---|
| 原组 `copy_shared` | v44匪方可复制可见遗言；好人保留共同查杀优先。警方按原规则明确归票，不根据预测票数另选匪。 |
| 协调组 `copy_both` | 原组基础上，警察在自己已知的多个活匪中，用当前公开发言预测哪个能获得更多平民式选票，并归票该人。只预测当下，没有模拟第三天。 |
| `copy_base`、`copy_coordinate` | 分别关闭以上两组的共同查杀优先。仅作兼容重放；这六局中，该开关没有改变完整轨迹。 |
| 共同查杀优先 | 至少两名符合接收条件的活来源当天都报同一人是匪，且没有相反报告及私人／合法候选限制时，平民优先投该人。来源未被认证。报不同人不触发。 |
| 接续匪 | 旧悍跳匪死亡、旧假查杀对象仍活着时，一名活同伙在自己的发言位接续指控，可以报假验人并归同一目标。 |
| 复制遗言 | 接续匪若看见当夜死者公开验人，可把报告字段换成该内容。拥有能力不等于实际触发；**这六局没有触发复制。** |
| 正式归票 | 明确说今天投谁，可与验人报告对象不同。警队实际票仍统一跟归票。 |
| 位置排序 | 本次冻结策略第二天起，没有私人反证、共同目标或可用来源区分时，从接受的候选中按当日发言顺序选人；不是计算来源为真警的概率。 |
| `q=1/2` | 特定首日可选回应节点的50%起跳概率，不是每天、每警50%跳。此次不改、不重新择优。 |
| 信用分 | 继续冻结。未新增分数、阈值、概率信用或票型权重。建议资格、目标选择与来源信用仍是不同概念。 |
| 影子计算 | 同一第三天投票时点，仅把真警的一个旧报告换成其当晚已知的新验人，保留归票及其他发言；重算平民首轮票，警匪票保持实际记录。不改变真实对局、不推演后续。 |

“预测多1票”是人数差，不是概率、信用增量或终局收益。私人反证、金水保护、PK限制继续保留。死亡不认证身份，不恢复机械轮出。

## 本轮结论

**六局都是：当天多争取一名平民，换出了不同的匪；这改变次日接续者和公开验人，原位置排序随后把平民票交给了错误目标。**

没有发现警方忘记已知匪、明知匪却投好人，或警队自己分票。也不是“复制死警获得更高信用”：第三天没有可供复制的遗言。

匪方按冻结策略合法触发接续，没有为六局新学规则、读取胜负或平民身份。它利用了当前有限好人策略的弱点，**不等于已证明完善好人策略也无法避免这个代价。** 当下增票的预测没有考虑续局；平民来源未决时仍依赖位置排序。公开信息发布也不充分，但只能解释部分案例。

起点提交 `6853686` 合入许可证，v44研究实现为 `d34718c`。运行前冻结配置、审计器、测试与协议，递归核对v44及父版本源码、归档哈希。

审计v44中 `copy_shared → copy_both` **全部六个由胜转负种子**：227000092、227000734、227001025、227001070、227001245、227001291。四组各重放六局，24条完整轨迹与原始哈希和胜负一致，没有另找种子。

记录器只接收行动者自己的Observation；完整对局和影子计算结束后才附裁判身份做分析。平民未获得警队位置、验人或全局身份。六个种子呈现同一结构，不是六种独立失败机制。

**这是已读数据上的失败机制审计，不是新留出实验。** 新增独立终局样本为0，不训练、不求均衡、不在同批调规则追胜率。

第二天警察已有真实查杀，也私下知道活悍跳者是匪。原组归查杀对象；协调组改归活悍跳者。被悍跳查杀的平民本就知道此人是假，因此改归悍跳者后，平民跟警方归票由6人增至7人。当前预测也恰好多1票。

第二天两边都出匪，日末都是 **3警、2匪、7民**，但留下的人不同：

1. **原组留下旧悍跳者。** 第三天它继续推原平民，警方归它；原位置排序及部分案例的金水保护，使平民跟警方。日末2警、1匪、7民。
2. **协调组留下旧真查杀。** 旧悍跳者已死，另一匪满足接续条件。警方归旧真查杀，接续匪归平民；大部分平民按位置选了平民。日末2警、2匪、6民。
3. 第四天协调组又出一匪，但第五夜最后一警被刀，留下一个匪而失败。这个最后的匪，第三天警方已经知道它是假警；不是没有找匪依据。

六局第三天均为：两警投真匪2票；两匪加六名无私人反证的平民投错平民8票；被假查杀的平民凭私人反证投接续匪1票。**警队统一，但警民没有统一。**

### 例子：2号、6号和11号

种子227000092：2、6、11号是匪，16号是平民。身份均为赛后解释。

第二天5号死警遗言查杀2号，7号真警也报2号是匪。6号旧悍跳者推16号。

- 原组：7号归2号，2号以9票出局。
- 协调组：7号仍诚实报2号是匪，但明确归6号；6号以10票出局。

第三天两边都刀7号，警方这夜验到16号好人：

- 原组中2号已死，9号报新金水16号、归6号，最后6号9票出局。
- 协调组中2号仍活着，旧报告选择器优先重复查杀2号，没有公开新金水16号。11号接续6号旧指控，报16号是匪并归16号。警方两票投2号，六名普通平民按候选位置选16号，16号8票出局。

当日真警报2号，假警报16号，不是双方共同查杀16号，因此共同查杀优先不触发。程序没有给11号更高信用，而是从候选2、16中，按7号死后的发言顺序选了更靠前的16号。

所有日程、验人、归票和票数见[六局阅读版](continuation_audit_cases_v45.md)。

## 漏报新验人：存在，但不是统一答案

旧报告选择器优先报最新一个仍活着的已验匪；没有活查杀才退回最新验人。它保留私人信息，但可能没有公开新增信息。**这是报告选择策略的局限，不能说验人被程序遗失。**

六局第三天都验到新好人，却重复旧查杀。按预先冻结的协议做同一时点单字段诊断：

| 诊断 | 结果 |
|---|---:|
| 未报当晚新金水 | 6局 |
| 换新金水后首轮票改变 | 1局，共6张平民票 |
| 最高票从平民改为匪 | 1局 |
| 其余五局首轮票 | 完全不变 |

改变的就是16号案例：公开16号好人后，既有金水保护过滤了推16号的建议，六张票改投2号。由“16号8、2号2、11号1”变为“2号8、16号2、11号1”。其余五局新金水不是被冲的平民，原位置选择不变。

**只证实一局投票可以被合法公开信息纠正，未证实赢回一局，更没有一般性的1/6修复率。** 诊断固定了匪方发言和实际警匪票，未重跑完整续局、未让匪方回应新报告。不能部署为“总报新验人”更优的结论。

其他发言也被固定，因此没有重新生成新金水可能引发的委托或接力；五局票不变不等于这种完整策略无用。影子计算保留原公开逐票前缀，而此处两类票型学习均关闭，不使用该前缀重算信用或目标。

终局胜负0/1继续作为目标；每日警匪数、首次分岔、私人信息是否公开、跟票原因作为机制诊断。**不把出匪数改成训练奖励，也不据它给所有失败排优劣。**

若说“只修一步就能赢”，需要从该步实际重跑完整续局；若说“怎么出都找不到最后一匪”，还需要指定信息集和策略下的可达性论证。本轮没有完成这些证明。六局则已经明确：剩余匪并非警方无法识别，而是没有及时转成共同放逐。

## 先报、后复制与可信度

“后报相同内容不是独立证据”值得保留；“A先报C金水，所以A必然比B可信”还不是铁逻辑：

- 警队共同验人，真警重复团队信息不需要巧合；应否暴露第二警是另一策略问题。
- 匪可先报、真警后回应；机械相信先报者会奖励早悍跳。
- 后报者看过前报内容，可能直接模仿，不能把一致当两份独立验证，也不自动提高其来源可信度。
- 复制有时只是让“唯一匹配死者的活来源”变成“两名都匹配”，取消原优先；这不是认定复制者更真。也可能只满足建议资格，之后由位置排序决定目标。

需要分别检查：有无回应机会、报新夜验还是旧验、真警为何这样报、假警能否直接从公开前缀复制，再比较生成策略的支持与可能性。现在不指定未经校准的先后信用权重。

**本次六局实际发生的是重报死匪同伙的首日假查杀，不是复制当夜死警。** 第三天没有相关遗言可供复制。匪方成功仍依赖当前接收器机械回退，不能称为一般人类玩家也必然信服的骗术。

## 建议下一步，由用户决定

先把“跟谁／出谁／报哪条信息”分开。新金水诊断不足以覆盖五个案例，不能直接统一改为总报新金水。

可做一个窄实验：给协调预测增加公开可推断的续局情形——今天出了旧悍跳者，明天谁可能接续、已有共同查杀会否留下——再固定信息发布预算，比较单日多一票与续局风险。先冻结规则，再用全新种子和完整终局验收，不能用六局调好后就称泛化。

先后报验人的来源判断另作生成机制问题。q、数值信用、A→C严格同概率对照、票型、遗言制度、金水假跳挡刀保持分开待办，本轮未增加。
