# v25：反制是种子过拟合，还是在利用机械接收？

2026-10-30。本轮先读旧留出做机制审计，再冻结一项消融及新训练／验收，不增加匪策略，不同时加信用或票型评分。

## 策略／参数字典

|名称|实际动作、继承与对照|
|---|---|
|base_q0 / base_q50 / base_q100|v24两项修复、私人记忆和原路由不变；窄条件单警回应概率0% / 50% / 100%。base不是冻结信用对照。|
|gate_q0 / gate_q50 / gate_q100|只在第二天起限制建议资格：仅说自己是警察、从未以本人来源提出report验人声明者，其建议不进入当日归票集合。|
|restate|原首日假警与旧目标都活着时，原人再次建议出旧目标。|
|claim|保留restate；原假警死亡且旧目标仍活时，首位活匪在正常发言自己跳警，并提议出旧目标；无新验人。|
|late / decoy|继承safe_late后置位置刀 / posterior_decoy伪装刀。|
|near / far|首位匪按公开后续发言序选最近／最远非队友作首日假查杀目标。|
|q|局部行动概率，不是信用或身份概率，也不是全局跳警率。|
|report|公开声称验人；没有裁判身份认证，匪也能伪造。|
|police / accuse|公开跳警身份声明 / 今天想出某人的建议；accuse不自动等同于新查杀。|

**q生效条件：** 首夜没死警、预定首警尚未发言、已经出现假警且假查杀未中警队，只有该警在自己正常轮次抽一次。其余被打中警队的必答、后续警察发言规则不变，不再拉第二警。q从0至1，不累计、无信用衰减；本轮三档是人工比较网格，未训练、冻结或宣称新的最佳比例。

**gate的具体例子：** A昨天查杀C后死亡，B今天只说“我也是警察，今天出C”。B的身份声明仍保存，也仍能形成冲突或被真警私下识破，但其建议暂不进入集合。B如果自己报了一条验人，即使是假的，也能通过资格。这里不是判断B真伪，只改变建议通道；没有数值权重、门槛拟合或身份概率。

来源信用、目标怀疑、建议资格和实际投票分开：数值信用继续冻结；位置排序不变；gate仅改建议资格；私人已知匪优先、金水先后关系和投票破同分不变。source_credit=True为兼容字段，实际routing=evidence不用数值信用分支；history=False关闭旧票型加分，remember=True仍保留跨日私人证据。

其余均继承：4警4匪8民、警方互认共享夜验、真实警察报真实实际验人、死亡不翻身份、前三死亡遗言、可弃票、一轮PK再平票平安日。位置等权似然、gap验人、二人内推、固定程序续局均不变。2%扰动只在好人位置似然假设中，实际匪刀未添加。规则虽允许自刀，本池无自刀策略；无平民假跳。所有玩家为固定程序，不使用LLM临场推理。

## 本轮先看结果

四个固定匪条件中，4/4项来源资格消融的同时95%区间支持好人胜率提高。这里只是同一对手池、同一规则中的机制证据，不是完整最优防守。下文同时列出不跳藏条件、负对照和未解决问题。

## 先回答过拟合的质疑

应区分三件事：**记住某批seed**、**针对固定对手协议的利用**、**对更完善好人策略仍稳健**。v24的新seed验证反制不是只在开发种子上好用；合法Observation审计未见直接读取未知警民标签。它仍明显针对现有来源与归票协议，尚未证明能利用合理、完善的好人最佳应对。双方都不是完整最佳应对，所以不能解释为真实游戏客观只剩这些胜率。

旧两项逻辑修复和新漏洞可以同时存在：不再按死—活历史冲突强制轮出是合理动作修复；新活人声明改变当日建议又是另一机制。本轮继续不认证死亡、不恢复机械轮出，也不拿胜率降低作为撤销修复的理由。

“有意针对对手”在固定模型里是合法反制；“这就是完整游戏的稳健最优应对”目前没有证据。若轻微改变接收规则就改变结果，则更说明反制对协议敏感；这仍不等于匪策略不合法或只拟合了seed。

## 两项分别审计：先有证据，再决定做哪项消融

固定重放v24旧留出前512seed×四组×restate/claim，共4096个不同单元轨迹。第一次发现口径后补充核查“两个目标是否都私知匪”，实际共两遍8192次旧轨迹运行；只算4096个不同旧轨迹，不算新确认样本。旧留出已使用开发，不能继续充当未看过验收。

“打散”口径：原路由取兼容建议并集；有无本人验人声明的新来源；其他有验人声明的来源存在共同建议；在完全同一观察中，只挡无report建议的影子票改变。影子票是动作敏感性诊断，不是整局因果效应。此口径只计进入兼容建议并集的情况，未包括新来源触发活人冲突比较等其他来源敏感路径；86—285局不是全部受影响局。

公开查杀与投票不一致的全部被标记票，两目标都在该警私知匪集合中。这不是“明知匪却投好人”，但可能让平民跟A、警队投B。该标记仅限本人当天公开过合法活目标查杀；没说话者不被误计。它仍需单独试验，今天没有修。两类可同局出现，不能把计数相加当独立损失贡献。

例：旧留出174000033（后置刀组），第二天10号真警公开查杀5号，却投3号；他的私人已知匪同时有3、5。公开信息让平民倾向5，警方位置破同分却倾向3，这是需要单独研究的协调差异，不是没记住5号是匪。

选择来源资格消融的理由：四个claim组都有较多来源敏感动作，restate中该口径均0；先用一个明确开关隔离这个通道。不因胜率不好就同时修两个模块，也不按新结果继续调门槛。

## 票型能不能抓匪？本轮先量化误判风险

统计所有已完成普通首轮投票中，某个被公开提议的目标获得至少3票的组。3只是描述口径，不是部署的怀疑阈值。事后裁判角色仅用于评价，不能进入当时玩家推理；同局／跨日组重复且相关，不作为独立样本做显著性结论。

|模式|集中票组|其中全是好人的票组|组内累计好人票／全部票|匪占多数票组|
|---|---:|---:|---:|---:|
|restate|7486|4751|39051／49435|2146|
|claim|9667|4660|36264／53475|3663|

初始只有4名匪，因此5张票的组至少有1名好人；不能把整组都判坏。仅凭总票数也不知道其中几张是匪。

因此你的方向值得继续：跟随已被自己合法证据推翻的来源、连续多轮同一联盟冲票，可能是比孤立同票更好的信号。但“15号挂5票”不足以把5人都判匪：真警会抱团，普通民会被假警误导，匪也可跟真查杀做身份。你提出“可信好人共同投票不应让整个团队被同等怀疑”是合理方向；但即使是真好人也可能因信息不足投错。金水来源还可能是假警，所以需要记录来源关系，不能把每个集中票组作对称加分。

下一步票型应按观察者的合法信息来定义：何时公开了改归、谁当时有反证、PK是否合法候选、哪些金水互相支持、是否存在可以解释的改票。只有完成的票可用；普通首投公布后可供PK/后续日参考，不能预读尚未发生的票。本轮旧路由虽然看得到公开票，尚未实现这种完整学习；没有直接加任意怀疑分。

两项旧漏洞、忽略合法已知匪、投私人已知好人、非法票在本轮所有正式格子的审计标记均为0；这核对特定规则，不证明其余推理完整。
